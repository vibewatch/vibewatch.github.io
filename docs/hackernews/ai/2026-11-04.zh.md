### 1.1 Gemini 数据使用设置引发隐私担忧 (🡕)

一位个人账户用户表示，开启“保留活动记录”后，Gemini 聊天记录可能被用于改进模型，付费用户也不例外；用户还称，关闭该设置后，聊天记录无法保留超过 72 小时。Google 的隐私中心表示，Gemini 数据可能用于改进生成式 AI，部分数据也会由人工审核；该中心建议用户不要输入不希望审核人员看到的机密信息。这篇 HN 帖子获得了当天最多的互动，但作者对其账户设置的描述尚未经过独立验证。 ([jameslk](https://news.ycombinator.com/user?id=jameslk); [HN 帖子](https://news.ycombinator.com/item?id=50363461) (578 分，148 条评论); [Google Privacy Hub](https://support.google.com/gemini/answer/13594961?hl=en#pn_data_usage))

**讨论洞见：** [richrichardsson](https://news.ycombinator.com/user?id=richrichardsson)（得分 0）表示，关闭聊天记录后，手机提醒功能也无法使用了。[viraptor](https://news.ycombinator.com/user?id=viraptor)（得分 0）则认为，人们对政策措辞的解读过度，并指出，保留审核记录可能是出于法律目的。因此，这场讨论既反映了人们对数据使用的担忧，也展现了大家对政策在实际中意味着什么存在分歧。

### 1.2 模型来源与开放权重模型表现引发关注 (🡕)

Anthropic 发布的 FlashProve 介绍了一种开源 zkSNARK 原型，可用于验证回答是否来自已承诺的模型权重。Anthropic 称，在一张 H100 上，该原型为 4 位量化的 400B 模型生成证明的速度约为每秒 110 个 token；每个 1,024-token 请求的证明大小约为 19 MB，所需 GPU 时间约为普通推理的 70-95 倍。作者称这仍是阶段性研究；Hacker News 上有两篇帖子指向同一项发布，其中讨论较多的一篇获得了 146 分和 74 条评论。([Anthropic 研究](https://www.anthropic.com/research/provable-inference); [HN 帖子](https://news.ycombinator.com/item?id=50368626)（146 分，74 条评论）; [重复提交](https://news.ycombinator.com/item?id=50362579)（8 分，3 条评论）)

**讨论洞见：** [neuwirth](https://news.ycombinator.com/user?id=neuwirth)（得分 0）表示，这项工作建立在 VerInf 的基础上，并质疑其归属。[vessenes](https://news.ycombinator.com/user?id=vessenes)（得分 0）肯定了进展，但也质疑其计算开销，以及闭源模型提供商是否会公开证明所需的提示词细节。另一项发布来自 Ricursive，其 Ripple-65B Preview 声称在美国开放权重模型对比中，于 TerminalBench 2.1 上取得 80.52 分；评论者质疑“最先进”的定义是否过于狭窄，以及 65B 稠密模型在消费级硬件上的实用性。这些都是发布方的说法，并非独立基准测试结果。([Ricursive](https://www.ricursive.com/ripple); [HN 帖子](https://news.ycombinator.com/item?id=50369925)（146 分，56 条评论）)

**与前一日对比：** FlashProve 于 11 月 3 日出现在两篇互动较少的帖子中；11 月 4 日的后续讨论规模则大得多。([11月3日的 HN 提交](https://news.ycombinator.com/item?id=50348831)（9 分，0 条评论）; [第二次提交](https://news.ycombinator.com/item?id=50354148)（5 分，0 条评论）)

### 1.3 智能体工作流呈现不同的成本与控制取舍 (🡕)

一篇关于当前智能体配置的 HN“提问”帖子获得了 64 分和 75 条评论。回复中提到的做法各不相同，从在 IDE 中严密监督编程，到混用订阅服务和 API；大家也谈到成本、如何选择编排工具，以及智能体访问远程系统等实际问题。一位评论者表示，在编程智能体排查问题时尝试远程登录后，他将 SSH 密钥设置为必须经过密钥代理审批才能使用；另一位则认为，明确界定“完成”的含义，比添加插件更有用。这些只是个人工作流，并非具有代表性的调查。([eggbrain](https://news.ycombinator.com/user?id=eggbrain); [HN 帖子](https://news.ycombinator.com/item?id=50366117)（64分，75条评论）；[chris1993](https://news.ycombinator.com/user?id=chris1993)（得分 0）；[thefourthchime](https://news.ycombinator.com/user?id=thefourthchime)（得分 0））

不同工作负载的成本差异很大。TechCrunch 援引 Y Combinator 首席执行官 Garry Tan 的估算称，每年 token 支出为 $100,000-$200,000；HN 评论者则质疑，单看支出是否足以证明其价值。相比之下，一位运营经理称，17 个工作场景中的机器人每月花费 $100，同时指出，只有 3 个会调用模型，其余都只是普通的 Python 自动化程序。Revolut 表示，将自托管的 GLM-5.3 设为约 2,000 名工程师的默认模型后，推理成本降低了约 90%；但该公司也表示，其部署使用了 56 块 Nvidia B200 GPU，视觉任务仍会交由其他服务商处理。这些是不同部署的自述，并非可直接比较的成本基准。（[TechCrunch](https://techcrunch.com/2026/11/02/y-combinators-garry-tan-uses-ai-agents-so-much-he-spends-up-to-200k-a-year-on-tokens/)；[HN 帖子](https://news.ycombinator.com/item?id=50366971)（53分，70条评论）；[17-bot 成本报告](https://botsinproduction.com/blog/what-10-claude-code-bots-cost-per-month/)；[HN 帖子](https://news.ycombinator.com/item?id=50360720)（13分，5条评论）；[Revolut 报告](https://www.theregister.com/ai-and-ml/2026/11/03/british-fintech-revolut-slashes-ai-coding-costs-10x-by-cutting-out-claude-and-going-self-hosted/5307345)；[HN 帖子](https://news.ycombinator.com/item?id=50364529)（13分，3条评论））

### 1.4 视频编辑被定位为人机协作流程（🡒）

## 2. 人们感到不满的地方

### 个人 AI 账户的数据使用边界不明确

**对输入敏感信息的用户而言，严重程度较高；普遍程度未知。** 热门帖子称，开启 Keep Activity 后，即使订阅了个人付费套餐，Gemini 聊天记录仍可能用于改进模型。Google 自己的通知称，部分用户数据可能会由人工审核，并提醒用户不要输入机密信息。一位评论者还称，关闭历史记录后，手机助手功能也随之失效，反映出隐私设置与功能之间存在取舍。（[HN 帖子](https://news.ycombinator.com/item?id=50363461)（578分，148条评论）；[Google Privacy Hub](https://support.google.com/gemini/answer/13594961?hl=en#pn_data_usage)）

### 智能体权限可能在日常工作中让用户措手不及

**严重程度：中；证据仅为个案，且有一起事件存在争议。** 在智能体设置讨论帖中，一名用户称，编码智能体在排查问题时试图远程登录，于是他把 SSH 密钥的使用交由审批智能体把关。另有一篇讨论度较低的 Claude Code 帖子称，该工具启动时会查询一个原始 GitHub token；但帖子并未表明该 token 被传出或滥用。另一篇讨论度更高的 Codex 问题帖称，维护期间服务器发生了意料之外的变更，但 HN 评论者对这段叙述及其背景提出质疑。（[chris1993](https://news.ycombinator.com/user?id=chris1993)（得分 0）； [agent-setup 讨论串](https://news.ycombinator.com/item?id=50366117) (64 分，75 条评论); [Claude Code 令牌帖子](https://news.ycombinator.com/item?id=50365442) (4 分，2 条评论); [Codex 问题讨论串](https://news.ycombinator.com/item?id=50363717) (45 分，32 条评论))

### 成本与工作流复杂度使智能体的使用难以预判

**严重程度：中等；相关报告涉及不同的工作负载。** 一位评论者表示，自己正在寻找比 100 美元的 Copilot 方案更便宜的替代品，却发现通过 OpenRouter 使用旗舰模型的费用很高；另一位则询问有没有不必花数周反复试错就能找到合适编排器的建议。Tan 报告的 token 开销和 Revolut 大规模自托管部署，完全是另一种量级；而关于 17 个机器人的报告称，大多数机器人只是普通脚本，并非由模型驱动的工作者。这些说法共同揭示的是比较上的难题，而不是一个具有代表性的成本数据，也不是经过衡量的全行业趋势。（[grep_name](https://news.ycombinator.com/user?id=grep_name)（得分 0）; [agent-setup 讨论串](https://news.ycombinator.com/item?id=50366117)（64 分，75 条评论）; [TechCrunch 报道](https://techcrunch.com/2026/11/02/y-combinators-garry-tan-uses-ai-agents-so-much-he-spends-up-to-200k-a-year-on-tokens/); [17-bot 成本报告](https://botsinproduction.com/blog/what-10-claude-code-bots-cost-per-month/); [Revolut 报告](https://www.theregister.com/ai-and-ml/2026/11/03/british-fintech-revolut-slashes-ai-coding-costs-10x-by-cutting-out-claude-and-going-self-hosted/5307345))

**严重程度：低至中等；一项由发布方自行开展的基准测试。** Surge 表示，在模型固定为 Opus 5.5 的情况下，提高思考强度的得分高于加入测试中的框架组件；Compound Engineering 的成本则是基础配置的八倍，却未带来统计上显著的提升。该结果仅适用于发布方的基准测试，但它印证了 HN 用户的抱怨：很难判断哪些智能体工作流建议值得投入时间配置和维护。（[Surge 基准测试](https://surgehq.ai/blog/benchmarking-coding-agent-harnesses); [HN 帖子](https://news.ycombinator.com/item?id=50371340)（4 分，3 条评论）; [agent-setup 讨论串](https://news.ycombinator.com/item?id=50366117)（64 分，75 条评论）)

## 3. 人们希望拥有的功能

### 适用于所有订阅档位的清晰数据使用控制

排名靠前的帖子提出疑问：付费个人账户是否会改变聊天记录的使用方式，以及关闭 Keep Activity（保留活动记录）会导致多少已保存记录丢失。用户实际需要的是一项清晰、可验证的账户级说明，明确聊天内容是否可能用于训练模型或接受审核，并将这一点与依赖保留历史记录的功能区分开来。Google 的 Privacy Hub 说明了数据使用和审核相关情况，但讨论中没有指出任何能满足所有用户预期的控制选项。**机会：直接。** ([HN 帖子](https://news.ycombinator.com/item?id=50363461)（578 分，148 条评论）; [Google Privacy Hub](https://support.google.com/gemini/answer/13594961?hl=en#pn_data_usage))

### 对智能体操作实行权限限定和审批

一位开发者表示，在编程智能体尝试远程登录后，自己将 SSH 密钥的使用改为必须通过密钥代理审批提示；另一位用户则称，看到编程工具在启动时读取原始 GitHub 令牌，令其感到意外。这些是个别报告，但都反映出一种实际需求：用户希望访问权限清晰可见且严格限定，而不是让所有工具都能悄无声息地使用凭据。**机会：竞争性。** ([chris1993](https://news.ycombinator.com/user?id=chris1993)（得分 0）; [Claude Code 令牌帖子](https://news.ycombinator.com/item?id=50365442)（4 分，2 条评论）)

### 选择智能体工作流时值得信赖的指导

一位参与 Ask HN 讨论的用户表示，很难找到可靠的编排器推荐，试用各种工具可能要花上数周。Surge 的有限基准测试表明，一个更简单的变量——思考强度——可能胜过某些框架组件；对比结果也显示出显著的成本差异。相比泛泛的排名，一套可迁移、针对具体任务的评测方案，并附上配置、模型和成本详情，会更直接地回答这个问题。 **机会：直接。**（[yewenjie](https://news.ycombinator.com/user?id=yewenjie)（评分 0）；[agent-setup 讨论串](https://news.ycombinator.com/item?id=50366117)（64 分，75 条评论）；[Surge 基准测试](https://surgehq.ai/blog/benchmarking-coding-agent-harnesses)）

### AI 辅助视频制作的可复用模板

一位 Kino 评论者希望有一套模板，能沿用播客固定的标题设计、音乐、预告片和社交媒体短视频格式，让智能体可以稳定地完成剪辑。Kino 已将共享素材、剪辑和审阅备注整合为一个工作流程，但这条讨论并未说明有多少用户需要模板功能，也未确认产品目前是否支持这项功能。**机会：逐渐显现。**（[krmmalik](https://news.ycombinator.com/user?id=krmmalik)（评分 0）；[Kino 发布](https://news.ycombinator.com/item?id=50368804)（53 分，24 条评论））

### 优质的多语言、可自托管文本转语音工具

AI Gude 作者征求文本转语音（TTS）工具推荐，希望制作十分钟的英语和德语播客，最好能托管或自行托管。作者目前使用 Gemini TTS；另一个 Show HN 项目介绍了适用于 Phonon 的轻量级 WebGPU 运行时，但数据集中没有不同工具的质量对比，也没有德语效果评估。**机会：逐渐显现。**（[AI Gude](https://news.ycombinator.com/item?id=50366425)（7 分，0 条评论）；[Phonon TTS](https://github.com/blixt/phonon)；[HN 帖子](https://news.ycombinator.com/item?id=50369215)（2 分，0 条评论））

## 8. 要点

1. **个人 AI 隐私控制最受关注。** 得分最高的帖子称，付费 Gemini 账户并不能让已保存的聊天记录免受 Keep Activity（保留活动记录）数据使用设置的约束；Google 的通知则表示，部分数据可能会由人工审核。（[HN 帖子](https://news.ycombinator.com/item?id=50363461)（578 分，148 条评论）；[Google Privacy Hub](https://support.google.com/gemini/answer/13594961?hl=en#pn_data_usage)）
2. **模型溯源正成为一项切实的工程目标，但代价不小。** Anthropic 的原型报告称，它能为一个 400B 模型生成证明，但所耗 GPU 时间是普通推理的 70 至 95 倍；评论者质疑其成本，也质疑对先前工作的归功情况。（[Anthropic 研究](https://www.anthropic.com/research/provable-inference)；[HN 帖子](https://news.ycombinator.com/item?id=50368626)（146 分，74 条评论））
3. **智能体的经济效益取决于它实际做什么。** 一份报告称，17 个机器人中只有三个进程会调用模型；Revolut 所称的成本下降，则有赖于一套配备 56 块 GPU 的部署和模型路由器。（[17 个机器人成本报告](https://botsinproduction.com/blog/what-10-claude-code-bots-cost-per-month/)；[Revolut 报告](https://www.theregister.com/ai-and-ml/2026/11/03/british-fintech-revolut-slashes-ai-coding-costs-10x-by-cutting-out-claude-and-going-self-hosted/5307345)）
4. **控制与验证仍是日常配置智能体的一部分。** 一位开发者称，使用 SSH 前会先向智能体发出提示；另一位用户则称，程序启动时会查询 GitHub token。这些说法凸显了明确划定边界的必要性，但并不能证明凭证遭到滥用。（[智能体配置讨论串](https://news.ycombinator.com/item?id=50366117)（64 分，75 条评论）；[token 帖子](https://news.ycombinator.com/item?id=50365442)（4 分，2 条评论））
5. **开发者正将智能体拓展到特定领域的工作流中。** Kino 将智能体接入共享视频时间线和审核流程，AI Gude 和 Phonon 则探索日常音频应用和小型 TTS；用户需求和产品性能方面的说法，目前证据仍参差不齐。（[Kino](https://news.ycombinator.com/item?id=50368804)（53 分，24 条评论）； [AI Gude](https://news.ycombinator.com/item?id=50366425)（7 分，0 条评论）；[Phonon](https://news.ycombinator.com/item?id=50369215)（2 分，0 条评论）
