# HackerNews AI - 2026-11-06

The 71 stories collected 367 points and 137 comments. Perplexity's work-agent launch led with 57 points and 49 comments; an Ask HN about overlooked computing topics followed with 40 points and 36 comments. The day's AI discussion connected ongoing agent work to cost, identity, and isolation, alongside interest in using AI to revisit interfaces and build small personal tools. Product capabilities and incident reports below are attributed to their authors or vendors where applicable.

## 1. What People Are Talking About

### 1.1 Agents move from answering prompts to owning ongoing work (🡕)

Perplexity introduced Teammates as agents that retain project goals and files, coordinate Computer sessions or other teammates, monitor changing work, and return progress or approval requests. The launch describes workflows across sales, marketing, support, and operations, with integrations including Slack, GitHub, and Gmail. Perplexity says each teammate runs in a separate environment and users can inspect or redirect its work; these are company descriptions, not independent performance results. ([Perplexity announcement](https://www.perplexity.ai/en-GB/hub/blog/teammates-are-agents-for-complex-ongoing-work); [HN story](https://news.ycombinator.com/item?id=50395866) (57 points, 49 comments))

**Discussion insight:** Reactions to the launch were sharply negative among several commenters. [trnvll](https://news.ycombinator.com/user?id=trnvll) (score 0) said Perplexity seemed to have declined in user experience and product quality; [jwr](https://news.ycombinator.com/user?id=jwr) (score 0) described a subscription experience that switched away from a selected higher-capability model. These are individual accounts, not a measure of overall customer sentiment.

**Comparison to prior day:** November 5's leading agent posts centered on a physical keypad for prompting and approving work and a local session-audit tool. November 6's leading launch instead pitches agents that monitor and advance ongoing work. This is a shift in the daily feed, not evidence of a lasting trend. ([Keypad HN story](https://news.ycombinator.com/item?id=50381302) (84 points, 55 comments); [Stroq HN story](https://news.ycombinator.com/item?id=50380704) (48 points, 10 comments))

### 1.2 Agent infrastructure converges on identity, isolation, and idle-time economics (🡕)

Zalando's Agentic Identity Broker is an open-source OAuth2 broker for scoped, revocable agent access to MCP services. Its author says it encrypts delegated tokens and uses RFC 8693 token exchange so agents do not receive users' credentials, and reports a v0.1 deployment with hundreds of internal agents; those deployment figures are author-reported. Commenters asked how the product differs from OAuth delegation alone and how it handles transitive access. ([Repository](https://github.com/zalando-incubator/agentic-identity-broker); [HN story](https://news.ycombinator.com/item?id=50393235) (18 points, 3 comments); [tiffanyh](https://news.ycombinator.com/user?id=tiffanyh) (score 0); [yubblegum](https://news.ycombinator.com/user?id=yubblegum) (score 0))

Google's announcement that it donated Agent Substrate and gVisor to the CNCF frames agent runtimes around isolating untrusted code while reducing compute held idle during model calls or human review. A separate Ask HN asks how to run multi-agent work overnight without high costs; Botel's builder describes pausing agent VMs when they are not active, while noting that identifying short- and long-lived jobs remains difficult. ([Google Open Source announcement](https://opensource.googleblog.com/2026/11/sandboxing-untrusted-ai-agents-at-scale.html); [HN story](https://news.ycombinator.com/item?id=50390509) (6 points, 0 comments); [Ask HN](https://news.ycombinator.com/item?id=50391647) (4 points, 3 comments); [Botel](https://botel.dev); [Botel HN story](https://news.ycombinator.com/item?id=50393793) (3 points, 3 comments))

### 1.3 AI-assisted work reopens questions about computing and interfaces (🡕)

An Ask HN about forgotten computing topics drew 40 points and 36 comments. Suggestions ranged from human-computer interaction and operating-system design to Pascal and memory allocation. [codingdave](https://news.ycombinator.com/user?id=codingdave) (score 0) argued that AI tools have sped up content creation without rethinking familiar screen, keyboard, and mouse interactions; [romesmoke](https://news.ycombinator.com/user?id=romesmoke) (score 0) described memory allocation as an area with unresolved definitions and tradeoffs.

A separate Ask HN offers a personal example of the same shift: its author reports building small tools for a TV remote, phone media timer, family photo frame, electricity monitoring, and offline maps, and says they are organizing a local course. A commenter, [stevendeluth](https://news.ycombinator.com/user?id=stevendeluth) (score 0), said they replaced invoicing software with a custom build on a Raspberry Pi. These are individual examples rather than adoption estimates. ([Forgotten-topics HN story](https://news.ycombinator.com/item?id=50387483) (40 points, 36 comments); [Home-cooked software HN story](https://news.ycombinator.com/item?id=50391446) (3 points, 3 comments))

### 1.4 Specialized agents emphasize evidence and structured artifacts (🡒)

TinyFish's TinyResearch article describes a research loop that breaks a question into subquestions, ranks sources for the task, reads pages live, extracts source-linked claims, checks for gaps, and writes from those claims. The author says the product is evaluated on factual correctness, credibility, readability, comprehensiveness, and instruction-following; these are the builder's design goals and reports, not an independent evaluation. ([TinyResearch article](https://www.tinyfish.ai/blog/inside-tinyresearch); [HN story](https://news.ycombinator.com/item?id=50389479) (19 points, 0 comments))

In a different domain, LDraw Mecha uses agents to infer mechanisms from annotated LEGO model files and produce rigged Blender animations. The builder presents it as a continuation of an earlier model-generation tool, illustrating a narrow pipeline from structured input to a finished visual artifact. ([Repository](https://github.com/anteloc/ldraw-mecha/tree/v0.5.0); [HN story](https://news.ycombinator.com/item?id=50397325) (15 points, 0 comments))

## 2. What Frustrates People

### Keeping persistent agents affordable and predictable

**Severity: Medium; prevalence: limited direct evidence.** An Ask HN author says their local agents stop overnight and asks about subscription, API, and self-hosted costs for always-on or multi-agent systems. Botel's builder offers active-time billing but says agent harnesses do not expose enough information to reliably distinguish short- from long-running jobs. The open question is not only idle compute, but how runtimes recognize when a job can safely pause. ([Ask HN](https://news.ycombinator.com/item?id=50391647) (4 points, 3 comments); [Botel HN story](https://news.ycombinator.com/item?id=50393793) (3 points, 3 comments))

### Destructive actions and unclear execution boundaries

**Potential severity: High; prevalence: unclear.** A Reddit post linked to HN alleges that an agent deleted a machine; this is a single user report and the cause is not independently established. In the HN discussion, [marcduck](https://news.ycombinator.com/user?id=marcduck) (score 0) asks whether Docker is a sufficient sandbox. A separate Show HN advertises a zero-trust POSIX runtime, but [spoaceman7777](https://news.ycombinator.com/user?id=spoaceman7777) (score 0) questions whether its repository supports the stated policy-enforcement claims. The evidence supports interest in containment and verifiable boundaries, not a conclusion about any product's security. ([Linked incident](https://old.reddit.com/r/google_antigravity/comments/1xpbc54/antigravity_ran_a_command_to_delete_my_entire/); [HN discussion](https://news.ycombinator.com/item?id=50395939) (5 points, 9 comments); [AegisKernel HN story](https://news.ycombinator.com/item?id=50394991) (10 points, 3 comments))

### Agent connections add friction and token overhead

**Severity: Low to Medium; evidence is one beta launch.** GRID's builder says MCP reconnection can fail after a browser refresh and that tool calls use more tokens than desired. They also report that the built-in local model struggles to follow written strategies. This is a concrete account of integration and model limitations, not a general evaluation of MCP or local models. ([GRID HN story](https://news.ycombinator.com/item?id=50392347) (4 points, 3 comments))

### Delegated access is difficult to explain at the user level

**Severity: Low; prevalence: one small discussion.** On the Agentic Identity Broker launch, [tiffanyh](https://news.ycombinator.com/user?id=tiffanyh) (score 0) asked for examples of where the broker fits into daily work and how it differs from existing OAuth delegation; another commenter asked about transitive cases. This points to a gap in explaining the use case and authority model, rather than a reported failure of the implementation. ([HN story](https://news.ycombinator.com/item?id=50393235) (18 points, 3 comments))

## 3. What People Wish Existed

### Affordable always-on agents with reliable pause and resume

The Ask HN author wants to leave complex tasks running overnight and asks how others control inference costs. Botel offers a pay-as-you-go VM model and estimates a small community website could cost about $0.40 per month under its described usage, but its builder also says job-lifecycle detection is unresolved. The practical need is persistent execution with transparent billing and dependable pause/resume behavior. **Opportunity: competitive**; a service exists, while workload detection and independent cost comparisons remain open. ([Ask HN](https://news.ycombinator.com/item?id=50391647) (4 points, 3 comments); [Botel HN story](https://news.ycombinator.com/item?id=50393793) (3 points, 3 comments))

### Clear, revocable authority for agents

The Agentic Identity Broker author describes scoped, revocable OAuth delegation as a way to avoid giving agents users' tokens. Questions about transitive access and everyday use suggest that builders also need clear explanations of which identity an agent acts as, what it can access, and how approval and revocation work. **Opportunity: competitive**, since an implementation is already presented, but the discussion leaves usage and authorization boundaries to explain. ([Repository](https://github.com/zalando-incubator/agentic-identity-broker); [HN story](https://news.ycombinator.com/item?id=50393235) (18 points, 3 comments))

### Tools that make personal computing easier to reshape

The home-cooked software author describes using AI assistance to fix small hardware and software annoyances and plans to teach others locally. In the larger forgotten-topics thread, a commenter calls for rethinking familiar screen and keyboard interactions rather than only speeding up work inside current interfaces. These are practical requests for more user control, but evidence is mainly a few individual accounts rather than broad demand. **Opportunity: emerging.** ([Home-cooked software HN story](https://news.ycombinator.com/item?id=50391446) (3 points, 3 comments); [Forgotten-topics HN story](https://news.ycombinator.com/item?id=50387483) (40 points, 36 comments); [codingdave](https://news.ycombinator.com/user?id=codingdave) (score 0))

## 6. New and Notable

### Agent Substrate and gVisor move into CNCF stewardship

Google announced that it donated Agent Substrate and gVisor to the Cloud Native Computing Foundation in Sandbox status, describing agent-specific needs around isolated execution and idle periods. Google's post says Agent Substrate had reached a 1.0 release; the HN submission received 6 points and no comments, so community response in this dataset was limited. An Ars Technica report published October 27 appeared in the day's feed, describing a Delaware draft proposal for companies whose agents could manage business operations and a congressional inquiry about transparency and responsibility for harmful actions. The HN submission received 7 points and no comments; the article reports a proposal and inquiry, not an operating AI-run company. ([Ars Technica](https://arstechnica.com/tech-policy/2026/10/no-human-at-the-helm-delaware-plan-would-let-ai-agents-run-entire-businesses/); [HN story](https://news.ycombinator.com/item?id=50396682) (7 points, 0 comments))

## 7. Where the Opportunities Are

**[+++] Lifecycle-aware agent runtimes with predictable idle costs** — The Ask HN post asks how to run agents overnight affordably, Botel's builder identifies job-lifecycle detection as an unresolved integration problem, and Google's Agent Substrate announcement focuses on isolating agents while they wait. A product that makes state, pause/resume behavior, isolation, and billing legible would address issues raised across discussion and builder posts. ([Ask HN](https://news.ycombinator.com/item?id=50391647) (4 points, 3 comments); [Botel HN story](https://news.ycombinator.com/item?id=50393793) (3 points, 3 comments); [Google Open Source](https://opensource.googleblog.com/2026/11/sandboxing-untrusted-ai-agents-at-scale.html))

**[++] Scoped identity and enforceable action boundaries** — The identity broker launch demonstrates one approach to revocable, scoped credentials, while the linked machine-deletion report and scrutiny of AegisKernel show that users want clear controls and evidence of enforcement. The incident is unverified and the broker's use case is still being clarified, so the demand signal is real but not yet broad or quantified. ([Agentic Identity Broker HN story](https://news.ycombinator.com/item?id=50393235) (18 points, 3 comments); [linked incident HN story](https://news.ycombinator.com/item?id=50395939) (5 points, 9 comments); [AegisKernel HN story](https://news.ycombinator.com/item?id=50394991) (10 points, 3 comments))

**[+] Evidence-first and domain-specific agents** — TinyResearch describes tying claims to live sources and checking unanswered parts; LDraw Mecha demonstrates a narrow path from structured model data to an animation. Both are builder examples, not evidence of market size, but they point to workflows where explicit intermediate artifacts can make agent output easier to inspect. ([TinyResearch HN story](https://news.ycombinator.com/item?id=50389479) (19 points, 0 comments); [LDraw Mecha HN story](https://news.ycombinator.com/item?id=50397325) (15 points, 0 comments))

## 8. Takeaways

1. **Agent products are moving toward ongoing task ownership.** Perplexity's Teammates launch led the day's discussion, with ongoing monitoring and review positioned alongside multi-agent coordination. ([HN story](https://news.ycombinator.com/item?id=50395866) (57 points, 49 comments))
2. **Runtime lifecycle and cost remain practical design questions.** An Ask HN author asks how to run work overnight affordably, and Botel's builder says detecting when jobs can pause is still difficult. ([Ask HN](https://news.ycombinator.com/item?id=50391647) (4 points, 3 comments); [Botel HN story](https://news.ycombinator.com/item?id=50393793) (3 points, 3 comments))
3. **Credential delegation and machine isolation are distinct parts of agent control.** The Agentic Identity Broker focuses on scoped access, while Google's Agent Substrate announcement focuses on isolated execution; user comments raise questions about use cases and sandbox confidence. ([AIB HN story](https://news.ycombinator.com/item?id=50393235) (18 points, 3 comments); [Google Open Source announcement](https://opensource.googleblog.com/2026/11/sandboxing-untrusted-ai-agents-at-scale.html); [linked incident HN story](https://news.ycombinator.com/item?id=50395939) (5 points, 9 comments))
4. **AI-assisted building appears in both infrastructure work and personal computing.** LDraw Mecha applies agents to a structured CAD-like model-to-animation workflow, while one Ask HN author describes building household utilities and hardware integrations. These are concrete examples, not prevalence estimates. ([LDraw Mecha HN story](https://news.ycombinator.com/item?id=50397325) (15 points, 0 comments); [Home-cooked software HN story](https://news.ycombinator.com/item?id=50391446) (3 points, 3 comments))
