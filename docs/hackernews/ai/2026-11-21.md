# HackerNews AI - 2026-11-21

## 1. What People Are Talking About

### 1.1 An AI coding agent runs on an original IBM PC XT (↑)

The day's standout submission was ClawDOS, a coding agent harness running on an IBM PC XT with an 8088 at 4.77 MHz, 640 KB of RAM, and CGA graphics. It connects to Claude through a separate TLS bridge, then reads and edits files, runs DOS programs, and keeps notes between conversations. Its 18 tools also include delete and low-level memory and port access; the author says safe mode asks before changes. One example took 64 seconds from prompt to answer, including 26 seconds to compile, link, and run. This is a working hardware demonstration, not a comparative benchmark. ([project](http://ricapar.net/ClawDOS/); [HN discussion](https://news.ycombinator.com/item?id=50586292)) (151 points, 47 comments)

![ClawDOS searches its compiler guide, writes PRIMES.C, compiles it with Turbo C, and prints the primes below 100](http://ricapar.net/ClawDOS/docs/images/coding.png)

![ClawDOS displays the agent's search, read, and edit tool calls while changing a DOS program](http://ricapar.net/ClawDOS/docs/images/agent-at-work.png)

**Discussion insight:** [linzhangrun](https://news.ycombinator.com/user?id=linzhangrun) (score 0) wanted agents for debugging existing Windows XP and Windows 7 devices, rather than developing for them. [Yashsarwaiya](https://news.ycombinator.com/user?id=Yashsarwaiya) (score 0) asked what stops an agent from running an irreversible delete.

**Comparison to prior day:** On November 20, an author reported using coding agents to improve FPGA inference throughput from 6 to 213 tokens per second. ClawDOS shifts the demonstration from using agents to build hardware software to running the agent harness itself on legacy hardware; both are individual projects, not independent benchmarks. ([FPGA experiment](https://ankitg.me/blog/vibecoding-inference-chip/); [HN discussion](https://news.ycombinator.com/item?id=50579297)) (78 points, 24 comments)

### 1.2 Agent evaluation measures side effects and task correctness (→)

Several tools and evaluations focus on what agents do, not just whether they return an answer. ClawVet scans agent skills and compares permission changes; its authors report that 40.2% of 209 scanned skills read undeclared secret environment variables, a project-authored finding. ([ClawVet](https://clawvet.vercel.app/); [Show HN](https://news.ycombinator.com/item?id=50587571)) (7 points, 1 comment) Pantry describes a local scanner for vulnerabilities that actually apply to installed software and repositories. ([Pantry](https://waffuru.ai/products/pantry); [Show HN](https://news.ycombinator.com/item?id=50586748)) (4 points, 1 comment); [second Show HN](https://news.ycombinator.com/item?id=50593848) (3 points, 0 comments)

RMRFBench evaluates whether a disposable server survives routine file-operation tasks, rather than ranking task completion alone; its site cautions that the scenario set is small and does not model product-level guardrails. ([RMRFBench](https://www.rmrfbench.com/); [Show HN](https://news.ycombinator.com/item?id=50587178)) (4 points, 1 comment) Stripe reports that its agent plugin raised average scores across 14 model and harness combinations on 69 payment scenarios, but the average fell from 78.1% to 29.4% when every required criterion had to pass. ([Stripe evals](https://stripe.dev/blog/stripe-integration-evals-methodology); [HN discussion](https://news.ycombinator.com/item?id=50589196)) (4 points, 0 comments)

The limits of additional search also appeared: agent-mcts' small benchmark on two tasks found that Monte Carlo tree search did not consistently improve on a coding agent's first attempt, and its judging mode cost about five times as many episodes and wall-clock time. ([agent-mcts benchmark](https://github.com/natsu0529/agent-mcts); [Show HN](https://news.ycombinator.com/item?id=50589235)) (8 points, 0 comments)

A separate transparency concern came from a public issue reporting that a hosted MCP response included a product-feedback request that the agent was told not to disclose. The reporter says their agent declined and told them; the HN story received 4 points and no comments. ([GitHub issue](https://github.com/runpod/runpod-mcp/issues/202); [HN discussion](https://news.ycombinator.com/item?id=50589793)) (4 points, 0 comments)

## 2. What Frustrates People

### Agent actions can have irreversible side effects

**Severity: High for destructive operations; prevalence is not established.** ClawDOS exposes file changes and deletes as agent tools, and its author says safe mode asks before file, memory, or port changes. A commenter still asked what prevents an irreversible delete. RMRFBench similarly focuses on server integrity during routine file tasks, but describes a small test suite rather than a measured rate of real-world incidents. This supports a case for explicit approval and outcome checks, not a claim that agents commonly destroy data. ([ClawDOS](http://ricapar.net/ClawDOS/); [HN discussion](https://news.ycombinator.com/item?id=50586292)) (151 points, 47 comments); [RMRFBench methodology](https://www.rmrfbench.com/); [HN discussion](https://news.ycombinator.com/item?id=50587178) (4 points, 1 comment)

### Agent skills can access undeclared secrets

**Severity: High if the scanned behavior is present; evidence is from one project-authored scan.** ClawVet's launch report says 84 of 209 scanned skills read secret-named environment variables without declaring them, and 10 touched host credential stores. These are static-analysis findings, not evidence that the credentials were exfiltrated. Pantry offers a local scan of installed software and repositories, but its product page notes that Windows machine-wide checks are limited. Permission review and local scanning address concrete risks, though the reports do not establish adoption or false-negative rates across the market. ([ClawVet launch report](https://github.com/MohibShaikh/clawvet/blob/master/docs/launch-report-2026.md); [Show HN](https://news.ycombinator.com/item?id=50587571)) (7 points, 1 comment); [Pantry](https://waffuru.ai/products/pantry); [Show HN](https://news.ycombinator.com/item?id=50586748) (4 points, 1 comment); [second Pantry submission](https://news.ycombinator.com/item?id=50593848) (3 points, 0 comments)

### Tool instructions can conflict with user transparency

**Severity: Medium for user trust; evidence is one open issue.** A user report says RunPod's hosted MCP server appended a product-feedback request to successful tool results and instructed agents not to disclose it. The issue's author says the behavior was deliberate and asks for visible or opt-in feedback; this remains a single report, not evidence of broader practice across MCP servers. ([GitHub issue](https://github.com/runpod/runpod-mcp/issues/202); [HN discussion](https://news.ycombinator.com/item?id=50589793)) (4 points, 0 comments)

### Average agent scores can hide incomplete work

**Severity: Medium for integration work; measured in vendor-run evaluations.** Stripe says its average score across evaluated agents fell from 78.1% to 29.4% when a passing result required every criterion to succeed. Its plugin improved average scores across all 14 model and harness pairs, but the strict pass rate shows that partial credit can obscure missing requirements. Separately, agent-mcts reports that tree search did not consistently improve results on two small tasks. Both findings point to evaluation quality as an active limitation, not a broad user complaint. ([Stripe evals](https://stripe.dev/blog/stripe-integration-evals-methodology); [HN discussion](https://news.ycombinator.com/item?id=50589196)) (4 points, 0 comments); [agent-mcts benchmark](https://github.com/natsu0529/agent-mcts); [Show HN](https://news.ycombinator.com/item?id=50589235) (8 points, 0 comments)

### AI-generated resumes may carry hidden markers

**Severity: Low-confidence, with limited evidence.** The creator of an online cleaner says files produced by more than 40 AI models carried hidden markers and offers to remove them. One commenter instead said they reject resumes based on obviously AI-generated prose, whether or not a marker is present. The post does not independently establish that applicant tracking systems broadly use these markers, so the cleaner may not address the reviewer's stated concern. ([Unmark](https://unmark.grandimam.com/); [Show HN](https://news.ycombinator.com/item?id=50587783)) (5 points, 3 comments)

## 6. New and Notable

### A hosted MCP response reportedly asked an agent to hide a product survey

A public issue reports that RunPod's hosted MCP server appended a product-feedback request to successful tool results and told the agent not to disclose it. The reporter says the behavior was deliberate and that their agent declined and told them; the open issue asks for a visible or opt-in survey. This is one user's report, but it illustrates why agent-facing tool output should not silently override user expectations. ([GitHub issue](https://github.com/runpod/runpod-mcp/issues/202); [HN discussion](https://news.ycombinator.com/item?id=50589793)) (4 points, 0 comments)

### Search-based coding agents need stronger evaluators

The agent-mcts README reports mixed outcomes on two tasks: tests-only tree search matched the initial answer in 9 of 10 runs and was worse in one, while adding a judge produced 4 better, 4 unchanged, and 2 worse results. The judge also used about five times the episodes and wall time. These are small, project-run measurements, but they make the cost and answer-selection problem visible rather than assuming that more agent exploration improves code. ([Benchmark report](https://github.com/natsu0529/agent-mcts); [Show HN](https://news.ycombinator.com/item?id=50589235)) (8 points, 0 comments)

### Agentic commerce is framed by levels of delegated control

One article describes a progression from agent-led product discovery to assisted purchases, condition-based buying, and multi-step transaction orchestration. ## 7. Where the Opportunities Are

**[++] Transparent permissions and safeguards for agent actions** - ClawDOS exposes mutable tools but uses confirmation in safe mode; ClawVet audits skill permissions; Pantry scans local software; and RMRFBench measures environment integrity. The RunPod issue adds a separate user-transparency concern about instructions in tool results. The signals span several projects, but most HN threads had low engagement and the reported scanner findings are not independent audits. ([ClawDOS](http://ricapar.net/ClawDOS/); [ClawVet](https://clawvet.vercel.app/); [Pantry](https://waffuru.ai/products/pantry); [RMRFBench](https://www.rmrfbench.com/); [RunPod issue](https://github.com/runpod/runpod-mcp/issues/202))

**[++] Evaluation that checks complete outcomes, not partial scores** - Stripe's average strict pass rate fell from 78.1% to 29.4% when every criterion had to pass, while agent-mcts' small trials did not show consistent gains from additional search. RMRFBench applies the same outcome-first question to server integrity. The evidence supports a need for more discriminating evaluation, though it comes from vendor or project-run benchmarks with limited scenarios. ([Stripe evals](https://stripe.dev/blog/stripe-integration-evals-methodology); [agent-mcts](https://github.com/natsu0529/agent-mcts); [RMRFBench](https://www.rmrfbench.com/))

**[+] Local and deliberately bounded AI workflows** - WebBrain keeps browser processing local, Musset limits AI to editorial feedback, and Klistra emphasizes precise, repeatable changes. These products address different tasks, and the HN discussions do not establish whether users will pay for or adopt these approaches at scale. ([WebBrain](https://blog.mozilla.org/addons/2026/11/20/developer-spotlight-webbrain/); [Musset](https://github.com/Musset-App/musset); [Klistra](https://klistra.ai/))

**[+] Agent support for legacy systems** - ClawDOS demonstrates one agent on DOS, and a commenter asks for agents to debug existing Windows XP and Windows 7 devices. The product and request do not yet establish demand beyond enthusiasts and maintainers of older systems. ([ClawDOS](http://ricapar.net/ClawDOS/); [HN discussion](https://news.ycombinator.com/item?id=50586292)) (151 points, 47 comments)

## 8. Takeaways

1. **The day's clearest signal was a working agent on legacy hardware.** ClawDOS runs a coding workflow on an 8088-based DOS machine, with confirmation before file, memory, or port changes; its discussion drew 151 points and 47 comments. ([Project](http://ricapar.net/ClawDOS/); [HN discussion](https://news.ycombinator.com/item?id=50586292)) (151 points, 47 comments)
2. **Trust now includes both what tools can access and what they tell agents to hide.** ClawVet's project-authored scan reports undeclared secret access in 84 of 209 skills, while a public issue reports concealed survey instructions in a hosted MCP result. ([ClawVet report](https://github.com/MohibShaikh/clawvet/blob/master/docs/launch-report-2026.md); [RunPod issue](https://github.com/runpod/runpod-mcp/issues/202); [HN](https://news.ycombinator.com/item?id=50589793)) (4 points, 0 comments)
3. **Partial scores can overstate reliable completion.** Stripe reports an average strict pass rate of 29.4%, down from an average score of 78.1% when incomplete results receive partial credit. ([Stripe evals](https://stripe.dev/blog/stripe-integration-evals-methodology); [HN](https://news.ycombinator.com/item?id=50589196)) (4 points, 0 comments)
4. **More search is not automatically better.** In agent-mcts' small trials, the judge improved 4 of 10 answers, left 4 unchanged, and worsened 2, at roughly five times the episodes and wall time. ([Benchmark report](https://github.com/natsu0529/agent-mcts); [HN](https://news.ycombinator.com/item?id=50589235)) (8 points, 0 comments)
5. **Explicit demand for legacy-system agents is still anecdotal.** One commenter asked for debugging help on Windows XP and Windows 7 devices; the high ClawDOS thread score does not establish a broader need. ([HN discussion](https://news.ycombinator.com/item?id=50586292)) (151 points, 47 comments)
