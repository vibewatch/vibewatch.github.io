### 1.2 Builders are making agent decisions and results easier to inspect (→)

Several submissions address the gap between an agent's claim of completion and a person being able to inspect what it decided or changed. MarginCue previews how Claude Code or Codex interprets a prompt and lets the user change open choices before execution. A commenter who tried it said it exposed omissions in their own prompts. ([fus3r](https://news.ycombinator.com/user?id=fus3r)'s [MarginCue post](https://news.ycombinator.com/item?id=50641783) (3 points, 5 comments); [repository](https://github.com/fus3r/margincue))

A separate held-out-test experiment reports that, across seven tasks and 105 runs, agents working from loose tickets passed their own generated tests in every run, but an independent hidden suite rejected 75 runs. The author says the sample is small and repeated runs on the same task are not independent. ([charliercrvta](https://news.ycombinator.com/user?id=charliercrvta)'s [HN post](https://news.ycombinator.com/item?id=50642317) (2 points, 0 comments); [experiment and results](https://lunox.work/articles/coding-agents-held-out-tests))

Other low-engagement builder posts target specific parts of this control loop: Sightline captures Windows UI state for agents; Belay proposes semantic diffs and receipts for system changes; Pontia offers remote, encrypted access to local coding agents. Their posts drew 4, 2, and 2 points respectively, so they show experiments rather than broad adoption. ([lwh-x](https://news.ycombinator.com/user?id=lwh-x)'s [Sightline post](https://news.ycombinator.com/item?id=50639090) (4 points, 0 comments); [allexsendev](https://news.ycombinator.com/user?id=allexsendev)'s [Belay post](https://news.ycombinator.com/item?id=50641716) (2 points, 0 comments); [ocherry6622](https://news.ycombinator.com/user?id=ocherry6622)'s [Pontia post](https://news.ycombinator.com/item?id=50642794) (2 points, 0 comments))

**Comparison to prior day:** Verification was already a visible concern on November 24, when Protocolis's browser-agent results drew questions about what its “verified” label guarantees. This day's posts carry the same concern into prompt interpretation, hidden tests, and audit trails. ([Protocolis discussion](https://news.ycombinator.com/item?id=50632998) (31 points, 9 comments))

### 1.3 Debate continues over whether generated code is becoming useful software (→)

An Ask HN post asks where the “amazing AI-generated software” is, arguing that easy code generation has produced many proof-of-concept projects whose results are barely usable. Replies point to switching costs and quality gaps, while one commenter describes a small local browser-based tool they use daily. This is a debate about adoption and software quality, not a measure of how common useful AI-built products are. ([8bitbeep](https://news.ycombinator.com/user?id=8bitbeep)'s [Ask HN thread](https://news.ycombinator.com/item?id=50643767) (4 points, 8 comments); [Lithuanian](https://news.ycombinator.com/user?id=Lithuanian) (score 0))

An Evil Martians analysis tests the claim that static types improve agent coding: its authors report roughly tied results for typed and dynamic languages in selected benchmarks, and no solve-rate improvement from Sorbet or RBS in their Rails runs. These are bounded, author-run experiments. In contrast, a practitioner essay describes an internal orchestrator running 2–100+ Claude agents and argues for task delegation; its author discloses advising a fund with a large reported Anthropic stake. ([Evil Martians analysis](https://evilmartians.com/chronicles/type-errors-cost-our-coding-agents-under-one-percent-of-their-time); [ksec's HN post](https://news.ycombinator.com/item?id=50638556) (5 points, 0 comments); [akalin's HN post](https://news.ycombinator.com/item?id=50645541) (4 points, 0 comments); [multiagent coding essay](https://www.kalzumeus.com/2026/11/25/multiagent-coding-is-the-future/))

## 2. What Frustrates People

### Agent-reported success can diverge from independently checked behavior

**Severity: Medium; prevalence is not measured.** The held-out-test author reports 75 failures among 105 runs on loose tickets even though every run's own tests were green. The experiment suggests that vague requirements and self-authored tests can mask missed behavior; it covers seven tasks and is not a population-wide failure rate. The author’s workaround is a separate hidden acceptance suite. ([held-out test experiment](https://lunox.work/articles/coding-agents-held-out-tests); [HN post](https://news.ycombinator.com/item?id=50642317) (2 points, 0 comments))

One Show HN author also said their coding agent repeatedly claimed completion on images it had not inspected. The linked project generates promotional images from an app's real UI, but its repository does not establish a general visual-validation solution. **Severity: Medium for image-heavy work; prevalence is unknown.** ([oabdiraimov](https://news.ycombinator.com/user?id=oabdiraimov)'s [HN post](https://news.ycombinator.com/item?id=50640365) (3 points, 0 comments); [linked skill](https://github.com/abdiraimov-otabek/claude-code-og-image-skill))

### Generated prototypes may not replace mature software

**Severity: Medium for builders seeking adoption; prevalence is not measured.** The Ask HN author worries that easier code generation yields more one-off proofs of concept than durable products. A commenter attributes slow adoption to switching costs and tools that are not good enough to replace existing alternatives. These are participant observations from one discussion, not a market-wide finding. ([8bitbeep](https://news.ycombinator.com/user?id=8bitbeep)'s [Ask HN thread](https://news.ycombinator.com/item?id=50643767) (4 points, 8 comments); [Lithuanian](https://news.ycombinator.com/user?id=Lithuanian) (score 0))

**Worth building for:** The day contains several attempts to make agent behavior easier to inspect, but little evidence that any single product has broad adoption. Independent acceptance checks, prompt previews, and auditable changes are practical directions; this dataset does not establish demand size.

## 3. What People Wish Existed

### Acceptance checks that do not rely on the agent's own tests

The held-out-test experiment shows why a user might want an independent check: in the author's loose-ticket runs, all agent-written tests passed while 75 of 105 runs failed the hidden suite. The practical need is a reviewable acceptance test tied to the intended behavior, not simply a green test report. **Urgency: Medium. Opportunity: direct, but early; evidence is one author's small study.** ([experiment](https://lunox.work/articles/coding-agents-held-out-tests))

### A chance to correct an agent's interpretation before it acts

MarginCue's maker says agents often resolve choices that a prompt leaves open, with users discovering the interpretation later in a diff. The tool previews those choices before execution, and one tester said it helped expose missing details in their prompts. **Urgency: Medium for coding workflows. Opportunity: competitive; a concrete tool exists, but this thread does not measure broader demand.** ([MarginCue HN discussion](https://news.ycombinator.com/item?id=50641783) (3 points, 5 comments); [repository](https://github.com/fus3r/margincue))

### Permissioned use of private data and consequential actions

NPR describes shopping agents that may read inboxes or use payment information, while California's Attorney General raised concerns about a proposed sale of Character.AI chat histories and associated account data. Together these reports point to a practical requirement for narrow permissions, clear user approvals, and understandable data-retention and transfer policies. They do not show a direct request from HN users for a specific product. **Urgency: High when private data or money is involved. Opportunity: competitive and unvalidated by this day's HN engagement.** ([NPR on shopping agents](https://www.npr.org/2026/11/25/nx-s1-6048524/what-to-know-before-using-ai-agents-for-black-friday-shopping); [California Attorney General release](https://oag.ca.gov/news/press-releases/attorney-general-bonta-opposes-asset-sale-characterai-amid-child-safety-concerns); [Character.AI HN post](https://news.ycombinator.com/item?id=50641464) (8 points, 0 comments))

## 6. New and Notable

### A proposed Character.AI asset sale raises questions about private chat data

California's Attorney General says a proposed auction would include chat histories and account data, including IP addresses, for more than 21 million U.S. accounts, over 2.1 million registered to minors. The state opposes the proposed sale and says the buyer may not be bound by existing privacy policies; this is a dispute over a proposed transaction, not a completed sale. ([California Attorney General release](https://oag.ca.gov/news/press-releases/attorney-general-bonta-opposes-asset-sale-characterai-amid-child-safety-concerns); [HN post](https://news.ycombinator.com/item?id=50641464) (8 points, 0 comments))

### Amazon reports agent-enabled exploitation of a zero-day

Ars Technica reports Amazon's account that agents running on the Cairn framework found and exploited a vulnerability after receiving a broad goal. The article also cites Palo Alto Networks' report of autonomous operations against multiple organizations. The report illustrates dual-use concerns but does not establish how often such operations succeed. ([Ars Technica](https://arstechnica.com/security/2026/11/amazon-says-hackers-ai-agents-found-and-exploited-0-day-with-little-human-input/); [HN post](https://news.ycombinator.com/item?id=50642880) (4 points, 1 comment))

### Google sets a future MCP requirement for Workspace agent access

Google announced managed Workspace MCP servers and a CLI with admin controls, audit logs, and confirmations. The company says agent access will need to use MCP rather than direct Workspace REST APIs beginning February 1, 2027, with scaled-tier usage charges starting April 1, 2027. ([Google announcement](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html); [HN post](https://news.ycombinator.com/item?id=50637725) (3 points, 2 comments))

### AI shopping agents put convenience beside privacy and reliability concerns

NPR cites a National Retail Federation survey saying 59% of U.S. shoppers planned to use AI for holiday shopping, and describes agents that can track orders or purchase goods while warning about mistakes and sensitive inbox or payment access. This is a cited survey and an article's account, not a measure of adoption among HN users. ([NPR report](https://www.npr.org/2026/11/25/nx-s1-6048524/what-to-know-before-using-ai-agents-for-black-friday-shopping); [HN post](https://news.ycombinator.com/item?id=50646548) (3 points, 0 comments))

## 7. Where the Opportunities Are

**[+++] Verifiable agent changes and independent acceptance checks** — The held-out-test experiment found self-written tests passing even when an independent suite rejected many loose-ticket runs; MarginCue, Belay, Sightline, and Pontia each address a different part of visibility or control. This is the clearest repeated builder pattern, though low HN engagement and early product stages do not establish market demand. ([test experiment](https://lunox.work/articles/coding-agents-held-out-tests); [MarginCue](https://news.ycombinator.com/item?id=50641783) (3 points, 5 comments); [Belay](https://news.ycombinator.com/item?id=50641716) (2 points, 0 comments))

**[++] Permission boundaries for agents handling sensitive data or actions** — Shopping workflows may require inbox and payment access; the Character.AI proposed sale highlights the sensitivity of stored conversations; Google is formalizing controlled Workspace access through MCP. Products that make access narrow and approvals understandable could address these concerns, but this day's HN data does not show specific demand for a winning approach. ([NPR report](https://www.npr.org/2026/11/25/nx-s1-6048524/what-to-know-before-using-ai-agents-for-black-friday-shopping); [California Attorney General release](https://oag.ca.gov/news/press-releases/attorney-general-bonta-opposes-asset-sale-characterai-amid-child-safety-concerns); [Google announcement](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html))

**[+] Turning generated code into software people keep using** — The Ask HN thread identifies usability and switching costs as barriers, while builders are launching narrow tools around specific workflows. The signal is worth watching, but this single discussion and low-vote launches cannot establish a broad product gap. ([Ask HN](https://news.ycombinator.com/item?id=50643767) (4 points, 8 comments); [Avva](https://news.ycombinator.com/item?id=50641710) (4 points, 4 comments))
