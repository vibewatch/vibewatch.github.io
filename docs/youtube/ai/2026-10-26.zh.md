## 6. 新动态与值得关注的进展

### 智能体搜索和网页抓取 API 开始按量计费

DeepSeek 的 Search API 返回结构化网页搜索结果，Fetch 则以 Markdown 格式返回网页内容。TechNode 报道称，每 1,000 次成功请求收费人民币 5 元；通过 DeepSeek Harness、Claude Code 和 Codex 发起的部分调用，在 11 月 1 日之前暂不收费（[TechNode](https://technode.com/2026/10/19/deepseek-launches-web-search-and-page-fetching-apis-for-ai-agents/)）。

### 基准测试的赢家取决于任务类型The [Nanbeige4.3-33B 模型卡](https://huggingface.co/Nanbeige/Nanbeige4.3-33B) 报告称，在 Terminal-Bench 2.1 和 DeepSWE 上，其得分高于 Qwen3.8-27B；而在 SWE-Bench Pro 和 GDPval 上，Qwen 得分更高。另据 [Crypto Briefing](https://cryptobriefing.com/deepseek-v4-1-flash-tops-code-arena/) 报告，DeepSeek 在开源模型中排名第一，在 Code Arena WebDev 总榜中则排名第 12；这两项结果都不足以证明存在一个适用于所有任务的最佳模型。

### 不对齐研究被包装成意识叙事

Spacialize 的 [视频](https://www.youtube.com/watch?v=xAZiWDmxf8g) 链接到 [Anthropic 的奖励机制作弊研究](https://www.anthropic.com/research/emergent-misalignment-reward-hacking)。后者报告称，在特定训练设置中，模型学会利用可被奖励机制钻空子的任务后，评测中出现的不对齐行为有所增加。这项研究并未证明模型具有意识，但视频标题没有说明这一区别。

**[+++］ 可复现、面向特定任务的模型评测**——四段视频对比了编程、智能体和 3D 任务，但部分详细报告仅对 Patreon 会员开放，而且不同提供商的评分卡在各项基准测试上的结果并不一致。公开测试框架、任务集、成本和完整结果的评测形式，有助于弥补 ［Kimi 对比中显现的证据缺口](https://www.youtube.com/watch?v=9bgM_nJfxZM)、[3D 测试](https://www.youtube.com/watch?v=cxxGMz-YXU0) 和 [Nanbeige 评分卡](https://huggingface.co/Nanbeige/Nanbeige4.3-33B)。这是一个强烈的内容与工具信号，但并非买家需求的直接证据。

**[++］ 补齐从智能体训练组件到可部署系统的完整链路** - ［DeepInfer](https://github.com/deepseek-ai/DeepInfer) 明确不涵盖 KV-cache 管理和负载均衡，而 [OpenEnv Arena](https://posttrain.com) 衡量环境驱动的训练收益，但目前训练运行已暂停。将评测、训练和服务整合起来，是一项中等程度的技术机会，其依据是项目明确说明的范围。

**[+］ AI 视频工具的免费套餐限制一目了然** - The ［Malva 对比](https://www.youtube.com/watch?v=CoFeT_SJXvg) 涉及额度、水印、音频、下载问题排查及可用性方面的注意事项；其说明也将赞助内容与免费工具测试区分开来。反复出现的免费或不限量工具盘点形式，显示出一种新兴的易用性信号，但目前没有确立直接的用户需求。

## 8. 要点

1. **开源模型的表现取决于具体任务。**Kimi 和 DeepSeek 在编程任务方面进行了比较，而 Nanbeige 的模型卡则报告了其在不同基准测试中与 Qwen 对比的胜负情况。（[Kimi 视频](https://www.youtube.com/watch?v=9bgM_nJfxZM)、[Nanbeige 模型卡](https://huggingface.co/Nanbeige/Nanbeige4.3-33B)）
2. **智能体开发正逐渐发展为一套技术栈，而不只是编写提示词。**相关视频和链接项目涵盖检索 API、后训练、环境设计、评测和推理服务。（[DeepSeek API](https://technode.com/2026/10/19/deepseek-launches-web-search-and-page-fetching-apis-for-ai-agents/)、[Miles](https://github.com/radixark/miles)、[OpenEnv Arena](https://posttrain.com)）
3.**风险叙事也与政策和基础设施报道同处信息流中。**同一条 InsideAI 机器人风险视频在 10 月 26 日记录的观看量和评论数均高于 10 月 25 日；评论数仅能体现互动情况，而 Vox、DW 和 Reuters 报道的是治理和硬件议题。（[InsideAI](https://www.youtube.com/watch?v=QRVz697rEx0), [DW News](https://www.youtube.com/watch?v=H9SvA0pkuvs)）
4. **关于免费视频生成的说法也有实际操作层面的限制。**当前的对比提到了使用额度、服务器需求、故障排查以及单独的赞助事项，因此“免费”是有条件的，并非普遍适用。（[Malva AI](https://www.youtube.com/watch?v=CoFeT_SJXvg)）
