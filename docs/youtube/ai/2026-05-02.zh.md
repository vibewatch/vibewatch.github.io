## 2. 什么让人感到沮丧

### 人形机器人炒作超前于实际部署

Bloomberg 的纪录片（21.7 万次观看、250 条评论）揭示了核心挫败感：企业推出令人印象深刻的演示，吸引数十亿美元投资，但由于训练数据稀缺以及非结构化环境复杂，机器人在现实工厂中的部署仍然十分有限。Figure 总部参观视频（7.5 万次观看、457 条评论）提供了部分反例——展示了真实的制造基础设施——但参观工厂与大规模交付机器人之间的差距，仍是核心张力所在（[人形机器人：炒作与现实之间的鸿沟](https://www.youtube.com/watch?v=UQZooauU-FQ)）。严重程度：中等——主要是投资者和行业关切，但在主流受众中的可见度正在提升。

### 推理复杂性被低估

Caleb Writes Code 的视频（11.8 万次观看、4,826 个赞）回应了一个具体痛点：训练模型与高效提供模型服务之间存在巨大差距。大量量化格式（GGUF、AWQ、EXL2、FP8、NVFP4）和推理引擎（llama.cpp、vLLM、SGLang、TensorRT-LLM、TGI）造成了碎片化格局，从业者必须在速度、质量和内存之间做复杂权衡，却缺乏清晰指导（[为什么推理很难……](https://www.youtube.com/watch?v=B18zBnjZKmc)）。严重程度：对从业者而言较高——4,826 个赞（点赞率 4.1%）表明这一问题引发了强烈共鸣。

### AI 图像生成的改进已难以继续吸引注意力

两支 GPT Image 2.0 评测视频累计获得 23.9 万次观看，但日增长率低于 1%。这表明图像生成评测已基本满足当前受众需求：最初的兴奋感已经消退，观众正在等待下一次能力跃升，而不是继续观看对同一版本的更多评测。严重程度：低。

## 3. 人们希望有什么

### 推理引擎选择方面的清晰指导

Caleb 的视频介绍了五种推理引擎和六种量化格式，但其背后的真实需求是一个决策框架：给定模型规模、硬件预算和延迟目标，从业者应该选择哪种引擎与量化组合？视频的高互动率（4,826 个赞）表明，从业者正在主动寻找这类指导（[为什么推理很难……](https://www.youtube.com/watch?v=B18zBnjZKmc)）。机会：直接——开发能够自动完成引擎/量化方案选择的工具或文档。

### 能够可靠在设备端运行的小模型

Labonne 的演讲描述了这样一种需求：模型体积小于 1GB，能遵循指令并调用工具，同时不会陷入“死循环”或出现能力相互干扰。当前方案需要多阶段后训练配方（SFT、偏好对齐、智能体 RL），大多数从业者都难以采用（[训练前沿小模型时我学到的一切](https://www.youtube.com/watch?v=fLUtUkqYHnQ)）。机会：竞争性——Liquid AI、Apple 等公司正在积极推进这一方向。

### 超越演示的人形机器人基准

Bloomberg 的纪录片和多支机器人发布视频共同凸显了一个愿望：建立针对现实环境中人形机器人能力的标准化、可复现基准。当前证据主要由宣传演示和北京半程马拉松等计时展示构成，两者都无法提供可靠的性能对比（[人形机器人：炒作与现实之间的鸿沟](https://www.youtube.com/watch?v=UQZooauU-FQ)）。机会：愿景型——需要行业协作。

| MCP | 智能体协议 | (+) | 跨厂商：IBM、Anthropic、Codex | 实现碎片化 |
| RAG / GraphRAG | 检索架构 | (+) | 通过上下文工程提升 AI 性能 | 实现质量参差不齐 |
| pi-0.7 | 机器人基础模型 | (+) | 具备组合泛化能力；可处理训练数据之外的任务 | 处于研究阶段；支持的机器人平台有限 |

推理工具领域的碎片化尤为明显：五种不同引擎和六种量化格式正在争夺从业者的关注，目前没有一种方案能在所有使用场景下明显胜出。在 AI 编程领域，Codex 和 Claude Code 正朝不同方向分化：Codex 走向通用智能体（设计、演示文稿、自动化），Claude 则走向基于 skill 的领域专业化（UGC 视频制作）。智能体协议层（MCP、RAG、GraphRAG）继续充当连接代码开发与企业智能体应用场景的纽带。

## 7. 机会在哪里

**[+++] 推理工具与决策框架**——Caleb 关于推理复杂性的视频获得 11.8 万次观看，加上五种引擎和六种量化格式构成的碎片化格局，清晰指出了一个缺口：从业者需要能够根据硬件、模型和延迟约束，推荐或自动选择引擎及量化方案的工具。4,826 个赞（点赞率 4.1%）证实了强劲需求。IBM 的上下文工程视频则提供了互补的基础设施信号。

**[+++] 人形机器人制造基础设施**——Bloomberg 的纪录片（21.7 万次观看，单日增加约 2.8 万次）、Figure 的工厂参观视频（7.6 万次观看、457 条评论）以及另外五支机器人视频，显示出持续的增长势头。机会不在于制造机器人本身，而在于配套基础设施：感知系统、训练数据管线、仿真环境和制造工具。

**[++] 高效小模型与递归架构**——Labonne 的 LFM2.5 配方和 Y Combinator 关于递归推理的报道都实现了显著增长（分别为 +26% 和 +76%）。帮助从业者训练、部署和优化低于 1B 参数模型的工具、服务和基础设施，正面向规模不断扩大且技术水平日益提高的受众。

**[++] 面向非代码创意工作的 AI 编程工具**——Riley Brown 的 Codex 课程（9.8 万次观看）展示了该工具在设计、演示文稿和社交媒体自动化方面的应用。Jason Lee 的 Claude UGC Skill 则展示了广告视频的自动化制作。趋势很明确：AI 编程工具正扩展到内容创作、营销和业务运营领域。让非开发者也能使用这些能力的平台仍有很大的成长空间。

**[+] AEO（AI Engine Optimization）**——Ahrefs 的课程（2,600 次观看，增加 281 次）继续将 AEO 定义为一门独立学科。虽然规模不大，但来源权威；随着 AI 搜索引擎成为主要的内容发现渠道，该领域也具备结构性增长动力。

## 8. 要点总结

1. **人形机器人是主导主题，推动力来自 Bloomberg 纪录片的快速增长和 Figure 前所未有的工厂参观。** Bloomberg 单日增加约 2.8 万次观看，达到 21.7 万次；Figure 总部参观视频则在一个拥有 3.95 万订阅者的频道上获得 457 条评论，是数据集中互动/订阅比最高的视频。叙事重点正从“炒作与现实的对照”转向展示真实的制造基础设施。（[人形机器人：炒作与现实之间的鸿沟](https://www.youtube.com/watch?v=UQZooauU-FQ)、[Figure 首次完整总部参观](https://www.youtube.com/watch?v=ch_UM_JJU9w)）

2. **推理基础设施首次成为独立的高互动主题。** Caleb Writes Code 关于量化格式和推理引擎的技术讲解获得 11.8 万次观看和 4,826 个赞，显示从业者强烈需要关于模型部署的指导，而不仅是模型训练指导。（[为什么推理很难……](https://www.youtube.com/watch?v=B18zBnjZKmc)）

3. **AI 编程叙事已从讨论后果转向展现能力。** 前一天的数据集聚焦 AI 编程对团队和就业的影响（Molist 25.2 万次观看，SimonDev 6.4 万次观看）。这些视频已退出本次数据集，取而代之的是展示 Codex 和 Claude 如何扩展至内容创作、营销自动化和 UGC 视频制作的实用教程。（[Codex 完整课程 2026](https://www.youtube.com/watch?v=KXIdYEdOPys)、[Claude + Seedance 2.0](https://www.youtube.com/watch?v=jQO9RAmy5lk)）

4. **小模型和递归扩展研究继续加速。** Y Combinator 的递归推理视频单日增长 76%（百分比增幅最高），Labonne 在 Liquid AI 的演讲增长 26%。两者都以具体证据挑战“大就是好”的范式，表明架构创新能够以少得多的算力释放新的能力。（[训练前沿小模型时我学到的一切](https://www.youtube.com/watch?v=fLUtUkqYHnQ)、[递归将成为 AI 的下一个规模化定律](https://www.youtube.com/watch?v=DGtUUMNYLcc)）
