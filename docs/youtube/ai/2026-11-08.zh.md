## 2. 令人困扰的问题

原始材料主要是演示和评论，而非用户亲自提交的求助报告。这些问题均由创作者提出；它们在观众中的普遍程度尚不明确。

### 编码智能体的上下文开销与令牌成本

**严重程度：中等（针对运行编码智能体的开发者）；普遍程度：未知。** Better Stack 的 [TokenEconomizer 演示](https://www.youtube.com/watch?v=P5QCrpdr9gU) 和 [研究论文](https://huggingface.co/papers/2610.22732) 描述了持续产生的成本：反复重新熟悉代码库、在上下文中纳入未用到的工具，以及陷入无效循环。提出的应对办法包括为特定代码库定制微技能、精简工具，并在陷入失败循环时介入。论文报告称，在其基准测试环境中可以节省成本，但样本并未表明这些做法已在生产环境中落地，也没有用户报告账单有所减少。

### 生成媒体免费套餐的可用性与再利用权利不确定

**严重程度：中等（针对比较工具的创作者）；普遍程度：未知。** Malva AI 的 [四款工具教程](https://www.youtube.com/watch?v=VIZlSgcknxA) 和 [九款工具排名](https://www.youtube.com/watch?v=aG5OgGFYYuw) 提醒用户，点数、模式、水印、地区可用性、商业使用权和条款都可能因工具而异或发生变化。两者都包含 Higgsfield 的赞助内容。另一位创作者声称，部分工具无需注册即可使用，或可无限使用，但简介中未提供服务提供商链接（[Becky the Ai Girl](https://www.youtube.com/watch?v=2RJsuf1Y1Cw)）。这反映出创作者指南存在不确定性，并非对投诉率的测量结果。

## 6. 最新动态与亮点

### 有研究支持的编程智能体成本控制

TokenEconomizer 论文报告称，在五种智能体-模型配置中，平均 token 成本降低了 18.4%–30.9%；在测试的编程任务中，任务成功情况与基线相当。作者还报告称，在全部 30 个代码仓库与配置的组合中，成本都有所降低。这些结果来自作者的基准测试研究，并不保证在生产环境中也能节省成本。（[论文](https://huggingface.co/papers/2610.22732), [代码仓库](https://github.com/microsoft/TokenEconomizer)）

### DeepSeek 检索 API 的计费方式另有特点

TechNode 报道称，DeepSeek Search and Fetch APIs 每 1,000 次成功请求收费 5 元人民币，并返回结构化搜索结果和 Markdown 格式的网页文本；请求失败、结果为空或超时均不收费。同一报道还称，通过 DeepSeek Harness、Claude Code 和 Codex 发起的某些服务端调用将于 2026 年 11 月 1 日开始计费。因此，截至本报告日期，报道中所说的免费期已经结束。（[TechNode](https://technode.com/2026/10/19/deepseek-launches-web-search-and-page-fetching-apis-for-ai-agents)）

### Kimi K3.1 Pro 发布大规模开放权重规格

Moonshot AI 的模型卡将 Kimi K3.1 Pro 描述为一款多模态开放权重模型，总参数量为 2.8 万亿，激活参数量为 1,040 亿，上下文窗口为 100 万 token。这些是发布方提供的规格；本概览不包含对模型质量或部署要求的独立比较。（[模型卡](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)）
