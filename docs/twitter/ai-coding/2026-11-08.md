# Twitter AI Coding - 2026-11-08

## 1. What People Are Talking About

### 1.1 Spec-first work and independent review 🡕

Several posts focused on Google’s Elephant-Goldfish Model (EGM), an open-source plugin that separates specification drafting from review. [@GoogleCloudTech](https://x.com/GoogleCloudTech) describes an “Elephant” that drafts a spec with project context and “Goldfish” reviewers that examine it with fresh context; a person approves the architectural trade-offs before implementation. ([post](https://x.com/GoogleCloudTech/status/2119203243054023129); 426 likes, 53 reposts, 22 replies, 9 quotes, 23,738 views, 342 bookmarks.) The [repository](https://github.com/google/elephant-goldfish-model) documents support across several coding-agent surfaces and cautions that review does not replace tests or human judgment.

[@johan_builds](https://x.com/johan_builds) shared a diagram of the three roles: context-holding spec author, fresh-context reviewers, and human approver. ([post](https://x.com/johan_builds/status/2119528808890134625); 1 like, 2 replies, 124 views.)

![Diagram showing the EGM workflow: the Elephant drafts a spec, fresh-context Goldfish reviewers examine it, and a person approves before code](https://pbs.twimg.com/media/HWoUGwQbMAAxLOh.jpg)

**Discussion insight:** A reply to the launch compared fresh-context review to Fagan-style inspection. A concrete limitation is recorded in [EGM issue #237](https://github.com/google/elephant-goldfish-model/issues/237): Codex and Antigravity can inject project instruction files into reviewers even when the parent conversation is excluded, making isolation host-dependent.

**Comparison to prior day:** November 7’s prominent posts covered access to existing browser sessions and local VM boundaries. Today’s EGM discussion moves the boundary earlier, to reviewing a design before code is written. ([@thdxr](https://x.com/thdxr), [test post](https://x.com/thdxr/status/2118878460391137310); 345 likes, 14 reposts, 38 replies, 2 quotes, 10,650 views, 114 bookmarks; [@RoundtableSpace](https://x.com/RoundtableSpace), [DevVM post](https://x.com/RoundtableSpace/status/2118874827683774478); 26 likes, 2 reposts, 24 replies, 48,708 views, 9 bookmarks.)

GitHub’s [release notes](https://github.blog/changelog/2026-10-28-github-copilot-app-universe-releases/) place computer use in public preview on Windows and macOS. ([post](https://x.com/FlowAltDelete/status/2119431746764816494); 32 likes, 2 replies, 1,583 views, 20 bookmarks.)

Antigravity’s [Remote Agents](https://antigravity.google/docs/remote-agents/) instead run in a Google-managed environment and can continue after the local device sleeps. The documentation limits availability to personal Google AI Pro and Ultra subscribers, excluding free, Plus, and business accounts. [@EvanRConroy](https://x.com/EvanRConroy) highlighted the rollout and plan restriction. ([post](https://x.com/EvanRConroy/status/2119401522094100931); 1 like, 72 views, 1 bookmark.)

**Discussion insight:** These are distinct forms of continuity: resuming an existing task in an IDE, controlling local desktop apps, and running work remotely. The latter two raise different permission and availability constraints.

**Comparison to prior day:** This extends the November 7 browser-access discussion from working inside an existing logged-in session to carrying work across applications or running it away from the local machine. ([@opencode](https://x.com/opencode), [Browse post](https://x.com/opencode/status/2118895128152621153); 183 likes, 12 reposts, 11 replies, 4 quotes, 4,272 views, 44 bookmarks.)

## 2. What Frustrates People

### Model access does not always match the subscription value

**Severity: High for the user reporting it; prevalence is unknown.** [@jan_volad](https://x.com/jan_volad) says a handful of Argon messages used the five-hour quota and a short Antigravity coding session used about one-third of the weekly allowance. The user valued bundled storage and other services but said they subscribed mainly for AI and would prefer Claude Pro’s model access and usage. This is a firsthand account, not a population-wide measure. ([post](https://x.com/jan_volad/status/2119513284399223188); 19 likes, 8 replies, 1,173 views, 1 bookmark.)

**Build relevance:** Clearer per-model meters, reset windows, and plan comparisons would address the specific uncertainty raised; the evidence supports a user pain point, not its prevalence.

### Cloud workspace data loss

**Severity: High in the incident described; prevalence is unverified.** [@jerry_ying42171](https://x.com/jerry_ying42171) says a Dot workspace was recreated with empty directories and that an 865 MB handoff was lost. The author also claims to have compiled 101 first-person reports, but that count and the reported lack of official recoveries are not independently established here. The post says affected users relied on their own GitHub, Drive, or library backups. ([post](https://x.com/jerry_ying42171/status/2119248875617677417); 11 replies, 1 quote, 68 views.)

**Build relevance:** The incident makes backup, snapshot retention, and a clear restore path concrete requirements for cloud workspaces, but one post cannot establish the rate of failure.

### Fresh-review context can still inherit host instructions

**Severity: Medium; the evidence is one open technical issue.** [EGM issue #237](https://github.com/google/elephant-goldfish-model/issues/237) reports Codex and Antigravity reviewers receiving project instruction files despite a fresh reviewer context. That matters specifically because EGM relies on reviewers not inheriting the drafting agent’s assumptions. The report is a concrete compatibility bug, not evidence that every review run is affected.

For people storing project work in a remote workspace, this is a practical and urgent need; the available evidence is one author’s report and does not establish prevalence. **Opportunity: Direct** for affected users, with independent confirmation still needed. ## 6. New and Notable

### Antigravity as a cheminformatics workbench

Google DeepMind’s case study describes a suite of Cheminformatics Skills for Antigravity that combines agent orchestration with RDKit calculations and ChEMBL and PubChem data. The authors report extracting and curating 568 compounds from papers and patents, exploring potency and molecular structure in an interactive viewer, and proposing candidate molecules with synthesis routes in an hour. This is a research case study, not a general coding benchmark or clinical validation. [@antigravity](https://x.com/antigravity) shared the workflow ([post](https://x.com/antigravity/status/2119490135049867264); 467 likes, 35 reposts, 34 replies, 7 quotes, 19,506 views, 98 bookmarks); [DeepMind’s article](https://deepmind.google/blog/agentic-cheminformatics-with-google-antigravity/) provides the methods and scope.

Together these examples point to review, approval, and recoverability as product requirements across agent surfaces, not just model quality. ## 8. Takeaways

1. **Review is moving earlier in the coding loop.** EGM puts specification review before implementation, but an open issue shows that “fresh context” can still inherit host instructions on some harnesses. ([EGM launch](https://x.com/GoogleCloudTech/status/2119203243054023129); 426 likes, 53 reposts, 22 replies, 9 quotes, 23,738 views, 342 bookmarks; [issue #237](https://github.com/google/elephant-goldfish-model/issues/237).)
2. **Continuity is becoming a product feature.** Copilot can carry an app session into VS Code, while computer use and Antigravity Remote Agents extend work to desktop apps and remote execution. ([Copilot handoff](https://x.com/github/status/2119529896296722931); 42 likes, 4 reposts, 16 replies, 11,693 views, 10 bookmarks; [computer-use post](https://x.com/FlowAltDelete/status/2119431746764816494); 32 likes, 2 replies, 1,583 views, 20 bookmarks; [Remote Agents post](https://x.com/EvanRConroy/status/2119401522094100931); 1 like, 72 views, 1 bookmark.)
3. **Usage predictability remains a practical constraint.** One user reports Argon exhaustion during light use, while another proposes a $50 middle tier and asks that Plus users also benefit. The tier is a request, not an announced plan. ([Argon report](https://x.com/jan_volad/status/2119513284399223188); 19 likes, 8 replies, 1,173 views, 1 bookmark; [plan proposal](https://x.com/codexresets_/status/2119329341058224507); 155 likes, 12 replies, 15,756 views; [Plus follow-up](https://x.com/codexresets_/status/2119416545054965951); 64 likes, 6 replies, 4,906 views.)
4. **Remote workspaces need visible recovery guarantees.** A user describes a serious Dot workspace loss and asks for snapshots and retention rules; the account’s broader incident count remains unverified. ([report](https://x.com/jerry_ying42171/status/2119248875617677417); 11 replies, 1 quote, 68 views.)
5. **The build pattern is shifting toward inspectable context and output.** Repository instructions, on-demand skills, knowledge graphs, and line-level diff review are concrete responses to team-specific conventions and opaque code changes. ([team-context demo](https://x.com/nisalrenuja/status/2119491264014135433); 8 likes, 4 replies, 247 views; [Understand Anything](https://x.com/balance0014/status/2119491500140880004); 5 likes, 1 repost, 6 replies, 237 views, 1 bookmark; [Universal Agent Diff](https://x.com/MatthewSessa/status/2119191262628655569); 3 likes, 7 replies, 1 quote, 108 views.)
