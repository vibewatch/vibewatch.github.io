# Twitter AI 编程 - 2026-10-28

## 1. 大家在讨论什么

### 1.1 基准表现领先，同时也在比较成本 🡕

[@ArtificialAnlys](https://x.com/ArtificialAnlys) [据报道](https://x.com/ArtificialAnlys/status/2115494553780367384)（2,317 个赞，108 条回复，104,866 次浏览，219 次收藏）Gemini 4 Carbon 在 Intelligence Index v5 和 Coding Agent Index（编程智能体指数）上的得分均为 59，比 Claude Code 的 62 分低 3 分。发布者称，目前仅向部分用户开放，并在后续回复中报告了单项任务的成本。

![Artificial Analysis 对比智能指数和编码代理指数模型得分的图表](https://pbs.twimg.com/media/HVu8EbubkAA3w5b.jpg)

### 1.2 对可靠性的抱怨涉及响应延迟和账号处置 🡕

[@alwayspriyesh](https://x.com/alwayspriyesh) [据报道](https://x.com/alwayspriyesh/status/2115364939066175569)（74 个赞，32 条回复，3,839 次浏览）有用户称，Gemini 3.8 Flash 在 Antigravity 中响应缓慢，还会遭遇限流；回复中另一位用户也反映，简单提示词也会出现延迟。另有一则较早的政策警告事件：[@ArtemR](https://x.com/ArtemR) [更新](https://x.com/ArtemR/status/2115520088178880991)（175 个赞，17 条回复，10,741 次浏览，31 次收藏）作者称，与防御性研究相关的账号违规记录在 Antigravity 员工介入后被撤销，但通知发得迟，内容也含糊不清。

### 1.3 跨会话上下文正成为产品功能 🡕

[@RoundtableSpace](https://x.com/RoundtableSpace) [描述](https://x.com/RoundtableSpace/status/2115371744688996845)（33 个赞，18 条回复，34,889 次浏览）agentlog 是一款命令行工具，可搜索 Claude Code、Codex 和 Copilot CLI 的会话日志。作者提醒，范围较广的搜索可能消耗大量 token，日志中也可能包含敏感信息；一条回复则认为，与其搜索原始对话记录，不如使用简洁的交接笔记。

**与前一天相比：** 10 月 27 日的讨论集中在插件、规范和专注于代码审查的工具上。今天的焦点则转向模型排名的依据，以及延迟、限流和政策申诉带来的实际使用摩擦。

## 2. 用户感到不满的地方

### 编程环境中的延迟和限流

一位用户称，Gemini 3.8 Flash 在 Antigravity 中变慢了，还经常卡在思考状态；回复中另一位用户也反映，简单提示词也会出现延迟。这条讨论规模不大，但反映出确实存在、尚未量化的可靠性问题。[@alwayspriyesh](https://x.com/alwayspriyesh) [据报道](https://x.com/alwayspriyesh/status/2115364939066175569)（74 个赞，32 条回复，3,839 次浏览）。

### 含糊的政策通知让用户对访问权限感到不确定

一位 Antigravity 用户称，与防御性研究相关的账号违规记录在员工介入后被撤销，但警告通知发得较迟，也没有明确指出触发警告的行为。一条回复质疑，普通用户是否也能得到同样的纠正。[@ArtemR](https://x.com/ArtemR) [更新](https://x.com/ArtemR/status/2115520088178880991)（175 个赞，17 条回复，10,741 次浏览，31 次收藏）。

## 3. 用户期待什么

### 提供明确行动指引的政策通知和稳定可预期的性能

账号警告事件的后续说明反映出，用户需要及时收到通知，了解涉及的具体行为，并获得可靠的申诉渠道。延迟问题则指向另一项需求：稳定的响应速度，以及清晰易懂的限流机制。**存在直接的改进机会**，不过今天的报告并未量化这两类问题各自出现的频率。[@ArtemR](https://x.com/ArtemR) [更新](https://x.com/ArtemR/status/2115520088178880991)（175 个赞，17 条回复，10,741 次浏览）；[@alwayspriyesh](https://x.com/alwayspriyesh) [据报道](https://x.com/alwayspriyesh/status/2115364939066175569)（74 个赞，32 条回复，3,839 次浏览）。

## 4. 正在使用的工具和方法

| 工具 | 类别 | 评价 | 优势 | 局限 |
|---|---|---|---|---|
| Gemini 4 Carbon / Artificial Analysis Index | 模型评测 | (+/-) | 据报告，综合得分突出，并提供单项任务成本对比 | 仅向部分用户开放，且基准由发布方制定 |
| Antigravity 中的 Gemini 3.8 Flash | 编程模型/集成开发环境 | (-) | 集成式编程工作流 | 用户反映存在延迟和限流；问题普遍程度尚不清楚 |
| agentlog | 会话日志搜索 | (+/-) | 可搜索多个编程智能体的历史会话 | 作者指出，目前优先支持 macOS，也需考虑 token 成本和日志中的敏感信息 |
| Google 政策通知 | 账号处置 | (-) | 后续说明提到经过人工审核并撤销处置 | 据用户称，最初的通知发得迟，内容也含糊 |

当天的整体评价不一：用户对基准测试结果兴趣浓厚，同时也有人反映响应缓慢、账号处置不透明。跨会话笔记可用来弥补上下文丢失，但也会带来 token 成本和数据处理方面的负担。目前没有迹象表明用户已转向其他服务提供商。
