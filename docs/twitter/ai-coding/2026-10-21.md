# Twitter AI Coding - 2026-10-21

## 1. What People Are Talking About

### 1.1 Longer-lived context is now a named feature (🡕)

An OpenAI Developers post announced optional 12-hour API prompt caching; a follow-up said logged-in Codex and Work users could resume old conversations while keeping cache benefits. Replies treated the change as useful for persistent agents and work spanning several hours.

[@thsottiaux](https://x.com/thsottiaux) [described](https://x.com/thsottiaux/status/2112712984644784534) (5,521 likes, 1,025 replies, 399,266 views, 426 bookmarks) the longer cache behavior in Codex and Work. The quoted OpenAI Developers announcement specifies the 12-hour API option.

**Comparison to prior day:** October 20 focused on infrastructure that resumes agent work after failures, as [@rauchg](https://x.com/rauchg) [described](https://x.com/rauchg/status/2112658577110520122) (135 likes, 43 replies, 12,134 views, 80 bookmarks). Today's cache announcement addresses a related but distinct issue: reusing context when a user returns to an existing session.

### 1.2 OpenAI distribution was reported to expand beyond Azure (🡕)

Posts citing Reuters said OpenAI would sell its frontier models and Codex through Google Cloud, alongside existing cloud distribution. Another post said GPTs would also be available in Antigravity. These were access-route reports, not evidence of a change to the models themselves.

[@unusual_whales](https://x.com/unusual_whales) [reported](https://x.com/unusual_whales/status/2112905997240991909) (113 likes, 38 replies, 60,166 views, 13 bookmarks) that OpenAI models and Codex were coming to Google Cloud. [@AndrewCurran_](https://x.com/AndrewCurran_) [posted](https://x.com/AndrewCurran_/status/2112907155787411582) (126 likes, 11 replies, 4,965 views, 8 bookmarks) that GPTs would be available in Antigravity.

### 1.3 Agents turned archives into an explorable 3D site (🡒)

Google described feeding LiDAR scans and archival records about Chaco Canyon into Antigravity, then using Gemini 4 Argon and Blender MCP to create an explorable heritage site.

[@Google](https://x.com/Google) [demonstrated](https://x.com/Google/status/2113005543623450865) (125 likes, 28 replies, 42,949 views, 22 bookmarks) a page with clickable rooms, historical context, and a solar-dial interaction.

Severity: High for software handling private data; prevalence is not independently measured in this feed. ## 3. What People Wish Existed

### Context that persists across long sessions

The positive response to longer prompt caching and persistent Codex/Work sessions signals a practical need to return to old conversations without rebuilding context. The API option and logged-in product behavior are distinct, so users also need scope made explicit. Opportunity: Direct.

### Security checks that understand application permissions

The post's example of document access-control mistakes points to a need for agent workflows that preserve business-specific privacy rules and check them continuously. The post offers this as a recommendation, not evidence that a specific product solves it. Opportunity: Direct.
