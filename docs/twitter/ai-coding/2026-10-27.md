## 2. What Frustrates People

### General-purpose code review can trade coverage for confidence

Alibaba's repository says general-purpose agents can skip files, drift on line locations, and vary with small prompt changes. Its own benchmark description says Open Code Review favors precision over recall, so fewer false alarms come with a risk of missing some defects. These are project-reported limitations and trade-offs, not an independent comparison. [Repository](https://github.com/alibaba/open-code-review); [announcement](https://x.com/thisdudelikesAI/status/2115010135588589932) (29 likes, 17 replies, 1,088 views).

## 6. New and Notable

### Alibaba open-sourced an internal code-review assistant

The repository says Open Code Review was used internally for two years before release and describes a benchmark of 200 pull requests across 50 repositories, with 1,505 annotated issues. It trades lower recall for higher precision and fewer false alarms, a clear quality choice for teams considering automated review. [GitHub repository](https://github.com/alibaba/open-code-review).
