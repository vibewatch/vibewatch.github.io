## 1. What People Are Talking About

### 1.1 Spec-first workflows are adding structured review before code changes

Google's [Elephant-Goldfish Model repository](https://github.com/google/elephant-goldfish-model) describes an open-source plugin that uses a long-context agent to draft a specification, then fresh-context reviewers to challenge it before implementation. The project says this is most useful when a feature needs design decisions; it does not replace tests or human judgment, and is not an officially supported Google product. [@thisguyknowsai](https://x.com/thisguyknowsai) [summarized](https://x.com/thisguyknowsai/status/2116453452977152209) the method (29 likes, 4 replies, 1,760 views, 34 bookmarks).

![Elephant-Goldfish design and review workflow](https://pbs.twimg.com/media/HV8nMwkaAAAHNLr.jpg)

Matt Pocock's [engineering skills repository](https://github.com/mattpocock/skills) takes a more modular approach, with routines for clarification, TDD, debugging, review, and handoff. Replies debate whether a detailed upfront interview is efficient or whether agents should make reversible choices and ask before costly ones. [@heynavtoor](https://x.com/heynavtoor) [shared](https://x.com/heynavtoor/status/2116501931778842809) the repository (29 likes, 60 replies, 2,974 views, 13 bookmarks).

### 1.3 Prompt-cache retention can change during ordinary tool waits

An analysis of public GitHub Copilot coding-agent traces reports that the token-weighted cached share of user-opened prompts fell from 59.6% in the 270–300 second bin to 26.1% in the 300–330 second bin. The author also found similar drops for some agent calls after tool runs, while other models retained more context. This is one analysis of a public trace with model names hidden, not a general guarantee for every Copilot session. [@Siddhant_K_code](https://x.com/Siddhant_K_code) [shared](https://x.com/Siddhant_K_code/status/2116593398660674014) the measurement (12 likes, 8 replies, 408 views, 4 bookmarks); [the full analysis](https://siddhantkhare.com/writing/coding-agent-cache-five-minutes) details its method and limitations.

## 2. What Frustrates People

### A good initial interview cannot anticipate every decision

The Skills For Real Engineers discussion treats misalignment as a reason to clarify requirements before coding. Replies add an important counterpoint: many small decisions arise mid-task, so an exhaustive interview can create friction; one practitioner suggests guessing when a choice is reversible and asking when mistakes are costly. The thread reflects a design trade-off, not a measured preference across developers. [@heynavtoor](https://x.com/heynavtoor) [shared](https://x.com/heynavtoor/status/2116501931778842809) the skill workflow (29 likes, 60 replies, 2,974 views).

### Long waits can reduce prompt-cache reuse

The trace analysis finds a marked drop around the five-minute boundary for some models. It cannot determine whether a cache expired, a request went to a replica without the prefix, or memory pressure evicted it, so it points to a workflow concern rather than a single established cause. [@Siddhant_K_code](https://x.com/Siddhant_K_code) [summarized](https://x.com/Siddhant_K_code/status/2116593398660674014) the result (12 likes, 8 replies, 408 views).

### Usage-feature teasers leave room for expectation mismatch

The Codex thread shows users interpreting a short “resets” teaser as a concrete usage benefit, while also expecting a larger announcement. Without rollout details, anticipation can outrun what the product update eventually delivers. [@kimmonismus](https://x.com/kimmonismus) [reacted](https://x.com/kimmonismus/status/2116519700431622224) to the teaser (339 likes, 67 replies, 12,949 views).

## 3. What People Wish Existed

### Clarification that adapts to the cost of being wrong

The replies suggest a useful interaction model: ask when a decision is expensive or irreversible, and proceed on reversible choices with a clear record. The skill repository addresses requirements alignment, but the debate points toward making clarification proportional to risk and uncertainty. **Opportunity: competitive.** [@heynavtoor](https://x.com/heynavtoor) [shared](https://x.com/heynavtoor/status/2116501931778842809) the discussion (29 likes, 60 replies, 2,974 views).

### Harnesses that account for cache lifetime during long tasks

The trace analysis suggests that test runs and other pauses can affect reuse of prompt tokens. Possible responses include measuring cache retention by model, designing background work around provider limits, or making long waits visible to the user; the article presents these as design implications, not tested product fixes. **Opportunity: emerging.** [@Siddhant_K_code](https://x.com/Siddhant_K_code) [shared](https://x.com/Siddhant_K_code/status/2116593398660674014) the trace result (12 likes, 8 replies, 408 views).

## 6. New and Notable

### A public trace shows a sharp cache-share change near five minutes for some models

The article analyzes a public release containing 301,026 sessions and more than nine million model calls. For user-opened calls, its token-weighted cached share is 59.6% in the 270–300 second bin and 26.1% in the 300–330 second bin; some models retain much more, while others fall sharply. The model labels are anonymized, and the author cautions that the trace cannot distinguish cache expiration from routing or eviction. These results are useful for harness design, but they are not a Copilot service-level guarantee. [@Siddhant_K_code](https://x.com/Siddhant_K_code) [reported](https://x.com/Siddhant_K_code/status/2116593398660674014) the headline comparison (12 likes, 8 replies, 408 views); [the article](https://siddhantkhare.com/writing/coding-agent-cache-five-minutes) provides the method.

## 7. Where the Opportunities Are

**[+++] Spec-first, independently reviewable coding workflows** — EGM and Matt Pocock's skills both make requirements and engineering discipline explicit before or during implementation. The discussion also surfaces a product-design question: when should an agent ask, and when should it make a reversible choice?

**[++] Cache-aware agent harnesses** — The trace analysis identifies a possible five-minute retention cliff for some anonymized models. Model-specific measurement and wait-aware orchestration are promising, though the data does not prove a universal mechanism.

**[+] Clearer usage controls and release communication** — The Codex teaser drew substantial discussion about banked resets, but the evidence concerns expectations, not confirmed feature behavior.
