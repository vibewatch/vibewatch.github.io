## 7. 机遇所在

**[+++] 可与现有智能体协作的服务商 API ** - Gemini API CLI 的设计目标，是在不取代智能体的记忆或规划器的前提下，为其增加专门能力；相关帖子也获得了大量互动。

**[++] 面向生产环境智能体的运维培训 ** - 测试版认证凭证的截图将智能体部署、集成和治理列为一组技能，但帖子没有展示考试标准或雇主需求。

**[+] 面向特定任务的 AI 辅助软件工具 ** - Bezier Type 是一个小型的在线实例，展示了如何借助模型和编程环境解决特定设计任务。
