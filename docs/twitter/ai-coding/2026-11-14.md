# Twitter AI Coding - 2026-11-14

## 1. What People Are Talking About

### 1.1 Coding-agent rankings are changing as benchmark tasks and verifiers change 🡕

Artificial Analysis updated its Coding Agent Index with FrontierCode-AA 2.0 and Terminal-Bench 4.1. The post says FrontierCode-AA 2.0 uses 132 real-world coding tasks, while Terminal-Bench keeps 66 tasks with revised verifiers. Across 23 configurations tested on both FrontierCode versions, the reported mean fell from 45% to 29%; among configurations scoring 48 or more, reported cost per task varied about 30-fold.

[@ArtificialAnlys](https://x.com/ArtificialAnlys) [announced](https://x.com/ArtificialAnlys/status/2121393821955334328) (314 likes, 55 replies, 48,878 views, 56 bookmarks) the v2.1 index. The scores are not interchangeable with the earlier version because the task set changed.

![Artificial Analysis Coding Agent Index v2.1 scores and cost per task across coding-agent configurations](https://pbs.twimg.com/media/HXCuvDDb0AA4PR9.jpg)

**Discussion insight:** The publisher says updated tasks explain the lower scores; this makes benchmark version and verifier quality important context for comparisons.

**Comparison to prior day:** Nov. 13 highlighted product-level cost claims; today's index gives a more explicit task and scoring basis, while still showing cost variation.

### 1.2 Developers want one place to see agent sessions and permissions →

Agent Hover is presented as a Mac menu-bar view of Claude Code, Codex, Cursor, Gemini, and OpenCode sessions, with status, spend limits, and permission prompts. The author describes it as local-first; a reply asks for worktree management, which the author says is planned.

[@hii_mohit](https://x.com/hii_mohit) [introduced](https://x.com/hii_mohit/status/2121594780400652330) (74 likes, 46 replies, 2,127 views, 13 bookmarks) the app. Separately, GitHub's October feature summary describes Copilot automations for issue triage, multi-repository Projects, and model routing through Copilot Fusion.

[@github](https://x.com/github) [listed](https://x.com/github/status/2121361459582025982) (90 likes, 21 replies, 16,988 views, 16 bookmarks) the Copilot features. A reply asks for a shared view of multi-repository pull requests and their merge order.

**Comparison to prior day:** Nov. 13 focused on gateways and reusable instructions; today's posts emphasize live coordination across coding clients and repositories.

### 1.3 Evaluation includes cost and independent plan review →

A ByteAsk comparison says it matched Codex CLI's fixes on 72 C++ bugs across 19 repositories using the same model, with 68% lower cost and 78% fewer tokens. These are product-comparison claims without independent replication in the captured evidence.

[@kapilansh_twt](https://x.com/kapilansh_twt) [reported](https://x.com/kapilansh_twt/status/2121527733356486684) (42 likes, 39 replies, 1,778 views) the comparison. A separate post recirculated Google's Elephant-Goldfish Model, which separates plan drafting from review by agents that do not see the original chat. A reply notes that the plugin had shipped weeks earlier and is not an officially supported Google product.

**Comparison to prior day:** The earlier report discussed cost-per-task claims; today's posts add task-specific code results and a plan-review pattern.

## 2. What Frustrates People

### Benchmark scores change when task sets and verifiers change

**Severity: Medium for teams comparing agents over time.** Artificial Analysis says the new FrontierCode version moved the mean score from 45% to 29% across configurations tested on both versions, while revised tasks and verifiers changed the evaluation. A score without its benchmark version can therefore mislead; this is a limitation of comparison, not evidence that a specific system regressed. ([@ArtificialAnlys](https://x.com/ArtificialAnlys/status/2121393821955334328) (314 likes, 55 replies, 48,878 views, 56 bookmarks))

### Agent sessions still need more cross-worktree management

**Severity: Low, single feature request.** A reply to Agent Hover asks to manage unused worktrees from the same interface, and the builder says that capability is planned. The post does not establish broader demand. ([@hii_mohit](https://x.com/hii_mohit/status/2121594780400652330) (74 likes, 46 replies, 2,127 views, 13 bookmarks))

### Cost claims need matched tasks and independent replication

**Severity: Medium for teams choosing coding agents.** ByteAsk's post compares the same model on a defined C++ task set, but the captured thread does not provide independent results or all evaluation conditions. The 68% figure should be treated as a vendor-linked claim, not a general savings estimate. ([@kapilansh_twt](https://x.com/kapilansh_twt/status/2121527733356486684) (42 likes, 39 replies, 1,778 views))

## 7. Where the Opportunities Are

**[+++] Versioned, cost-aware coding-agent evaluations** — The revised FrontierCode set changed all 23 overlapping configuration scores, and the post reports roughly 30x variation in cost per task among configurations scoring 48 or higher. Version-aware results that show task quality and cost together would address both comparison problems. ([index update](https://x.com/ArtificialAnlys/status/2121393821955334328))

**[++] Cross-agent session and permission visibility** — Agent Hover targets session status and permission prompts across several clients, while a reply requests worktree management and Copilot users ask for an ordered multi-repository PR view. These are concrete coordination gaps, though only one product is described. ([Agent Hover discussion](https://x.com/hii_mohit/status/2121594780400652330), [Copilot discussion](https://x.com/github/status/2121361459582025982))

**[+] Cost-efficient coding-agent runs** — ByteAsk's author reports matching Codex CLI fixes at lower cost and token use on a defined C++ set. The claim merits task- and harness-level independent comparison before drawing a general conclusion. ([post](https://x.com/kapilansh_twt/status/2121527733356486684))
