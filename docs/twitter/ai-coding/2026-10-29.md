## 1. What People Are Talking About

### 1.1 IDE ecosystems are opening extension points 🡕

[@antigravity](https://x.com/antigravity) [announced](https://x.com/antigravity/status/2115852199502684342) (907 likes, 58 replies, 28,615 views, 164 bookmarks) a plugin marketplace for Antigravity. Follow-up posts show integrations for Jira, Confluence, and Bitbucket context, plus brand-kit design checks and CrowdStrike alert triage.

### 1.2 Model choice is being framed as a cost, speed, and control trade-off 🡕

[@rohanpaul_ai](https://x.com/rohanpaul_ai) [summarized](https://x.com/rohanpaul_ai/status/2115612239193686050) (28 likes, 25 replies, 2,818 views) Copilot Fusion's reported Coding Agent Index score of 60 versus 62 for Claude Code, with $5.59 versus $11.42 per task. The figures are a third-party recap of benchmark results, not production measurements. Meanwhile, [@rapidmlx](https://x.com/rapidmlx) [announced](https://x.com/rapidmlx/status/2115862466068623609) (22 likes, 8 replies, 931 views, 13 bookmarks) a Mac-focused local inference release with more than 240 models and a built-in coding-agent harness; its claimed speed gains are vendor-reported.

### 1.3 Developer SDKs are separating agent logic from inference 🡕

[@dotnet](https://x.com/dotnet) [shared](https://x.com/dotnet/status/2115896453692260370) (14 likes, 2,115 views, 9 bookmarks) a C# GitHub Copilot SDK sample using ProviderConfig to route requests to a chosen model provider, with .NET 10, Microsoft Foundry, and Entra ID.

**Comparison to prior day:** October 28's discussion centered on benchmark scores and reliability complaints. Today's signals emphasize extension marketplaces, provider choice, and local execution as ways to adapt coding environments.
