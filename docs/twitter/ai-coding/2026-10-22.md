# Twitter AI Coding - 2026-10-22

## 1. What People Are Talking About

### 1.1 Agent Skills moved toward shared governance (🡕)

Anthropic said it was donating Agent Skills to the Agentic AI Foundation, the same foundation that received MCP. The post said more than 70 agent platforms had integrated the standard, naming ChatGPT, Cursor, GitHub Copilot, and VS Code. Replies described unchanged licensing and participation from several agent vendors.

[@ClaudeDevs](https://x.com/ClaudeDevs) [announced](https://x.com/ClaudeDevs/status/2113328526413996100) (2,083 likes, 105 replies, 110,245 views, 437 bookmarks) the donation and described platform adoption.

**Comparison to prior day:** October 21 emphasized persistent cache and session continuity, including the update [@thsottiaux](https://x.com/thsottiaux) [described](https://x.com/thsottiaux/status/2112712984644784534) (5,521 likes, 1,025 replies, 399,266 views, 426 bookmarks). Today shifted toward portable and governed agent instructions.

### 1.2 Agents produced visual and application artifacts (🡕)

Google demonstrated a 3D, audio-reactive cathedral scene created from one image with Gemini 4 Argon, Antigravity, and Blender MCP. OpenAI separately said its Decisions API was generally available and showed Codex reimagining a small demo app.

[@Google](https://x.com/Google) [showed](https://x.com/Google/status/2113353489938075794) (413 likes, 59 replies, 136,956 views, 171 bookmarks) the generated scene. [@romainhuet](https://x.com/romainhuet) [announced](https://x.com/romainhuet/status/2113369156838121938) (336 likes, 55 replies, 23,052 views, 49 bookmarks) the Decisions API launch and Codex demo.

### 1.3 Reference material is being packaged for agent retrieval (🡕)

A new skill converts books and document folders into structured references that agents can consult while working. Another project turns prompts into editable HTML and SVG diagrams for several coding assistants.

[@RoundtableSpace](https://x.com/RoundtableSpace) [described](https://x.com/RoundtableSpace/status/2113227616299942097) (77 likes, 6 replies, 46,673 views, 45 bookmarks) [book-to-skill](https://github.com/virgiliojr94/book-to-skill), whose repository confirms support for multiple coding agents.

[@tom_doerr](https://x.com/tom_doerr) [shared](https://x.com/tom_doerr/status/2113139880154812447) (86 likes, 5 replies, 6,742 views, 110 bookmarks) [Diagram Design](https://github.com/cathrynlavery/diagram-design), an agent skill for self-contained HTML and SVG diagrams.

## 2. What Frustrates People

### Reference knowledge is easy to lose between tasks

Severity: Medium. The book-to-skill post frames a recurring problem: developers forget where useful material lives or paste whole documents into agent sessions to recover it. The proposed tool instead creates structured references, but its reported token savings are the author's claim rather than an independently checked result. [@RoundtableSpace](https://x.com/RoundtableSpace) [described](https://x.com/RoundtableSpace/status/2113227616299942097) (77 likes, 6 replies, 46,673 views, 45 bookmarks) the workflow. Worth building for: Medium.

No other strong frustration signal was evident in the selected discussion.

## 3. What People Wish Existed

### Portable, governed instructions for agents

The Agent Skills donation and cross-tool collections point to demand for instructions that can move between assistants without changing their license or format. The feed does not establish how consistently each platform implements the standard. Opportunity: Direct.

### Reference material that remains usable without bloating each prompt

book-to-skill turns a book or document folder into chapter-level agent references, while Diagram Design emits editable HTML and SVG. These address distinct needs: retrieval from owned source material and diagrams that can be revised as a project changes. Opportunity: Competitive.
