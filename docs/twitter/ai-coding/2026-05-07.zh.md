### 1.6 Claude Code 被放到显微镜下：架构研究与 Skills 生态 🡒

[@simplifyinAI](https://x.com/simplifyinAI) [分享了](https://x.com/simplifyinAI/status/2052337675634679920)（1 个赞、1 条回复、1 次收藏、23 次浏览）介绍了一篇研究论文：“研究人员逆向了 Anthropic 泄露出来的 Claude Code。他们发现的东西，彻底打碎了我们对 AI agents 的认知。”

![VILA Lab 的学术论文，题为《Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems》](https://pbs.twimg.com/media/HHteLVoaAAAMnYb.jpg)

这篇来自 Mohamed bin Zayed University 的 VILA Lab 论文，通过 Claude Code 公开可得的 TypeScript 源代码分析其架构。主要发现包括：核心只是一个简单的 while 循环——调用模型、运行工具、然后重复。复杂性都集中在这个循环之外：一个包含七种模式的权限系统、一个基于 ML 的分类器、一个五层压缩流水线、四种扩展机制（MCP、plugins、skills、hooks），以及一个子 agent 委派系统。

[@mikefutia](https://x.com/mikefutia) [演示了](https://x.com/mikefutia/status/2052456159886651598)（8 个赞、8 条回复、4 次收藏、311 次浏览）介绍了生产环境中的 Claude Code Skills：“一套完整的品牌到广告流水线，能构建永久性的品牌大脑，并按需产出 hooks、briefs、脚本和广告变体，全都在 Claude Code 里完成。”这条 skill 链包括 Brand DNA Builder、Voice Profiler、ICP Deep Dive、Hook Writer、Brief Generator、Ad Script Writer 和 Variation Engine。

[@NainsiDwiv50980](https://x.com/NainsiDwiv50980) [认为](https://x.com/NainsiDwiv50980/status/2052334953447522653)（8 个赞、2 条回复、4 次收藏、106 次浏览）：“Claude Opus 4.7 不只是让写代码更快。它改变了谁才是最优秀工程师。赢家不再是敲代码最快的人，而是那些能做系统思考、设计杠杆、管理上下文、正确引导智能的人。”

**讨论洞察：** VILA Lab 的论文提供了首份针对生产级编程 agent 的学术架构分析。Claude Code 的核心只是一个简单的 while 循环——所有复杂性都在外围基础设施中（权限、压缩、扩展性）——这说明 agent 开发中最难的问题，不在于 LLM 交互本身，而在于围绕它展开的系统工程。

**与前一天的比较：** 5 月 6 日，Claude Code 主要通过 Code with Claude 大会出现（GitHub 展示了集成架构），以及 Spaghetti agent 的质量概念。今天，学术视角进一步加深了讨论：我们现在既有实践层面的反馈（mikefutia 的广告流水线 skills），也有研究层面的分析（VILA Lab 的架构拆解）。讨论重心从“如何使用 Claude Code”转向“Claude Code 实际是如何运作的”。

## 2. 什么让人感到挫败

### Copilot 的定价无法承受 Agent 工作负载 -- 高

## 7. 机会在哪里

**[+++] 语音控制编程 Agent 集成** -- GPT Realtime 2 提供 GPT-5 级语音推理能力。tinyblue_dev（46 个赞）和 ziwenxu_ 分别独立使用了“Jarvis”这一隐喻。VraserX（44 个赞）预测，agent 式语音模式将“接入 Codex 等工具”。目前还没有编程 agent 支持用于工作流控制的双向语音交互。再结合 Antigravity 的屏幕录制泄露，语音输入与视觉上下文的融合正在创造一种全新的交互范式。第一个上线语音控制编程 agent 能力的工具，将拿下一个新品类。

**[+++] 按用量计费套利工具** -- SouthernValue95 报告称 Copilot 将在 6 月涨价 10 倍（44 个赞、19 次收藏），这会推高成本优化需求。Continue（33K stars、Apache 2.0）已经提供自带模型架构。能够帮助团队估算、监控并优化 Copilot、Claude Code、Codex 等工具 AI 编程支出的工具，尤其是那些能自动把任务路由到更便宜模型上的工具，会在价格修正来临时立刻获得需求。

**[++] 自主 Agent 会话的移动端监控** -- Remodex（第三方 Codex 移动客户端）和 mosesbabychrist 持续 3 小时的 /goal 会话表明，自主编程 agents 已经可以在无人照看的情况下运行数小时。目前没有任何第一方工具能跨 agent 提供移动监控、通知或干预能力。一个可监控 Codex /goal 会话、Claude Code 例程和 OpenCode 会话的跨平台移动仪表盘，将服务于不断增长的“设好就走”工作流模式。

**[++] 多 Agent 迁移框架** -- JamesOR 的 Express 到 Next.js 编排器 skill（22 个赞）展示了这一模式：规划 agent + 代码级 agents，并配套验证阶段。遗留系统迁移是高价值、高风险任务，单提示词方案很容易出现幻觉。带内置验证功能的产品化迁移框架（auditing-data-models、auditing-api-contracts、auditing-business-logic）将满足企业现代化需求。

**[+] Claude Code Skills 市场** -- mikefutia 的品牌到广告流水线表明，Claude Code Skills 可以编码完整的专业工作流（品牌 DNA、声音画像、广告脚本、变体引擎）。这一模式可复用于多个行业。一个面向打包 Claude Code Skills 的市场或注册中心——如果提供版本管理、依赖管理和质量评级——将推动其采用超越如今开发者通过 Twitter 私信单独分享的阶段。

## 8. 要点总结

1. **Copilot 定价即将迫使整个行业面对现实。** SouthernValue95 报告称，6 月成本将上涨 10 倍（44 个赞、19 次收藏、8,558 次浏览），这揭示出统一费率定价原本是为自动补全设计的，而不是为 agents 设计的。随着补贴结束，团队要么优化用量，要么转向 Continue（33K stars）等开源替代方案，要么接受显著上升的成本。这次重定价也影响 Anthropic——SouthernValue95 表示“Anthropic 也在做同样的事”。（[来源](https://x.com/SouthernValue95/status/2052497809769992446)）

2. **Codex 正从代码生成扩展为完整的 computer-use agent。** Chrome 扩展可以跨多个标签页处理浏览器任务（VraserX，92 个赞）。/goal 能借助 Computer Use 自主运行 3 小时完成迁移（mosesbabychrist，3,757 次浏览）。Remodex 提供移动端控制。mark_k 确认官方 Codex iOS 应用即将发布。Codex 正把自己定位为表面能力最广的编程 agent，而不只是增长最快的那个。（[来源](https://x.com/VraserX/status/2052496712590414185)）

3. **GPT Realtime 2 引发了语音控制编程 Agent 竞赛。** 公告发布后数小时内，多位开发者独立使用了“Jarvis”这一隐喻。再结合 Antigravity 的屏幕录制泄露（311 个赞、48 次收藏），编程 agents 的交互模型正趋向多模态：既能看到你的屏幕，也能听到你的声音。第一个上线这类集成的工具，将拿下一个新品类。（[来源](https://x.com/ziwenxu_/status/2052441225362342050)）

4. **Claude Code 的架构就是一个 while 循环——真正难的是围绕它的一切。** VILA Lab 的论文揭示，Claude Code 的核心很简单（调用模型、运行工具、重复执行）。工程复杂性体现在七种权限模式、五层压缩流水线、四种扩展机制和子 agent 委派系统中。这一发现重新定义了 agent 开发的挑战：LLM 交互并不难，真正重要的是系统工程。（[来源](https://x.com/simplifyinAI/status/2052337675634679920)）

5. **GitHub Copilot CLI 正以前所未有的速度交付新功能。** 一天内连发三条更新日志——跨家族审查 agents（在 GPT 会话中引入 Claude 的第二意见）、企业托管插件，以及带 /chronicle 的语义搜索——表明 GitHub 正在大力投入基于 CLI 的工作流。JamesMontemagno 意外接手自动更新组件，也印证了其内部开发正在积极推进。（[来源](https://x.com/GHchangelog/status/2052403102888739283)）

6. **Vibe coding 真正有用的细分场景，是非严肃、一次性的工具。** cyb3rops 的说法（10 个赞、537 次浏览）——“就像 IDA Pro，但我可以在 Roblox 里浏览函数图”——提供了迄今最有效的框架。与此同时，aryanlabde 的现实检验（“花了 200 美元，收入 0 美元”）和 WSJ 的报道都说明，vibe coding 适合构建，却不解决分发问题。市场正在分化成创意探索（cyb3rops）和生产化抱负（seelffff 所说的 2 亿美元 ARR）两条路线。（[来源](https://x.com/cyb3rops/status/2052515014947295695)）
