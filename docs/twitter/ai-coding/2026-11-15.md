# Twitter AI Coding - 2026-11-15

## 1. What People Are Talking About

### 1.1 Security alert triage is entering the coding-agent workspace 🡕

GitHub announced a public-preview security extension in the Copilot app for finding, explaining, fixing, or dismissing code-scanning alerts. GitHub's documentation says users should review the proposed diff and run relevant tests; the extension follows the app's tool permissions and does not close an alert until scanning confirms the fix.

[@github](https://x.com/github) [announced](https://x.com/github/status/2122058578005487774) (112 likes, 23 replies, 16,429 views, 21 bookmarks) the extension. The documentation also clarifies that the current feature covers code-scanning alerts, not Dependabot or secret-scanning alerts.

**Discussion insight:** A reply asks that dismissals not grant an agent more authority than the requesting user; another says explanations matter alongside fixes.

**Comparison to prior day:** Nov. 14 focused on benchmark revisions and session management; today's clearest product update brings defensive code review into the same client.

### 1.2 Fresh-context plan review is a cross-client workflow →

The Elephant-Goldfish Model separates plan writing from plan review: the drafting agent sees project context, while reviewers see only the written document, and a person approves before code is written. Its repository also describes a report for finding drift between design documents and code.

[@RRweb3](https://x.com/RRweb3) [described](https://x.com/RRweb3/status/2121860616696868883) (68 likes, 65 replies, 1,092 views) the plugin. The public [repository](https://github.com/google/elephant-goldfish-model) describes an open-source, Apache-2.0 project; a reply emphasizes that the human approval step matters.

**Comparison to prior day:** The Nov. 14 report covered changing benchmark tasks; this pattern tries to catch unstated assumptions before implementation begins.

### 1.3 Subscription portability remains a reported source of friction →

One user says a Google AI subscription is difficult to use outside Antigravity and describes restrictions on prompts sent through orchestrators. Replies echo a preference for using subscriptions through familiar tools, but the discussion is anecdotal. The author's further claim about data collection is unsupported and is not treated as evidence here.

[@kunchenguid](https://x.com/kunchenguid) [criticized](https://x.com/kunchenguid/status/2122043591451389962) (169 likes, 44 replies, 10,442 views, 27 bookmarks) the reported integration limits.

**Comparison to prior day:** Nov. 14's discussion centered on multi-client session visibility; today's complaint makes subscription rules another point of friction in cross-client workflows.

### 1.4 Checklists and monitors are described as part of the harness →

A post argues that monitors, checklists, and subagent managers are essential to a useful coding-agent harness. The author says the checklist can be manually populated or initiated by the agent, but the thread provides no measured effect on defect rates or completion quality.

[@championswimmer](https://x.com/championswimmer) [described](https://x.com/championswimmer/status/2121781169142243340) (26 likes, 5 replies, 1,698 views, 47 bookmarks) the workflow and shares a checklist interaction detail in a reply.

**Comparison to prior day:** This continues the session-visibility theme from Nov. 14, shifting from a status dashboard toward task-completion checks.

## 3. What People Wish Existed

The Copilot security extension offers alert explanations and suggested fixes, while the documentation requires review of changes and tests and a reply asks that dismissal rights match the user's permissions. Clear approval and audit boundaries are a practical need for security-related agent actions. **Urgency: High. ### Portable subscriptions and consistent client permissions

The interoperability complaint and its replies point to a preference for using paid model access in familiar clients. The feed contains one user's account and does not establish how common the restriction is. **Urgency: Medium. Opportunity: Competitive.** ([@kunchenguid](https://x.com/kunchenguid/status/2122043591451389962) (169 likes, 44 replies, 10,442 views, 27 bookmarks))

Opportunity: Direct.** ([@RRweb3](https://x.com/RRweb3/status/2121860616696868883) (68 likes, 65 replies, 1,092 views); [@championswimmer](https://x.com/championswimmer/status/2121781169142243340) (26 likes, 5 replies, 1,698 views, 47 bookmarks))

## 8. Takeaways

1. **Review and verification are built into both plan and code-fix workflows.** Elephant-Goldfish places human approval before implementation; GitHub's preview asks users to review proposed diffs and tests. ([repository](https://github.com/google/elephant-goldfish-model), [security extension docs](https://docs.github.com/copilot/how-tos/github-copilot-app/view-and-fix-security-alerts))
2. **Permission boundaries are part of security assistance.** GitHub documents permission-dependent access and notes that applying a local fix does not close an alert automatically. ([documentation](https://docs.github.com/copilot/how-tos/github-copilot-app/view-and-fix-security-alerts))
3. **Tool portability is reported as an individual friction point.** One user says a subscription is difficult to use outside its named client; the post does not establish how widespread this is. ([discussion](https://x.com/kunchenguid/status/2122043591451389962))
