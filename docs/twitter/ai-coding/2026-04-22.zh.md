### 1.2 GitHub Copilot 确认将于 6 月启用基于 Token 的计费 🡕

[@edzitron](https://x.com/edzitron) [发布了独家报道](https://x.com/edzitron/status/2047004616324469203)（101 个赞，7,416 次浏览）曝光了微软内部文件中的具体定价：“Copilot Business 客户每位用户每月支付 19 美元，并获得 30 美元的共享 AI 积分。Copilot Enterprise 客户每位用户每月支付 39 美元，并获得 70 美元的共享 AI 积分。”公告原定于 4 月 23 日发布，调整将在 6 月开始推出。

![文章标题：独家：Microsoft 将于 6 月把所有 GitHub Copilot 订阅用户转为按 Token 计费，执行摘要列出 Business 为 19 美元/月含 30 美元额度，Enterprise 为 39 美元/月含 70 美元额度](https://pbs.twimg.com/media/HGhryK3bQAAay8q.png)

[@edzitron](https://x.com/edzitron) 的一条回复补充说：“AI 积分的确切额度仍未最终敲定，可能会在上线前调整。”个人订阅用户会如何处理，仍不明确。

[@SantoshYadavDev](https://x.com/SantoshYadavDev) [精准表达了这种情绪](https://x.com/SantoshYadavDev/status/2046741437258104981)（4 个赞，684 次浏览）：“2024-2025 年是使用 AI 编程工具最好的时期，接下来只会越来越贵。GitHub Copilot 停止新用户注册，还移除了 Opus 4.6。现在 Anthropic 也不再在 20 美元套餐里提供 Claude code。准备多掏钱吧。”

**Comparison to prior day:** 4 月 20 日，edzitron 首次报道称，基于 Token 的计费是“最高优先级”，而 Copilot 的每周成本自 1 月以来已翻倍。如今，这一话题从方向性信号推进到了内部文件中的具体金额和明确时间表。补贴时代正在结束，而且现在已经有了清晰数字。

### 1.7 GitHub CLI 引入遥测，用于追踪 AI 代理使用情况 🡕

[@everyonebpup](https://x.com/everyonebpup) [记录了](https://x.com/everyonebpup/status/2046939778134733088)（8 个赞，570 次浏览，5 次收藏）指出，GitHub CLI v2.91.0 新增了遥测功能：“你现在运行的每一条 gh 命令都会向 GitHub 发送一个 ping：命令名、flags、操作系统、版本、一个 device_id，以及一个名为 ‘agent’ 的字段。”

![GitHub CLI 遥测文档，显示包含 command_invocation 事件类型、agent 字段、device_id、OS、version 和 flags 的负载结构](https://pbs.twimg.com/media/HGgwnKTWYAE3Y1V.png)

“agent” 字段会追踪每次 CLI 调用是由哪个 AI 工具驱动——Claude Code、Copilot CLI、Cursor，还是 Codex。用户可通过 `GH_TELEMETRY=false`、`DO_NOT_TRACK=true` 或 `gh config set telemetry disabled` 选择退出。[@lmkifiwin](https://x.com/lmkifiwin) 的一条回复认为：“他们不是在追踪你。他们是在追踪哪个 AI 工具驱动了最多 CLI 使用量。”[@everyonebpup](https://x.com/everyonebpup) 则反驳：“agent 字段追踪是哪个 agent 跑了命令，另外 8 个字段追踪的是你。”

这次遥测上线表明，AI 代理对开发者工具链的使用已经重要到足以让 GitHub 进行系统性度量。

## 2. 哪些事让人沮丧

### GitHub Copilot 定价不确定性加剧 —— 高

[@edzitron](https://x.com/edzitron) [披露](https://x.com/edzitron/status/2047004616324469203)（101 个赞，7,416 次浏览）透露，基于 Token 的具体计费档位将于 6 月上线，但个人订阅用户的命运仍“尚不明确”。[@SantoshYadavDev](https://x.com/SantoshYadavDev) [警告称](https://x.com/SantoshYadavDev/status/2046741437258104981)（4 个赞，684 次浏览）直言：“准备好多花钱吧。”新用户注册暂停（4 月 20 日）、模型被移除，以及眼下迫近的计费变化叠加在一起，使用户难以规划。应对方式则是叠加更便宜的替代品，例如 OpenCode Go（10 美元）和 Ollama 订阅。

### Vibe Coding 的质量与审查缺口 —— 高

[@itsolelehmann](https://x.com/itsolelehmann) [发现](https://x.com/itsolelehmann/status/2046959632921636998)（2 个赞，427 次浏览）：“2026 年 vibe coding 的肮脏秘密是：大多数 AI 写的代码在上线时根本没人真正读过。我们靠 claude code、cursor、codex，把交付速度提高了 100 倍，但审查层完全没跟上。”[@serpinxbt](https://x.com/serpinxbt) [将此与安全问题联系起来](https://x.com/serpinxbt/status/2046830023525429265)（21 个赞，447 次浏览）：“vibe coding 大幅降低了骗子的入场门槛。”[@walsxbt](https://x.com/walsxbt) 的一条回复问道：“我们需要一个用 vibe coding 写出来、专门检查其他 vibe coded 应用安全性的应用。谁在做这个？”

### Claude Code 使用限制被认为过于苛刻 —— 中

[@RasputinKaiser](https://x.com/RasputinKaiser) [发帖称](https://x.com/RasputinKaiser/status/2047080869706264732)（0 个赞，13 次浏览）贴出一张 Claude Code 使用情况截图，并写道：“这使用限制可真是‘无限’！Anthropic 对 Claude 和 Claude Code 既缺算力又贪钱。”[@Presidentlin](https://x.com/Presidentlin) 将对 Claude Code 的情绪概括为：“这个工具不是在帮你，而是在跟你作对。”

## 3. 人们希望出现什么

### 能匹配 AI 构建速度的代码审查层

### 跨 AI 编程工具的统一分析

[@tom_doerr](https://x.com/tom_doerr) [分享了](https://x.com/tom_doerr/status/2047079888683683913)（3 个赞，337 次浏览）介绍了 Agentlytics：一个开源仪表盘，可统一 16 款编辑器中的会话，包括 Cursor、Windsurf 和 Claude Code。该工具 100% 本地运行，可追踪会话、成本、模型和工具。

![Agentlytics 统一仪表盘，显示 Cursor、VS Code、Windsurf、Claude Code 及其他编辑器中的会话，以及成本和模型分析](https://pbs.twimg.com/media/HGiwT6_XwAANpET.png)

### 面向非技术用户的更好模型管理

[@pfanis](https://x.com/pfanis) [两次询问](https://x.com/pfanis/status/2047072256531034242)（2 个赞，50 次浏览）：“为什么每次有新模型，我们都得再更新一次？难道没有更简单一点的办法吗？抱歉，各位，我不是技术人员。”这个问题反映出，日益增长的非工程师用户群体在为 OpenCode 添加新模型时面临明显摩擦。

## 6. 新动态与值得关注的消息

### GitHub Copilot 基于 Token 的计费：具体数字浮出水面

[@edzitron](https://x.com/edzitron) [发布了](https://x.com/edzitron/status/2047004616324469203)（101 个赞，7,416 次浏览）曝光的微软内部文件显示：Business 为 19 美元/用户/月，对应 30 美元共享 AI 积分；Enterprise 为 39 美元/用户/月，对应 70 美元共享 AI 积分。公告预计于 4 月 23 日发布，并于 6 月推出。这让 4 月 20 日的报道从方向性信号进一步推进到具体价格档位。个人订阅方案仍未定义。

### Codex 工作区代理取代 Custom GPTs

OpenAI [推出了](https://x.com/9to5mac/status/2047012931628412955)（31 个赞，4,846 次浏览）在 ChatGPT 中推出了由 Codex 技术驱动的工作区代理。适用于 Business、Enterprise 和 Edu 套餐。代理在云端运行，可处理长时工作流，并可在组织内部共享。这使 Codex 从专用编程工具延展为通用型企业自动化层。

### SpaceX-Cursor 100 亿美元交易，可能通向 600 亿美元收购

SpaceX 和 Cursor [宣布](https://x.com/9to5mac/status/2046947214849712177)（40 个赞，6,455 次浏览）达成合作，让 Cursor 获得使用 xAI Colossus 超级计算机进行模型训练的能力。这笔 100 亿美元付款可能进一步演变为 600 亿美元收购。如果完成，这将打造出一个拥有自有算力、模型和 IDE 分发渠道的垂直整合竞争者——这是 OpenAI（Codex）和 Anthropic（Claude Code）目前都不具备的结构。

### Google Cloud 为竞争对手平台发布官方 Agent Skills

[@JackWoth98](https://x.com/JackWoth98) [宣布](https://x.com/JackWoth98/status/2047081072400466129)（4 个赞，106 次浏览）发布了 13 项官方 Google Cloud Agent Skills，可兼容 Gemini CLI、Codex、Claude Code 和 OpenCode。值得注意的是，Google 正在明确为竞争对手代理平台提供第一方云服务技能。

![Google Cloud Agent Skills 公告，显示 github.com/google/skills 仓库](https://pbs.twimg.com/media/HGixKCRaUAAyp5g.jpg)

### PixiJS 推出面向游戏开发的 Agent Skills

[@PixiJS](https://x.com/PixiJS) [已发布](https://x.com/PixiJS/status/2047013163900764508)（8 个赞，165 次浏览）发布了帮助代理正确使用 PixiJS v8 构建 WebGL/WebGPU 项目的 AI 技能。通过 [Agent Skills 格式](https://github.com/pixijs/pixijs-skills)，可兼容 40+ 个代理。这是首个发布专用代理技能的大型渲染库，说明技能生态正从云基础设施扩展到创意工具。

### Coinbase 报告非工程师开发工具使用量增长 27 倍

[@rwitoff](https://x.com/rwitoff)（Coinbase）[分享了](https://x.com/rwitoff/status/2046954173980446803)（15 个赞，310 次浏览）：“过去 12 个月里，我们看到使用 Claude、OpenCode 和 Cursor 等开发工具来构建并自动化工作流程的非工程师人数增长了 27 倍。”

![Coinbase 非工程岗位开发工具采用图表，显示从 2025 年 4 月到 2026 年 3 月的指数级增长](https://pbs.twimg.com/media/HGUE2msbYAAgm18.png)

[@rgivon](https://x.com/rgivon) 的一条回复指出：“每位员工都已经变成了一个团队。协调或共享不再是原语。”

## 7. 机会在哪里

**[+++] AI Code Review at Scale** -- [@itsolelehmann](https://x.com/itsolelehmann) [称其为](https://x.com/itsolelehmann/status/2046959632921636998) 点出了核心问题：“大多数 AI 写的代码在上线时根本没人真正读过。”[@serpinxbt](https://x.com/serpinxbt) [将此与诈骗风险联系起来](https://x.com/serpinxbt/status/2046830023525429265)。Antigravity 的安全事件（RCE 漏洞、木马化下载）表明，攻击面已经在被利用。一款能匹配 AI 代码生成吞吐量的审查工具——以代码上线速度扫描漏洞、逻辑错误和凭据泄露——正好对应一个会随着生产力提升而不断扩大的缺口。

**[+++] Subscription Cost Intelligence** -- Token-based billing is now confirmed with specific tiers ([@edzitron](https://x.com/edzitron)、[文章](https://x.com/edzitron/status/2047004616324469203)）。[@LottoLabs](https://x.com/LottoLabs) [描述了](https://x.com/LottoLabs/status/2046823278397042769) 正在手动比较 OpenCode Go 的 10 美元、GPT 的 20 美元以及 Ollama 订阅。一款能监测 Copilot、Codex、Claude Code 和 OpenCode 实际 Token 消耗、推荐最佳套餐分配，并自动将请求路由到最便宜且能力足够模型的工具，会在补贴时代结束之际满足一种结构性需求。

**[++］ Agent Skills 生态工具链** -- Google Cloud ［发布](https://x.com/JackWoth98/status/2047081072400466129) 发布了 13 项官方 agent skills。PixiJS [已发布](https://x.com/PixiJS/status/2047013163900764508) 发布了面向 40+ 个代理的渲染技能。[@asm3r96](https://x.com/asm3r96) [构建了](https://x.com/asm3r96/status/2047079483824345108) 将 wave-driven development 做成了个人技能。技能格式正在被越来越多地采用，但围绕发现、质量保障和组合的工具尚不存在。面向 agent harness 的技能市场、注册表或推荐引擎，能够加速这一新兴生态。

**[++] Post-Build Distribution for AI-Created Products** -- [@Parul_Gautam7](https://x.com/Parul_Gautam7) [发现](https://x.com/Parul_Gautam7/status/2047012381189079468) 指出：“Vibe coding 解决了构建，但分发仍是缺失的一层。”Open SaaS 借助 [1.4 万 GitHub 星标](https://x.com/hot_town/status/2046960073084432694) 在 vibe coding 热潮中获得增长，显示出市场对脚手架的需求。那些把已上线产品连接到可直接营销内容——落地页、UGC 广告、SEO——的工具，正好服务于如今位于代码生成下游的瓶颈。

**[+］ 面向非工程人员的开发工具入门** -- Coinbase ［报告](https://x.com/rwitoff/status/2046954173980446803) 提到非工程师使用开发工具增长了 27 倍。[@pfanis](https://x.com/pfanis) [询问](https://x.com/pfanis/status/2047072256531034242) 则提出，为什么添加一个新模型还需要手动更新——“我不是技术人员”。开发者导向工具与快速扩大的非工程师用户群之间的落差，创造了简化配置、引导式工作流和托管式模型配置的机会。

## 8. 要点

1. **Codex 的扩张速度超过所有竞争对手，而且正从编程走向更广泛场景。** 周活跃用户达到 400 万（据 ARK 数据，年初至今增长 20 倍），泄露的模型管线显示出 GPT-5.5 和多个实验代号，工作区代理也已在 ChatGPT 中面向团队上线。OpenAI 正在把 Codex 定位为通用企业自动化基础设施，而不只是编程工具。（[@richardseiler](https://x.com/richardseiler)、[图表](https://x.com/richardseiler/status/2047012252558016930)；[@9to5mac](https://x.com/9to5mac)、[工作区代理](https://x.com/9to5mac/status/2047012931628412955)）

2. **GitHub Copilot 的 Token 计费如今已有明确金额和 6 月时间点。** Business：19 美元/用户/月，对应 30 美元共享积分。Enterprise：39 美元/用户/月，对应 70 美元共享积分。个人套餐仍未定义。再结合 4 月 20 日的注册暂停和模型移除，补贴型 AI 编程时代终结的图景已基本完整。（[@edzitron](https://x.com/edzitron)、[独家](https://x.com/edzitron/status/2047004616324469203)）

3. **SpaceX-Cursor 交易打造出第三家垂直整合竞争者。** 这笔 100 亿美元、并可能通向 600 亿美元收购的交易，让 Cursor 获得 xAI Colossus 超级计算机用于模型训练。如果交易完成，Cursor 将拥有自有算力、定制模型和 IDE 分发渠道——这是 OpenAI 和 Anthropic 所不具备的结构。（[@9to5mac](https://x.com/9to5mac)、[报道](https://x.com/9to5mac/status/2046947214849712177)）

4. **一位前 Codex 工程师以 1,200 万美元押注“软件已被解决”，这是迄今最强烈的后软件信号。** [@DanielEdrisian](https://x.com/DanielEdrisian) 离开 OpenAI 转而做硬件（701 个赞、240 次收藏、44K 次浏览），反映出这位来自使用最广泛编程代理内部建设者的判断：软件创作的瓶颈已经消失，下一个约束在交互界面层。（[@DanielEdrisian](https://x.com/DanielEdrisian)、[公告](https://x.com/DanielEdrisian/status/2047066691142914124)）

5. **Google Antigravity 现在关联的是安全风险，而不只是信任问题。** 一个已修复的严重 RCE 漏洞、会投放会话劫持恶意软件的木马化下载，以及持续流失的关注度（“你们还记得 Google Antigravity 吗”）。叙事已从“发得快但会封用户”转向“发得快且用户面临主动威胁”。（[@DarkReading](https://x.com/DarkReading)、[RCE](https://x.com/DarkReading/status/2046653957884252442)；[@ransomnews](https://x.com/ransomnews)、[恶意软件](https://x.com/ransomnews/status/2046946372528812525)）

6. **代理技能生态正在迅速成形。** Google Cloud 为竞争对手平台发布了 13 项官方技能。PixiJS 推出了首批主要游戏渲染技能。个人开发者也在创建工作流技能。重心正从“带工具的代理”转向“带有整理过领域知识的代理”，这正在成为新的基础设施层。（[@JackWoth98](https://x.com/JackWoth98)、[Google skills](https://x.com/JackWoth98/status/2047081072400466129)；[@PixiJS](https://x.com/PixiJS)、[skills](https://x.com/PixiJS/status/2047013163900764508)）

7. **代码审查缺口是 AI 编程中最危险却尚未解决的问题。** 代码上线速度快了 100 倍，但审查并未同步扩展。木马化的 Antigravity 下载和由 vibe coding 助长的诈骗，都说明攻击面已经开始被利用。AI 代码生成速度与人工审查能力之间的落差，正在成为系统性脆弱点。（[@itsolelehmann](https://x.com/itsolelehmann)、[审核漏洞](https://x.com/itsolelehmann/status/2046959632921636998)；[@serpinxbt](https://x.com/serpinxbt)、[诈骗风险](https://x.com/serpinxbt/status/2046830023525429265)）
