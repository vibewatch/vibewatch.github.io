### 1.1 Claude Code 桌面版重设计与 Routines 发布（🡕）

Anthropic 在同一天为 Claude Code 推出了两项重大更新。官方账号 [@claudeai](https://x.com/claudeai) [宣布了桌面端改版](https://x.com/claudeai/status/2044131493966909862)，展示了可并排运行的多路会话、用于管理这些会话的新侧边栏、集成终端、文件编辑、HTML/PDF 预览，以及可拖放布局。[@9to5mac](https://x.com/9to5mac) [报道了此次发布](https://x.com/9to5mac/status/2044133564384502179)，并披露了推文里未提及的第二项功能：Routines——即使用户的 Mac 处于离线状态，也能在 Anthropic 的网页基础设施上运行的定时自动化任务。[9to5Mac 文章](https://9to5mac.com/2026/04/14/anthropic-adds-repeatable-routines-feature-to-claude-code-heres-how-it-works/) 说明了不同套餐的限制：Pro 每天 5 次，Max 每天 15 次，Team/Enterprise 每天 25 次。Routines 可访问代码仓库和连接器，用户无需再自行维护 cron 任务和 MCP 服务器基础设施。

[@Yuchenj_UW](https://x.com/Yuchenj_UW) [将此次改版描述为](https://x.com/Yuchenj_UW/status/2044133573326934384) 将其视为 IDE 范式的一次转变，并引用 Andrej Karpathy 的话：“我们需要一个更大的 IDE。基本单位不再是文件，而是智能体。”由此引申出的判断是：“Cursor 现在也必须争夺对 IDE 未来形态的定义权。”[@RoundtableSpace](https://x.com/RoundtableSpace) [进一步放大了这股兴奋情绪](https://x.com/RoundtableSpace/status/2044185178063679580) 以当天最高浏览量（4,898 次浏览、13 次收藏）引发关注，并收到诸如 [@traleyweb3](https://x.com/traleyweb3) 的回复：“claude code 刚刚迎来一次大升级。”

**讨论洞察：** 这次重设计获得了广泛传播，但没有引发技术层面的批评。相比之下，Routines 这项服务端定时自动化功能在结构上更重要，却没有视觉重设计那么受社交媒体关注。

**与前一天对比：** 昨日的报告追踪了 Copilot CLI 向远程化和移动化演进，以及 Codex 向桌面超级应用转型。今天，Claude Code 则通过让桌面应用支持多会话、并加入服务端自动化作出回应：既呼应了“设备无关”的方向，又增加了两家竞争对手都尚未宣布的调度能力。

### 1.2 Claude Code 技能生态扩张（🡕）

两篇帖子展示了不断壮大的可安装技能生态，这些技能正在扩展 Claude Code 开箱即用时的能力边界。

[@shi3z](https://x.com/shi3z) [发布了一个用于 SparkJS 的 Claude Code skill](https://x.com/shi3z/status/2044202378140995643)，这是一个基于 Three.js 构建的 3D Gaussian Splat 渲染库。该帖拿下当天最高评分（95.8），收获 22 个赞、12 次收藏和 3,240 次浏览。[GitHub 仓库](https://github.com/shi3z/sparkjs-skill) 包含一个 SKILL.md 和 references 目录，覆盖完整的 SparkJS API：SparkRenderer、SplatMesh、PackedSplats、基于 SDF 的 splat 编辑、细节层级流式传输、Dyno 着色器图系统（含 117+ 个标准库函数），以及针对不同平台的性能优化。安装只需一条 `git clone` 到 `~/.claude/skills/`。

另一方面，[@hasantoxr](https://x.com/hasantoxr) [重点介绍了 Taste Skill](https://x.com/hasantoxr/status/2044008552231252248)，这是一个开源智能体技能集合，旨在让 AI 编程工具具备“设计品味感”。[仓库](https://github.com/LeonxLnx/taste-skill) 已获得 8.3k stars 和 827 forks，包含七种技能变体（taste-skill、redesign-skill、soft-skill、brutalist、minimalist、stitch、output-skill），以及三个可调旋钮，用于控制布局变化幅度、动效强度和视觉密度。与 SparkJS Skill 不同，Taste Skill 支持跨工具使用：Cursor、Claude Code、Codex、Windsurf、Copilot 和 Antigravity。

![Taste Skill 的 GitHub README，显示 8.3k stars、skill 变体表，以及 CLI 安装命令](https://pbs.twimg.com/media/HF3G8lLbgAA4ErV.png)

**讨论洞察：** SparkJS Skill 展示的是领域专属知识注入（3D 图形 API），而 Taste Skill 展示的是跨领域的质量注入（设计模式）。两者共同体现了两种不同的技能模式：纵向深入的专业能力，与横向通用的质量能力。

**与前一天对比：** 昨日的报告并未专门涉及技能。随着技能生态与 MCP 并行发展，技能正成为 AI 编程智能体的第二种扩展机制。

## 2. 什么让人感到沮丧

### Claude Code 成本不透明（中等）

[@GithubAwesome](https://x.com/GithubAwesome) [直接点明了问题](https://x.com/GithubAwesome/status/2044203308642968037)：“有人每天在 Claude Code API credits 上花费超过 200 美元，却完全不知道钱花到哪儿去了。”对应的解决方案是 codeburn——一个终端 UI，能够读取本地会话转录，并按任务类型（调试、头脑风暴、编码）归类每一笔 token 消耗；它将“臃肿的 MCP 服务器带来的 token 额外开销”识别为成本驱动因素之一。该工具还提供交互式每日活动图表和 Mac 菜单栏小组件。整个分析过程无需调用 LLM。

这延续了昨日报告中的 token 膨胀问题：Claude Code v2.1.100+ 已被确认会在每次请求中注入约 20k 个服务端 token，而系统开销在用户发出任何消息前就会先消耗约 50k 个 token。今天的新证据又补充了一个成本来源：臃肿的 MCP 服务器也在造成 token 浪费。

### Claude Code 流失信号（低）

[@inancgumus](https://x.com/inancgumus) [简单地表示](https://x.com/inancgumus/status/2044202972578467949)：“我已经彻底摆脱 Claude Code 了。”该帖获得 374 次浏览，但没有任何点赞和收藏——关注者看到了，却没有进一步放大传播。发帖者没有解释为何转用其他工具。作为一个孤立数据点，这只能算是一个缺乏诊断价值的流失信号，但它出现的背景是：围绕成本和质量的担忧已连续多日存在。

## 3. 人们希望出现什么

### 细粒度的 token 成本归因

“每天在 Claude Code API credits 上花费 200 美元”（[@GithubAwesome](https://x.com/GithubAwesome)）与任何内置成本可视化能力之间，仍然存在巨大空白。Codeburn 虽然通过读取本地会话转录来补上这个缺口，但它是外部工具，而且只能事后分析。用户真正需要的是内置在智能体中的、按任务实时归因的成本视图：在调试会话开始前就知道它的成本会是代码生成会话的 3 倍，而不是等账单来了才知道。昨日的报告已经指出了同样的需求；今天的数据则用一个具体数字（200 美元/天）再次确认了它。

### 跨工具的技能可移植性

Taste Skill 的跨工具兼容性（Cursor、Claude Code、Codex、Windsurf、Copilot、Antigravity）凸显出大多数技能所欠缺的东西：可移植性。SparkJS Skill 只能运行在 Claude Code 中。随着技能生态继续增长，开发者会希望“一次安装，到处可用”——需要一种可跨智能体工作的技能注册表和技能格式，类似 MCP 对工具连接所做的标准化。Taste Skill 使用的 `npx skills add` 命令，暗示了这一方向。

## 6. 新动态与值得关注

### Claude Code Routines：服务端定时自动化

Anthropic 以研究预览形式推出了 Routines——运行在 Claude Code 网页基础设施上的定时自动化任务，可访问代码仓库和连接器。这让 Claude Code 从一种被动工具（用户发出提示，智能体响应）转向一种主动工具（无需用户在场，智能体也能按计划运行）。套餐限制为：Pro 每天 5 次，Max 每天 15 次，Team/Enterprise 每天 25 次。（[9to5Mac](https://9to5mac.com/2026/04/14/anthropic-adds-repeatable-routines-feature-to-claude-code-heres-how-it-works/), [帖子](https://x.com/9to5mac/status/2044133564384502179)）

### Claude Code 桌面版进入多会话时代

重新设计后的 Claude Code 桌面应用支持在单个窗口内运行多个并行会话，并提供管理侧边栏。新版本还加入了集成终端、文件编辑、HTML/PDF 预览，以及更快的 diff 查看器，并采用可拖放布局。这直接对应了开发者在同一代码库不同部分并行运行智能体任务的工作流需求。（[帖子](https://x.com/Yuchenj_UW/status/2044133573326934384)）

### SparkJS Skill：首个面向 3D 图形的领域专属 Claude Code Skill

这是一个采用 MIT 许可证的技能，为 Claude Code 提供完整的 SparkJS 3D Gaussian Splat 渲染库知识——覆盖渲染器、splat mesh、SDF 编辑、LoD 流式传输，以及 117+ 个着色器标准库函数。安装只需一次 git clone。它展示了把领域专属 API 知识打包成可移植技能文件的模式。（[GitHub](https://github.com/shi3z/sparkjs-skill), [帖子](https://x.com/shi3z/status/2044202378140995643)）

## 7. 机会在哪里

**[+++] 智能体技能注册表与跨工具可移植性** —— SparkJS Skill（仅支持 Claude Code）和 Taste Skill（支持 6+ 种工具）表明，两种技能分发模式正在同时出现。Taste Skill 的 `npx skills add` 和跨工具支持已获得 8.3k stars；而 SparkJS 这种仅限 Claude 的 git clone 方式，也在几小时内收获了 22 个赞和 12 次收藏。一个统一的技能注册表——让技能发布一次，就能在 Claude Code、Cursor、Codex、Windsurf 和 Copilot 上安装——将获得与 MCP 在工具连接领域相同的生态价值。需求已经存在，标准尚未出现。

**[++] AI 编程智能体的实时成本归因** —— 昨日的报告记录了在用户发消息前约 50k token 的系统开销。今天的数据又补充了 200 美元/天的成本数字，以及首个外部解决方案 codeburn。机会在于把成本归因直接做进智能体本身：执行前提供按任务划分的成本预估、预算提醒，以及按结果衡量的成本指标。每一个 Claude Code API 用户都可能是这项能力的潜在客户。

**[++] Anthropic 之外的定时智能体自动化** —— Claude Code Routines 是 AI 编程智能体中首个服务端定时自动化功能。它受套餐限制（每天 5-25 次运行），且仅限 Anthropic 生态。一个开源等价方案——支持任意 LLM 后端、运行在开发者自有基础设施上的定时智能体任务——将满足与昨日推动 Multica 获得 4,000+ stars 相同的需求：自托管智能体基础设施。

**[+] AI 辅助教育平台** —— Ship Your First App 展示了 Claude Code 作为面向非技术用户的结构化辅导平台的潜力。这种课程模式（获取说明、边做边教、交互练习）可以从 Web 开发推广到任何技术领域。当前的空白在于，现有内容只有 Phase 1，Modules 1-3 和 Phases 2-3 都仍标记为 “Coming Soon”。谁先在多个领域拿出完整课程体系，谁就可能占据这个类别。

## 8. 要点

1. **Claude Code 在同一天推出了桌面版重设计和服务端 Routines。** 并行会话、集成终端和拖放布局更新了桌面体验。Routines——运行在 Anthropic 基础设施上的定时自动化——则让 Claude Code 从被动工具走向主动工具，并按套餐设有限制（每天 5-25 次运行）。（[9to5Mac](https://9to5mac.com/2026/04/14/anthropic-adds-repeatable-routines-feature-to-claude-code-heres-how-it-works/)）

2. **Claude Code 技能生态正在形成两种鲜明模式。** SparkJS Skill（领域专属 API 知识、仅限 Claude）和 Taste Skill（横跨多场景的设计质量、8.3k stars、支持 6+ 工具）分别体现了纵向深度与横向广度。跨工具可移植性是关键分野。（[SparkJS](https://x.com/shi3z/status/2044202378140995643), [Taste Skill](https://x.com/hasantoxr/status/2044008552231252248)）
