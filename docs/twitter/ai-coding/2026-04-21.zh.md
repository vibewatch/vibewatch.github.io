### 1.2 AI 编程安全危机沿多个向量升级 🡕

三个彼此独立的安全事件汇聚成当天最令人警惕的主题。

**针对所有主流代理的提示注入。** [@The_Cyber_News](https://x.com/The_Cyber_News) [报道称](https://x.com/The_Cyber_News/status/2046510893752807689)（23 个赞，1,785 次浏览）讨论了一类被称为“Comment and Control”的跨厂商漏洞——攻击者可利用 GitHub pull request 标题、issue 正文和评论实施提示注入，劫持 AI 编程代理，并直接从 CI/CD 环境窃取 API 密钥。Claude Code Security Review（Anthropic 评为 CVSS 9.4，Critical）、Gemini CLI Action 和 GitHub Copilot Agent（SWE Agent）均已确认存在该漏洞。研究人员 Aonan Guan 演示了完整攻击链如何完全在 GitHub 内部完成：攻击者发起一个带恶意标题的 PR，AI 代理将其当作可信上下文处理，执行其中指令，再通过 PR 评论把凭据回传出去。

![“Comment and Control”漏洞示意图：Claude Code Security Review agent 读取了来自 GitHub PR 的恶意提示，并泄露了凭证](https://pbs.twimg.com/media/HGaqwqmbUAAdwhl.jpg)

[@jeremie_strand](https://x.com/jeremie_strand) 的回复点出了核心问题：“代理读取不可信内容时，赋予它的信任级别和操作员指令一样高。数据与指令的分离至今仍未解决。”

**Antigravity IDE 远程代码执行。** [@TheHackersNews](https://x.com/TheHackersNews) [报道称](https://x.com/TheHackersNews/status/2046535216068694239)（49 个赞，7,242 次浏览）称，Google 修复了 Antigravity IDE 的一个漏洞，该漏洞可通过搜索工具输入实现任意代码执行。攻击者能够注入命令、绕过沙箱控制并自动运行脚本。[@DarkReading](https://x.com/DarkReading) [另文报道了](https://x.com/DarkReading/status/2046653957884252442)（3 个赞，1,072 次浏览）也提到了同一修复。

![攻击流程图展示了不受信任内容如何到达由攻击者控制的 agent、绕过安全模式，并在 Antigravity IDE 中实现远程代码执行](https://pbs.twimg.com/media/HGbA7Z4bkAAq_6y.jpg)

**通过伪造 Antigravity 安装器发起的供应链攻击。** [@DFIR_Radar](https://x.com/DFIR_Radar) [详细介绍了](https://x.com/DFIR_Radar/status/2046605855752171956)（5 个赞，375 次浏览）提到一个被植入木马的 Antigravity 安装器：它一边交付功能完整的软件，一边部署信息窃取恶意程序。该安装器会投放一个 PowerShell 下载器、禁用 Windows Defender，并针对浏览器凭据、会话 Cookie、Discord 令牌和加密货币钱包下手。

![假冒 Google Antigravity 安装程序供应链攻击的恶意软件分析摘要](https://pbs.twimg.com/media/HGcBLV3WgAAQJAw.png)

**Vibe 编程平台数据泄露。** [@DEX_ion10](https://x.com/DEX_ion10) [报道称](https://x.com/DEX_ion10/status/2046471996452585652)（23 个赞，89 次浏览）称，vibe 编程平台 Lovable 暴露了 1,000 多名用户的数据。[@0x_kaize](https://x.com/0x_kaize) [把各条线索串联了起来](https://x.com/0x_kaize/status/2046534202498171186)（11 个赞，113 次浏览）则表示，Vercel 因 AI 工具 Context AI 被攻破，导致 580 名员工的 API 密钥、源代码和数据泄露，并被挂牌以 200 万美元、以 BTC 计价出售。他还引用了一组统计：“45% 的 AI 生成代码包含安全漏洞。仅 2026 年 3 月，就有 35 个新的 CVE 直接由 AI 生成代码导致。”

[@Replit](https://x.com/Replit) [主动回应了](https://x.com/Replit/status/2046712510703951904)（10 个赞，1,936 次浏览）转发了 CTO [@lhchavez](https://x.com/lhchavez) 关于安全架构的一篇详细帖子：“Replit 基础设施中每一层运行客户代码的环境，都是按纵深防御设计的。没有任何单一控制措施会成为最后一道防线。每一层都假设其上一层可能失效。”

**与前一天相比：** 昨天，安全还只是背景性担忧。今天，它成了主导议题：三大主流代理同时曝出一个 CVSS 9.4 漏洞，Antigravity 出现 RCE，针对 Antigravity 用户的供应链攻击、一个 vibe 编程平台数据泄露事件，以及 Vercel 通过 AI 工具遭入侵。攻击面扩张的速度快于防御能力的提升。

The Antigravity RCE was exploitable via search tool input. Fake Antigravity installers deploy credential-stealing malware. No vendor provides a unified security layer for AI agent deployments. A platform that monitors agent trust boundaries, sandboxes untrusted inputs, audits credential exposure, and applies least-privilege policies across Claude Code, Codex, and Copilot would address a structural gap that is being actively exploited.
