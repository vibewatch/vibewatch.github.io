## 2. What Frustrates People

### CLI-based API substitution may not remove usage constraints

Severity: Medium. The developer's motivation was to use an Antigravity subscription instead of Gemini API calls, but replies said the normal usage limits still apply and raised an integration concern. The small test worked, but the discussion showed that cost and integration tradeoffs remained. Worth building for: Medium.

### One provider test needed repeated retries

Severity: Low. In a developer-run comparison using the same harness and prompt, one CommandCode GOAT run failed after repeated retries but eventually produced working code. [@nothingto12](https://x.com/nothingto12) [reported](https://x.com/nothingto12/status/2114460558758236351) (94 likes, 18 replies, 3,041 views, 39 bookmarks) this single result; it is not enough to rank providers generally.

The attached screenshot records one test: DeepSeek API completed in 54 minutes 12 seconds at 211 tokens per second with no failed calls; OpenCode Go took 1 hour 17 minutes 37 seconds at 159 tokens per second with three failed calls; CommandCode GOAT was marked failed after 2 hours 28 minutes 4 seconds at 140 tokens per second, with 91 failed calls.

![Single-run benchmark comparison of DeepSeek API, OpenCode Go, and CommandCode GOAT showing run status, time, throughput, and failed calls](https://pbs.twimg.com/media/HVgPrViXAAAMyHY.jpg)

Worth building for: Low, as a reliability signal to include in repeatable evaluations.

## 3. What People Wish Existed

### A durable map of how a codebase fits together

Graphify's pitch is that agents should query a persistent map rather than repeatedly search files and lose the trail as context fills. Its repository provides a working implementation, but the post does not compare the approach with existing language-specific indexes. Opportunity: Competitive.

### One control surface for specialized agent harnesses

HarnessRouter's described coordinator pattern addresses the cost of wiring each model or coding agent separately and allows task-specific routing. It is an open-source project, though the feed did not provide independent results on its reliability or deployment effort. Opportunity: Direct.

## 7. Where the Opportunities Are

**[+++] Persistent project context across agents** - Graphify, reusable engineering skills, and HarnessRouter address repository rediscovery, repeated methods, and fragmented tool integrations from different directions.

**[++] Task-specific model and harness routing** - The coordinator pattern and CLI experiments show interest in choosing tools per task, but the feed does not establish reliability or cost advantages across providers.

**[+] Clear quota and integration boundaries** - The headless CLI workaround drew attention to subscription limits and integration concerns, suggesting a need for supported, predictable ways to connect local applications to agent plans.
