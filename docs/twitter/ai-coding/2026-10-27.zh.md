## 2. 大家感到困扰的地方

### 通用代码审查可能牺牲覆盖面，以换取更高置信度

阿里巴巴的代码仓库指出，通用智能体可能会跳过文件、无法准确定位代码行，也可能因提示词稍有变化而给出不同结果。该项目自己的基准测试说明称，Open Code Review 更注重精确率而非召回率，因此在减少误报的同时，也有可能漏掉部分缺陷。这些是项目方报告的局限和权衡，并非独立对比结果。[仓库](https://github.com/alibaba/open-code-review)；[公告](https://x.com/thisdudelikesAI/status/2115010135588589932)（29 个赞、17 条回复、1,088 次浏览）。

## 6. 新动态与值得关注的项目

### 阿里巴巴开源内部代码审查助手
