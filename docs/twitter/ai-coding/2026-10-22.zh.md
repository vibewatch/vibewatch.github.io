## 1. 大家在讨论什么

### 1.1 Agent Skills 开始走向共同治理 (🡕)

Anthropic 表示，将把 Agent Skills 捐赠给 Agentic AI Foundation；该基金会此前也接收了 MCP。帖子称，已有 70 多个智能体平台集成了这项标准，其中包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code。回复提到，许可条款保持不变，且有多家智能体厂商参与。

[@ClaudeDevs](https://x.com/ClaudeDevs) [宣布](https://x.com/ClaudeDevs/status/2113328526413996100)（2,083 个赞，105 条回复，110,245 次浏览，437 次收藏）这条帖子介绍了这项捐赠及平台采用情况。

### 1.2 智能体产出了视觉作品和应用成品 (🡕)

Google 展示了一个由单张图像生成、会随音频变化的 3D 大教堂场景，使用了 Gemini 4 Argon、Antigravity 和 Blender MCP。OpenAI 则宣布 Decisions API 已进入正式可用阶段，并展示了 Codex 对一款小型演示应用的重新设计。

[@Google](https://x.com/Google) [展示](https://x.com/Google/status/2113353489938075794)（413 个赞，59 条回复，136,956 次浏览，171 次收藏）展示了生成的场景。[@romainhuet](https://x.com/romainhuet) [宣布](https://x.com/romainhuet/status/2113369156838121938)（336 个赞，55 条回复，23,052 次浏览，49 次收藏）介绍了 Decisions API 的发布和 Codex 演示。

### 1.3 参考资料正被整理成便于智能体检索的形式 (🡕)

一项新技能可以把书籍和文档文件夹转换成结构化参考资料，供智能体在工作时查阅。另一个项目则能将提示词转换成可编辑的 HTML 和 SVG 图表，供多种编程助手使用。

## 2. 大家感到沮丧的地方

### 任务之间的参考知识容易丢失

严重程度：中等。书籍转技能的帖子指出了一个常见问题：开发者会忘记有用资料存放在哪里，或把整份文档粘贴到智能体会话中，以便找回所需内容。该工具提出的方案是生成结构化参考资料；不过，帖子中提到的 token 节省量是作者的说法，并未经过独立验证。[@RoundtableSpace](https://x.com/RoundtableSpace) [介绍](https://x.com/RoundtableSpace/status/2113227616299942097)（77 个赞，6 条回复，46,673 次浏览，45 次收藏）介绍了这套工作流程。值得构建的程度：中等。

在所选讨论中，没有发现其他明显的挫败信号。

## 3. 大家希望出现什么

### 可移植、受共同治理的智能体指令

Agent Skills 的捐赠，以及跨工具指令集合的出现，都表明人们希望指令能在不同助手之间迁移，同时保持许可和格式不变。信息流中的内容无法证明各个平台对这项标准的实现是否一致。机会类型：直接。

### 无须在每条提示中塞入大量内容，也能随时调用的参考资料

book-to-skill 可以将书籍或文档文件夹转换成按章节组织的智能体参考资料，而 Diagram Design 可以生成可编辑的 HTML 和 SVG。两者解决的是不同需求：从自有源材料中检索信息，以及生成可随项目变化而修改的图表。机会类型：竞争性。

## 4. 正在使用的工具和方法

| 工具 | 类别 | 评价 | 优势 | 局限 |
|---|---|---|---|---|
| Agent Skills | 智能体指令标准 | (+) | 已捐赠给共同基金会；多个平台正在使用 | 尚未衡量各平台实现的一致性 |
| book-to-skill | 知识检索 | (+) | 将书籍和文档文件夹转换成可重复使用的参考资料 | 节省 token 的数据由作者提供 |
