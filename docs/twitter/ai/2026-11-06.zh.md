# Twitter AI - 2026-11-06

## 1. 大家在讨论什么

### 1.1 评估正转向任务完成度和可重复性（→）

四篇关于基准测试的帖子衡量了静态模型排名可能无法体现的能力：反复进行科学推理、在生成过程中编辑视频、设置产品，以及完成类似工作任务的表现。[@ArtificialAnlys](https://x.com/ArtificialAnlys) [报告称](https://x.com/ArtificialAnlys/status/2118752670030700953)（97 个赞、21 条回复、11,161 次浏览）指出，VIALS-AA 测试了涵盖八个领域的 161 项视觉生命科学任务，只有模型在三次运行中均成功完成某项任务，该任务才计为通过。测试结果也体现了成本差异：Sol 的得分为 59%，每项任务成本约为 $0.056；得分最高的 Gemini 4 Carbon 得分为 64%，成本约为前者的 23 倍。

![VIALS-AA 模型得分与成本对比](https://pbs.twimg.com/media/HWdSUyKWoAEMJ-M.jpg)

[@alifcoder](https://x.com/alifcoder) [概述](https://x.com/alifcoder/status/2118680759758442694)（14 个赞、13 条回复、1,023 次浏览）StreamEval 测试流式视频模型能否遵循不断变化的指令、保持状态并编辑生成内容。帖子称，测试评估了 38 个模型；[论文](https://arxiv.org/abs/2610.28402) 报告了其中 37 个模型的结果。测试包含 300 个脚本化案例和十项指标，涵盖五类任务。

![StreamEval 排行榜与任务覆盖范围](https://pbs.twimg.com/media/HWcQ66Ab0AA6jZv.png)

![StreamEval 基准测试任务示例](https://pbs.twimg.com/media/HWcQ7GIbMAAGkyn.png)

[@Tabbu_ai](https://x.com/Tabbu_ai) [重点介绍](https://x.com/Tabbu_ai/status/2118801890280689947)（35 个赞、8 条回复、2,438 次浏览）介绍了 Scope 的数据库基准测试：在 18 款托管产品中，1,035 次智能体会话里只有 16.6% 成功获得首个可用结果。[排行榜](https://www.tryscope.com/leaderboard/databases) 记录了各类障碍，包括验证码、机器人拦截、邮箱域名遭拒，以及仅支持 OAuth 登录；其中 50 次成功会话在创建账户前使用了可用数据库。@Tabbu_ai 明确表示，希望看到更多针对智能体在真实产品中表现的评估。

[@DanielMiessler](https://x.com/DanielMiessler) [表示](https://x.com/DanielMiessler/status/2118820785888633321)（2 条回复、770 次浏览）表示，Artificial Analysis 的基准测试结果与他的实际体验不符，并介绍了自己构建 Explain、Science 和 Ship 基准测试的过程。[实时仪表板](https://thebenchmarks.ai) 将模型得分与成本并列展示；这是他自己的比较，并非独立验证。

![Daniel Miessler 的基准测试仪表板，对比得分与成本](https://pbs.twimg.com/media/HWePng6agAAhmBU.jpg)

### 1.2 模型和加速方面的说法也有证据局限（→）

[@ChinmayKak](https://x.com/ChinmayKak) [提供](https://x.com/ChinmayKak/status/2118795521196458187)（11 个赞、554 次浏览）提出了另一种解读：基准测试套件本身也可能随时间变化。该帖并未证实这一说法，但其中的图表是当天讨论如何解读加速估算时引用的内容之一。

## 2. 人们感到挫败的地方

### 智能体接入在产出首个有用结果前就受阻

在 Scope 的测试环境中，1,035 次会话里只有 16.6% 成功连接到可正常使用的数据库；373 次会话卡在 CAPTCHA 验证，另有 105 次遭到机器人拦截。18 款产品中有 7 款没有任何一次成功会话。允许智能体在创建账户前使用可正常运行的数据库，在 50 次成功运行中起到了帮助作用。这是基准测试中发现的一个具体障碍，并不代表所有开发者产品的情况。**严重程度：在测试任务中为高。产品开发启示：有充分依据支持构建适配智能体的接入流程，但其普遍程度尚未测定。** [@Tabbu_ai](https://x.com/Tabbu_ai) [总结](https://x.com/Tabbu_ai/status/2118801890280689947)（35 个赞、8 条回复、2,438 次浏览）提到了 [结果与排行榜](https://www.tryscope.com/leaderboard/databases)。

### 信任与协调仍是明显的失效点

[@swangentr](https://x.com/swangentr) [推广](https://x.com/swangentr/status/2118739597240775129)（96 个赞、8 条回复、19,722 次浏览）讨论了一款金融助手。在相关回复中，[@ProjectAglaya](https://x.com/ProjectAglaya) [表示](https://x.com/ProjectAglaya/status/2118742522424082711)（47 次浏览）提到，用户需要能在不可逆操作前行使否决权；[@kylekane](https://x.com/kylekane) [询问](https://x.com/kylekane/status/2118743823472017834)（57 次浏览）则提出了哪些检查能避免不良建议的问题。[@TammyBuilds](https://x.com/TammyBuilds) [报道](https://x.com/TammyBuilds/status/2118748752005538278)（9 个赞、17 条回复、300 次浏览）提到，把 16 个智能体放进一个聊天群后出现的 token 浪费和相互诱发幻觉。这些都是个别报告，因此发生频率未知。**严重程度：在所述工作流程中为中等。产品开发启示：可探索审批关卡、边界明确的交接以及独立审查。**

### 基准测试结果未必符合用户的实际工作需求

[@DanielMiessler](https://x.com/DanielMiessler) [表示](https://x.com/DanielMiessler/status/2118820785888633321)（2 条回复、770 次浏览）称，Artificial Analysis 的基准测试结果与他的实际体验不符，并构建了三个替代方案。另外，METR 表示，其 AECI 趋势估算取决于分析方法的选择，未必能推广到更广泛的任务。这说明排行榜与实际工作流程之间的匹配度确实有限，但相关讨论并未说明这种不匹配有多普遍。 **仅凭评分选择系统，风险程度为中等。开发信号：围绕用户的实际任务开展评测，并明确说明不确定性，信号强度为中等。**

## 3. 人们希望拥有的东西

### 增加对真实产品和重复执行表现的评测

[@Tabbu_ai](https://x.com/Tabbu_ai) [表示](https://x.com/Tabbu_ai/status/2118801890280689947)（35 个赞、8 条回复、2,438 次浏览）：“我们需要更多这样的基准测试”，指的是 Scope 对智能体创建和使用真实数据库产品的测试。其他帖子评测了重复成功率或交互式执行能力，但只有一篇帖子明确提出了这一需求。**需求：**务实，而非情绪诉求。**机会：直接。**

### 在智能体执行重大操作前设置人工否决权

在有关金融助理的讨论中，[@ProjectAglaya](https://x.com/ProjectAglaya) [表示](https://x.com/ProjectAglaya/status/2118742522424082711)（47 次浏览）有人提出，执行不可逆操作前，人们必须能够说“不”；[@kylekane](https://x.com/kylekane) [询问](https://x.com/kylekane/status/2118743823472017834)（57 次浏览）则有人询问，哪些检查机制能够防止给出不当建议。这是小范围讨论中明确提出的一项控制要求，但不足以证明需求普遍存在。**需求：**务实且后果重大。**机会：直接，但证据范围有限。**

## 8. 要点

1. **智能体往往还没开始完成有用的工作就已失败。** Scope 对 1,035 次数据库设置会话进行了测量，发现首次成功获得可用结果的比例为 16.6%；注册流程和机器人防护都是其中的阻碍因素。 [@Tabbu_ai](https://x.com/Tabbu_ai) [总结](https://x.com/Tabbu_ai/status/2118801890280689947)（35 个赞，8 条回复，2,438 次浏览）这项基准测试。
2. **可重复性和成本会影响人们对模型表现的判断。** VIALS-AA 仅将三次尝试均通过的任务计入统计，并报告称，得分相近的模型之间成本差异很大。[@ArtificialAnlys](https://x.com/ArtificialAnlys) [报道称](https://x.com/ArtificialAnlys/status/2118752670030700953)（97 个赞，21 条回复，11,161 次浏览）这些结果。
3. **智能体自主行动需要明确的边界。** 当天的案例包括：有人提出，在执行不可逆的金融操作前应允许人工否决；一位开发者报告称，16 个智能体的群聊中出现了协调问题。[@ProjectAglaya](https://x.com/ProjectAglaya) [表示](https://x.com/ProjectAglaya/status/2118742522424082711)（47 次浏览）否决权很重要；[@TammyBuilds](https://x.com/TammyBuilds) [报道称](https://x.com/TammyBuilds/status/2118748752005538278)（9 个赞，17 条回复，300 次浏览）群聊中的协调问题。
4. **开放机器人和本地推理在各自不同的约束下不断发展。** 机器人相关帖子展示了可复用的数据和公开的真实世界评测；本地推理方面的报告则指出，需要在内存容量、速度和成本之间权衡。[@ClementDelangue](https://x.com/ClementDelangue) [报道称](https://x.com/ClementDelangue/status/2118751330927780154)（104 个赞，30 条回复，5,435 次浏览）机器人领域的发布与评测活动。
