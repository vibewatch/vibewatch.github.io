## 2. What Frustrates People

### Intent-following gaps

One user says a faster model was less useful because it did not respect user intent, and a reply makes the distinction between intelligence and usefulness on underspecified tasks. This is a single-user report with one agreeing response, so prevalence is unknown.

### Shallow implementation claims

The workflow-redesign post criticizes prompt workshops and narrow integrations as insufficient for organizational change. Because the author is promoting their own services, this should be read as a builder’s perspective rather than a measured industry finding.
