## 1. 人们在讨论什么

### 1.1 SubQ 发布：其次二次复杂度架构宣称可取代 Transformer 🡕

当天最受关注的新闻是 Subquadratic 发布 SubQ。这款基于稀疏注意力的模型宣称打破了二次扩展瓶颈。[@MilkRoadAI](https://x.com/MilkRoadAI) [强调](https://x.com/MilkRoadAI/status/2051821820886864275)（282 个赞、36 次转发、9 次引用、357 次收藏、57,121 次浏览）发布了当天互动最高的公告：“SubQ 从底层开始就是为了解决这个问题而构建的。SubQ 不再处理每一种可能的 token 关系，而是识别哪些关系真正重要，并忽略其余部分……在 1,200 万 token 下，与标准前沿模型相比，SubQ 将注意力计算量降低了近 1,000 倍；在 100 万 token 下，它比 FlashAttention 快 52 倍。”成本方面，其宣称“每百万 token 成本低于 1.50 美元，不到 Claude Opus 收费的 5%。在 RULER 基准上，用 SubQ 跑测试成本为 8 美元，而用 Claude Opus 跑同样测试成本为 2,600 美元。”

[@bindureddy](https://x.com/bindureddy) [呼应](https://x.com/bindureddy/status/2051790195423605236)（294 个赞、20 次转发、5 次引用、98 次收藏、21,386 次浏览）：“SubQ 这种新型 AI 模型宣称比 Opus 4.7 和 GPT 5.5 快 50 倍、便宜 20 倍……如果属实，这将是石破天惊的——Anthropic/OpenAI 的估值会归零。”

![SubQ 基准测试对比图表](https://pbs.twimg.com/media/HHlrdO9bsAA1w0t.jpg)

[@alex_whedon](https://x.com/alex_whedon) 发布的原始公告将 SubQ 描述为“首个基于完全次二次复杂度稀疏注意力架构（SSA）构建的模型，也是首个拥有 1,200 万 token 上下文窗口的前沿模型”。Subquadratic 以 2,900 万美元融资启动，API 今日开放早期访问。

**讨论洞察：** 回复区整体以质疑为主。[@HouMuza](https://x.com/HouMuza) 回复称：“我对这些说法持怀疑态度。既然声称是这么大的转变，他们发布时就应该附上技术论文。他们说论文会来，但走着瞧吧。也可能只是我太怀疑了，不过稀疏注意力并不新鲜，最近 DeepSeek 的论文就用了。” [@samarthg1911](https://x.com/samarthg1911) 问道：“证据在哪？现在都只是说法。” [@homeMetaX](https://x.com/homeMetaX) 提醒：“RULER 或 SWE Bench 这样的基准是有用信号，但并不能完整反映真实世界表现……过去很多‘突破性架构’在受控测试中看起来很强，但扩展到大规模时却表现不佳。” [@adampatricknc](https://x.com/adampatricknc) 则反驳 bindureddy：“如果它真这么高效，为什么不直接上线提供服务，而要搞‘早期访问’报名？”

**与前一天相比：** 5 月 5 日的焦点还是现有 Transformer 模型之间的基准碎片化（GPT-5.5、Opus 4.7、Grok 4.3）。今天则引入了一个潜在的范式转移——不再只是讨论哪个 Transformer 最好，而是 Transformer 本身是否还是正确的架构。由于发布时没有技术论文，这波热度被明显降温。

### 1.2 Google 为 Gemma 4 推出多 token 预测——无需新模型即可提升推理速度 🡕

[@WesRoth](https://x.com/WesRoth) [报道](https://x.com/WesRoth/status/2051874596102525042)（103 个赞、14 次转发、2 次引用、43 次收藏、9,887 次浏览）介绍了 Google 为 Gemma 4 发布的多 token 预测草拟器：“标准大语言模型通常以自回归方式生成文本，每次只生成一个 token，这会造成内存带宽瓶颈。新的推测解码架构使用轻量级草拟模型，同时预测多个未来 token。”关键数据是：输出速度提升 3 倍且无质量损失；该功能以 Apache 2.0 许可在 Hugging Face 和 Kaggle 上提供，并兼容 vLLM、MLX、SGLang 和 Ollama。

[@googledevs](https://x.com/googledevs) [宣布](https://x.com/googledevs/status/2051700498328346945)：“Gemma 4：现在最高可快 3 倍。质量不变，速度大幅提升。”

**讨论洞察：** [@rameswar08](https://x.com/rameswar08) 回复称：“总算看到真正的推理提速进展了，而不是一味堆更大的模型。” [@wire_agent](https://x.com/wire_agent) 提出了技术问题：“这些草拟器的接受率是多少，还是说 3 倍只是吞吐上限？”回复反映出，相比继续扩大参数规模，社区更期待推理优化。

**与前一天相比：** 5 月 5 日主导模型叙事的是新模型发布（GPT-5.5 成为 ChatGPT 默认模型）。今天的重点则转向让现有模型跑得更快——这是行业成熟的信号。SubQ（1.1）和 Gemma MTP 都代表了相对于蛮力扩展的架构创新。

## 2. 人们在抱怨什么

### 架构宣称没有技术论文支撑——高

## 7. 机会在哪里

**[+++] Sub-quadratic inference infrastructure and cost arbitrage** -- SubQ claims 300x cost reduction at equivalent accuracy. Even if the actual gains are 10-30x (accounting for hype), any production-ready sparse attention system that meaningfully reduces cost-per-token creates massive arbitrage against current frontier pricing. The opportunity is either: (a) building on SubQ's architecture if verified, (b) building competing sparse attention implementations, or (c) building tooling that lets enterprises evaluate and migrate between inference backends as costs drop. The 357 bookmarks on [@MilkRoadAI](https://x.com/MilkRoadAI) 的帖子表明，商业兴趣很高。（[来源](https://x.com/MilkRoadAI/status/2051821820886864275)、[来源](https://x.com/bindureddy/status/2051790195423605236)）

**[+++］ Agent 安全基础设施（生产级确定性护栏）** -- 今天有三个独立项目同时发布，聚焦 Agent 安全：Sponsio（确定性防火墙）、Future AGI（测试/评估），以及 Clay 借助 LangSmith 给出的 3 亿 Agent 验证案例。供给侧建设与需求侧规模的汇合（单家公司每月 3 亿次运行）表明，这一市场正在形成。当前缺口在于：尚无占主导地位的平台能在单一产品中同时整合策略定义、运行时执行、成本监控和轨迹可观测性。(［来源](https://x.com/OvercookedJoJo/status/2052043556433633552)、[来源](https://x.com/iam_chonchol/status/2051949940918849740)、[来源](https://x.com/sofia_montoyac/status/2052127280403796159)）

## 8. 核心结论

1. **Transformer 架构迎来了首个可信的公开挑战者，但证据比宣称滞后数周。** SubQ 关于稀疏注意力的说法（计算量降低 1,000 倍、成本节省 300 倍、达到前沿级准确率）带来了当天最高互动（5.7 万次浏览、357 次收藏），也立刻引发怀疑。发布时没有技术论文，是最关键的缺口。哪怕这些说法只部分属实，所有 AI 提供商的经济模型都会改变；如果不属实，它就会成为 2026 年最醒目的“空气产品”。市场正在先为可能性定价，再等待证据。（[来源](https://x.com/MilkRoadAI/status/2051821820886864275)、[来源](https://x.com/bindureddy/status/2051790195423605236)）

2. **推理优化如今已成为首要竞争轴，而非模型规模。** Google 的 Gemma 4 MTP（快 3 倍、开源）、SubQ 的稀疏注意力（宣称快 52 倍）以及 Penguin Solutions 的 CXL 内存（避免 GPU 空转），都在瞄准同一个问题：如何让现有智能以更低成本、更高速度被提供出来。“只管把模型做大”的时代，正让位于“把模型跑得更好”。（[来源](https://x.com/WesRoth/status/2051874596102525042)、[来源](https://x.com/FinnStockinger/status/2051984034754949143)）

3. **中国 AI 模型正主导对成本敏感的全球部署，同时寻求西方资本。** OpenRouter 前五中有三个中国模型，80% 的开源初创公司在跑中国模型（a16z 数据），而 DeepSeek 正寻求 500 亿美元融资，以在全球扩展推理基础设施。所谓脱钩叙事因此变得复杂：中国模型已经凭借纯价格竞争嵌入了西方开发者工作流。（[来源](https://x.com/TheGeorgePu/status/2052065374540095954)、[来源](https://x.com/Reuters/status/2052049498273198495)）
