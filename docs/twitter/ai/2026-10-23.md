# Twitter AI - 2026-10-23

## 1. What People Are Talking About

### 1.1 Agentic model performance draws attention 🡕

[@ArtificialAnlys](https://x.com/ArtificialAnlys) [reported](https://x.com/ArtificialAnlys/status/2113688083145314416) (417 likes, 35 replies, 13,191 views) that Kimi K3.1 Pro scored 55 on its Intelligence Index, 11 points above Kimi K3, with larger gains on several agentic tasks. Its weights were not yet public in the announcement.

![Artificial Analysis Intelligence Index chart placing Kimi K3.1 Pro at 55, above Kimi K3 at 44](https://pbs.twimg.com/media/HVVTHDTaAAAyAl-.jpg)

### 1.2 Small-model gains vary by task 🡒

[@Raullen](https://x.com/Raullen) [compared](https://x.com/Raullen/status/2113716454571016261) (250 likes, 35 replies, 10,290 views) Nemotron 3.5 Bolt E4B with Qwen3.5-4B. The diagrams show different architectures and task-level results: Bolt’s post-training improves some scores, while Qwen leads on selected long-context and tool tasks. The author cautions that these comparisons do not establish architectural causality.

![Diagram comparing Nemotron Bolt and Qwen token-mixing architectures](https://pbs.twimg.com/media/HVVaIv9aQAAi_8x.jpg)

![Benchmark table comparing Gemma, Nemotron Bolt, and Qwen on instruction, agent, and long-context tasks](https://pbs.twimg.com/media/HVVcl5Eb0AA5K8f.png)

### 1.3 Agent security and local deployment add operational work 🡒

[@levie](https://x.com/levie) [framed](https://x.com/levie/status/2113738768645808277) (58 likes, 31 replies, 6,645 views) agent swarms as a defensive security use case and quoted EnclaveAI’s launch of an autonomous security service and live vulnerability feed. One reply cautioned that attackers also have access to agent swarms. Separately, [@Jhaddix](https://x.com/Jhaddix) [listed](https://x.com/Jhaddix/status/2113741754067546335) (60 likes, 4 replies, 2,686 views) several local-model hosting skills to learn, including storage offload, prompt caching, and inference-server choice.

**Comparison to prior day:** Yesterday’s posts emphasized agent standards and verification workflows; today the discussion shifts to model-level agent performance and concrete deployment products. [@ClaudeDevs](https://x.com/ClaudeDevs) [announced](https://x.com/ClaudeDevs/status/2113328526413996100) (320 likes, 28 replies, 15,590 views) the Agent Skills donation on October 22.
