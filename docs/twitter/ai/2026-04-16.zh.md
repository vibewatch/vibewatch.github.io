### 1.6 RL 中段训练改写 LLM 训练流程（🡕）

Meta 研究人员展示了，在预训练和后训练之间插入一个推理阶段，可以显著提升模型表现，从而挑战了“推理纯粹是后训练现象”的共识。

[@alex_prompter](https://x.com/alex_prompter) [详细介绍“thinking mid-training”论文](https://x.com/alex_prompter/status/2044807047817187588)（8 个赞、4 个收藏、687 次浏览）：Meta 让 Llama-3-8B 在任何指令微调之前，先基于原始预训练数据进行推理训练，在高难度数学基准（GSM8K、MATH-500、AMC23、Olympiad、GPQA-Diamond）上取得了 3.2 倍提升。关键洞察在于：预训练数据中存在潜在的推理机会，而现有训练流程都会将其丢掉。教师模型会在语义上合适的位置插入中间思考过程，随后通过中段 RL 训练去优化“思考本身的效用”——关注的不是任务是否完成，而是推理是否改善了下一个 token 的预测。

![Thinking Mid-training 架构图，展示了从 thinking augmentation、SFT mid-training、RL mid-training 到 RL post-training 的四个阶段](https://pbs.twimg.com/media/HGCdLCKagAAn8qz.jpg)**讨论洞察：** 论文发现，在训练中期切换到 RL，比单纯扩大 SFT 规模更省数据。将 SFT 步数从 7,800 增加到 10,500，准确率仅从 0.3346 提升到 0.3480；而在训练中期改用 RL 后，即便使用更少的 token，准确率也达到了 0.3785。经历过“思考”式中期训练的模型，在后训练全过程中都维持了更高的奖励。

**与前一天相比：** 新话题。这与当天数据集中出现 7 次的更广泛表述“RL 中期训练”相呼应，表明这正成为一个新兴研究方向。

## 6. 新动态与重要进展

### GitHub 通过 CLI 推出 Agent 技能管理

[@GHchangelog](https://x.com/GHchangelog) [宣布](https://x.com/GHchangelog/status/2044834471527027143)（10 个赞，6 个收藏）`gh skill`，这是 GitHub CLI 的一条新命令，可从代码仓库中发现、安装、管理和发布 AI Agent 技能。这些技能遵循开放的 Agent Skills 规范，可在 Copilot、Claude Code、Cursor、Codex 和 Gemini CLI 中运行。通过 git 标签进行版本锁定，并采用基于内容寻址的变更检测，为 Agent 配置带来了包管理器级别的供应链完整性。这是 GitHub 首次专门推动 AI Agent 能力分发方式的标准化。

### LLM 能向其他模型传递隐藏的行为特征

[@Analytics_699](https://x.com/Analytics_699) [分享了研究成果](https://x.com/Analytics_699/status/2044829197181583546)（11 个赞，6 个收藏）展示了 LLM 可以通过数据中的隐藏信号，把不受欢迎的特征传递给其他算法，而且即使清洗训练数据，这些特征仍会持续存在。在一项实验中，一个模型把对猫头鹰的偏好传递给了下游模型。[@pash22](https://x.com/pash22) [补充了背景信息](https://x.com/pash22/status/2044488296827343286)（1 次收藏，251 次浏览）：“用 AI 输出内容训练的大语言模型，可能会继承不良行为，即便这些行为并未直接出现在数据中。”研究结果表明，在利用 AI 生成的训练数据构建 LLM 时，需要进行更全面的安全检查。

## 8. 核心要点

1. **AI 金融工具正快速从基准测试走向实际部署的产品。** Claude 已获得对 TradingView 的完全控制权（286 次收藏、2.1 万次浏览），Anthropic 正将 Mythos 引入英国银行业，slashapp 则为其 AI 私人银行家筹集了 1 亿美元。交易、税务和银行代理的融合，表明 AI 原生金融正进入生产落地阶段。 ([来源](https://x.com/milesdeutscher/status/2044581570535911904))

2. **由 Princeton 牵头的联盟正推动开放世界评测，作为后基准测试时代的新范式。** 来自 13 家机构的研究人员认为，基准测试会系统性地扭曲能力衡量，因此提出改用长期、混杂且贴近现实世界的任务。他们的 CRUX 项目已经展示出代理可自主发布 iOS 应用。再结合面向长周期编程任务的 FrontierSWE，评测基础设施正在从第一性原理出发重建。 ([来源](https://x.com/sayashk/status/2044835523198370272))

3. **限制 AI 基础设施的关键约束不是 GPU 供应，而是供电能力。** 一名 Google 员工透露，生产级集群的可用性往往比芯片发布滞后 3—4 年，目前大多数工作负载仍运行在 H100 上，而电力保障是基础设施交易中“最重要的单一谈判筹码”。战略型 AI 实验室签下的合同价格可低至零售价的 20%—30%，相当于打 70%—80% 的折扣。 ([来源](https://x.com/RihardJarc/status/2044771812043616718))

4. **云端 AI 对隐私的侵蚀正引发有组织的反弹。** Perplexity 的 Personal Computer 功能因让云端 AI 完全访问本地文件系统和屏幕显示内容而招致尖锐批评（77 个赞）。《AI 风险评估法案》将要求在部署前进行测试。加拿大则建议强制标注 AI 内容。来自立法和消费者层面的多重信号都表明，对 AI 访问个人计算环境的限制可能会进一步收紧。 ([来源](https://x.com/SadlyItsBradley/status/2044880343463792936))

5. **在训练中段引入强化学习，可能重塑 LLM 训练流程。** Meta 展示称，在预训练与后训练之间插入一个推理阶段，可让模型在高难度推理基准上的表现提升 3.2 倍——基础模型相同、后训练相同，变化仅在于新增了一个此前无人采用的中间阶段。这一发现挑战了“推理纯属后训练现象”的主流共识。 ([来源](https://x.com/alex_prompter/status/2044807047817187588))

6.**GitHub 正在将代理技能的分发标准化，并将供应链安全内建其中。** 新的 `gh skill` CLI 为五大主流代理宿主平台上的 AI 代理配置带来了版本锁定、基于内容寻址的变更检测和不可变发布。这是首个专门用于将代理技能视为可审计、可版本管理的软件包，而非临时提示词文件的基础设施。 ([来源](https://x.com/GHchangelog/status/2044834471527027143))

7. **LLM 可能会悄然将不受欢迎的行为特征传播给下游模型。** 研究显示，模型会通过训练数据将隐藏偏好（痴迷猫头鹰）传递给其他模型，而且即使在数据清洗后，这种偏好仍会持续存在。随着越来越多模型基于 AI 生成的输出进行训练，这一发现意味着模型供应链中的安全风险可能会不断叠加。 ([来源](https://x.com/Analytics_699/status/2044829197181583546))
