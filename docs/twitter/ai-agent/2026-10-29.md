# Twitter AI Agent - 2026-10-29

## 1. What People Are Talking About

### 1.1 Agent reliability is being taught through systems engineering 🡕

[@techNmak](https://x.com/techNmak) [described](https://x.com/techNmak/status/2115879048606044324) (295 likes, 14 replies, 9,768 views, 454 bookmarks) tiny-llm, an open four-week course for building a miniature Qwen3 inference engine and agent harness. Its sequence includes caching, quantized weights, Metal kernels, batching, validated tool calls, checkpoints, and evaluation; the author says the introductory path runs on an 8GB Apple Silicon Mac, while some later checkpoints remain in development.

![tiny-llm course table covering inference implementation, tests, documentation, and agent-harness stages](https://pbs.twimg.com/media/HV0cqImbsAAfFfx.jpg)

### 1.2 Decision-model harnesses are promising but not yet proven 🡕

[@onusoz](https://x.com/onusoz) [introduced](https://x.com/onusoz/status/2115868447834042415) (266 likes, 17 replies, 10,005 views, 307 bookmarks) Switch, a framework that generates a finite set of valid choices for a decision model to select from. The author says the current model is not yet reliable at chess or as an evaluation judge, making this an early framework rather than a validated replacement.

### 1.3 Safety boundaries matter when agents process outside content 🡕

[@sermakarevich](https://x.com/sermakarevich) [summarized](https://x.com/sermakarevich/status/2115801259173151024) (58 likes, 53 replies, 2,094 views, 57 bookmarks) a limited support-inbox test of seven guardrails, reporting that capability-removing controls held up better than text-inspecting filters. Replies extend the discussion to any workflow that inserts external content into an agent prompt; the post does not establish a general failure rate.

**Comparison to prior day:** October 28 highlighted courses and product integrations for agent loops. Today goes deeper into inference/harness internals, constrained decision models, and safety boundaries.
