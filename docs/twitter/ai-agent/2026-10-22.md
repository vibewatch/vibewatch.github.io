# Twitter AI Agent - 2026-10-22

## 1. What People Are Talking About

### 1.1 Agent Skills moves into neutral governance 🡕

Anthropic announced that it is donating Agent Skills to the Agentic AI Foundation. [@ClaudeDevs](https://x.com/ClaudeDevs) [reported](https://x.com/ClaudeDevs/status/2113328526413996100) (1,228 likes, 72 replies, 57,510 views, 219 bookmarks) that 70+ agent platforms had integrated the standard since December 2025. A follow-up post named versioned releases, a formal proposal process, and security guidance as the committee's first priorities.

### 1.2 Coding-agent evaluation tests whether later changes break earlier work 🡕

SlopCodeBench evaluates agents on a sequence of changing requirements with regression tests for earlier features. [@NotRyanB](https://x.com/NotRyanB) [reported](https://x.com/NotRyanB/status/2113357440959791299) (25 likes, 8 replies, 1,607 views) a leading strict score of 16.33% versus 69.39% core-only success in the reviewed chart, while cautioning that the small run set and uncustomized harness do not establish a definitive model ranking.

![SlopCodeBench chart comparing strict full-suite success with core-only success](https://pbs.twimg.com/media/HVQhEXKXoAAfEmj.jpg)

### 1.3 Agents are reported in production lending workflows 🡒

A lender case study describes building ACH, underwriting, and syndicator systems with two engineers inside an existing production platform. [@mardehaym](https://x.com/mardehaym) [reported](https://x.com/mardehaym/status/2113235089513423216) (49 likes, 35 replies, 11,176 views, 28 bookmarks) successive cycle-time reductions, specifications before implementation, tests-first development, automated checks, and human review before merge. This is a vendor case study, not an independent productivity benchmark.

![Lender systems diagram showing the business core, shared data, and integrations](https://pbs.twimg.com/media/HVO4HOPX0AEnPDM.jpg)

## 2. What Frustrates People

### Regressions and missing operating context

SlopCodeBench's strict score is much lower than its core-only score in the reviewed run, illustrating how later changes can pass new-feature checks while breaking earlier behavior. The lender case identifies missing architecture context, discoverable build and test commands, consistent module patterns, and reusable procedures as practical gaps; its authors added context files and automated verification before delivering changes.

## 3. What People Wish Existed

### Portable skills with formal change and security processes

The Agent Skills announcement describes a standard intended for shared use; its governance follow-up names versioned releases, proposals, and security guidance as priorities. [@ClaudeDevs](https://x.com/ClaudeDevs) [outlined](https://x.com/ClaudeDevs/status/2113328529911730587) (142 likes, 5 replies, 12,033 views, 41 bookmarks) that work. **Opportunity: direct and emerging**; the post states concrete governance needs, but the resulting controls are not yet described.

### Benchmarks for evolving requirements

SlopCodeBench is presented as a way to test whether agents preserve earlier requirements as a codebase changes. The author [explains](https://x.com/NotRyanB/status/2113357440959791299) (25 likes, 8 replies, 1,607 views) the benchmark's sequence of changing specs and regression tests, while cautioning that its small run set limits ranking claims.
