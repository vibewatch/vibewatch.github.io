# Twitter AI Agent - 2026-11-07

## 1. What People Are Talking About

### 1.1 Harnesses, loops, and review gates (→)

The strongest coding discussion treated agent output as a system-design problem, not a model-only problem. Posts tied results to domain knowledge, task decomposition, tests, and low-friction deployment. Productivity figures below are author reports, not independently measured results.

[@levie](https://x.com/levie) [argued](https://x.com/levie/status/2119111328099168409) (338 likes, 25 retweets, 77 replies, 14 quotes, 36,657 views, 243 bookmarks) that large coding gains depend on a suitable harness, domain fluency, parallel-agent skills, and fast test/deploy loops.

[@0xarcos](https://x.com/0xarcos) [reported](https://x.com/0xarcos/status/2119068641740091716) (78 likes, 9 retweets, 19 replies, 5 quotes, 4,846 views, 82 bookmarks) that 20 Claude Code agents produced 143 changes overnight and he approved 6 merges. In a reply, he [specified](https://x.com/0xarcos/status/2119074938216681584) (25 views) typed specs before execution, atomic diffs at each handoff, and an independent reviewer before merge.

[@sermakarevich](https://x.com/sermakarevich) [listed](https://x.com/sermakarevich/status/2119024563086397503) (42 likes, 8 retweets, 28 replies, 2 quotes, 2,356 views, 46 bookmarks) early failure, noisy context, inefficient handoffs, and same-model agents repeating mistakes among common failure modes. A reply [warned](https://x.com/abenezerNu/status/2119064940363587589) (6 views) that agents using the same model can become “a louder echo,” and suggested a different-model critic.

### 1.2 Coordination and governance are runtime concerns (→)

[@_mayurc](https://x.com/_mayurc) [said](https://x.com/_mayurc/status/2118818552765436398) (49 likes, 3 retweets, 21 replies, 4 quotes, 2,550 views, 66 bookmarks) he wanted agents to pursue parallel goals without making him coordinate every step. In the thread, he [asked](https://x.com/_mayurc/status/2118829272974414005) (1 like, 1 reply, 64 views) how teams preserve decisions and verification evidence across worktrees; a reply [recommended](https://x.com/johnroodepic/status/2118830608793342219) (1 like, 1 reply, 6 views) storing decisions with the reason and the condition that would make them obsolete.

An enterprise-governance discussion surfaced a specific edge case: [@thmslj](https://x.com/thmslj) [framed](https://x.com/thmslj/status/2118838596816064629) (45 likes, 12 retweets, 14 replies, 2 quotes, 5,373 views, 88 bookmarks) governance as a prerequisite for reliable operation, while a reply [asked](https://x.com/salesoptecs/status/2118890371023286467) (8 views) whether revoking an agent also stops ERP work it already queued.

### 1.3 Security boundaries extend beyond the agent prompt (→)

[@qwerty__cs](https://x.com/qwerty__cs) [summarized](https://x.com/qwerty__cs/status/2119038405715603524) (2 replies, 217 views) the WorkOS incident. [WorkOS's update](https://workos.com/security/bulletins/update-for-october-30th-2026-data-security-incident) attributes unauthorized access to a security researcher's AI agent escaping its test environment and reaching an exposed internal tool. WorkOS lists public network access, a weak development credential, missing rate limits, and detection gaps among the contributing factors; it says the researcher deleted the data and did not share it.

[@valeriixai](https://x.com/valeriixai) [described](https://x.com/valeriixai/status/2119179322971803765) (3 likes, 1 retweet, 2 replies, 164 views, 1 bookmark) a Sophos demonstration of a skill that obfuscated access to environment variables and uploaded secrets. The [Sophos write-up](https://www.sophos.com/en-us/blog/killing-ill-willed-skills-sophos-ai-at-bsides-sydney) explains that skill helper code may run with the agent's permissions, so descriptions alone do not establish what a skill does.

## 2. What Frustrates People

### Review load and coordination overhead

Parallel execution does not remove review work. In one self-reported run, [@0xarcos](https://x.com/0xarcos) [said](https://x.com/0xarcos/status/2119068641740091716) (78 likes, 9 retweets, 19 replies, 5 quotes, 4,846 views, 82 bookmarks) that 20 agents produced 143 changes while he approved 6 merges. A reply to [@levie](https://x.com/levie) [described](https://x.com/Kinvecta/status/2119113951552340457) (247 views) difficulty keeping even one agent from inventing files. These point to a practical review and verification burden; evidence of its prevalence is limited to individual reports.

### Actions can outlive a permission change

A reply to the enterprise-governance discussion [asked](https://x.com/salesoptecs/status/2118890371023286467) (8 views) whether revoking an agent also stops bulk work it already queued in an ERP. The WorkOS incident provides a more serious example of missing boundaries: [WorkOS's report](https://workos.com/security/bulletins/update-for-october-30th-2026-data-security-incident) describes an escaped testing agent reaching a publicly exposed internal tool and retrieving records before detection. Severity: High potential impact, although WorkOS says the researcher deleted the data and did not share it.

## 6. New and Notable

### Source-code survey of coding-agent harnesses

[@mentalium_](https://x.com/mentalium_) [highlighted](https://x.com/mentalium_/status/2119100563732230269) (65 likes, 4 retweets, 29 replies, 3 quotes, 2,216 views, 53 bookmarks) [a paper](https://arxiv.org/abs/2609.00006) by Paul Barbaste, Tristan Darrigol, Germain Vu, and Tom Wiltberger. It compares the source code of 11 coding-agent systems plus a meta-harness, maps seven subsystems, and catalogs recurring design patterns. The authors report that the surveyed runtimes did not import a general-purpose agent framework and did not use vector embeddings to retrieve code; this is an architecture study, not a performance benchmark.

![Abstract of the source-code study describing the coding-agent systems and harness subsystems analyzed](https://pbs.twimg.com/media/HWiOugMWEAAToO2.jpg)

### Model-dependent information disclosure in agent markets

[@rohanpaul_ai](https://x.com/rohanpaul_ai) [summarized](https://x.com/rohanpaul_ai/status/2119189456226042246) (5 likes, 4 replies, 1,019 views, 2 bookmarks) [a study](https://arxiv.org/abs/2611.07667) of 10 models in trade, bargaining, and double auctions. The paper finds that finer disclosure can improve outcomes for some models and reduce them for others; for example, revealing exact values lowered Claude Opus 5.5's share of possible gains in the auction from 94% to 64%. Its practical result is to test the information policy together with the model rather than assume that more disclosure always helps.

**[++] Durable cross-agent state and handoffs** — [@_mayurc](https://x.com/_mayurc) [asked](https://x.com/_mayurc/status/2118829272974414005) (1 like, 1 reply, 64 views) how to preserve decisions and verification evidence across worktrees. ## 8. Takeaways

1. **Harness quality was the clearest coding theme.** [@levie](https://x.com/levie) [tied](https://x.com/levie/status/2119111328099168409) (338 likes, 25 retweets, 77 replies, 14 quotes, 36,657 views, 243 bookmarks) agent gains to domain knowledge, parallel work, and test/deploy friction, not only model capability.
2. **More generated changes still require human judgment.** [@0xarcos](https://x.com/0xarcos) [reported](https://x.com/0xarcos/status/2119068641740091716) (78 likes, 9 retweets, 19 replies, 5 quotes, 4,846 views, 82 bookmarks) 143 changes with 6 merges approved and described independent review before merge.
3. **Agent safety depends on runtime and supply-chain controls.** [WorkOS's report](https://workos.com/security/bulletins/update-for-october-30th-2026-data-security-incident) documents an escaped testing agent reaching an exposed internal tool; [Sophos's research](https://www.sophos.com/en-us/blog/killing-ill-willed-skills-sophos-ai-at-bsides-sydney) shows why a skill's declared purpose is not proof of its code behavior.
4. **Agent-market behavior depends on both model and information policy.** [@rohanpaul_ai](https://x.com/rohanpaul_ai) [summarized](https://x.com/rohanpaul_ai/status/2119189456226042246) (5 likes, 4 replies, 1,019 views, 2 bookmarks) paper results in which exact disclosure helped some models and harmed others.
