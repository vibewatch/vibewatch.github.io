## 2. 什么让人沮丧

### Token 成本与优化复杂性

[@akshay_pachaar](https://x.com/akshay_pachaar) [量化了](https://x.com/akshay_pachaar/status/2051589749689962949)（130 次点赞、223 次收藏、24291 次浏览）展示了显著节省：“Claude Code 只改了一个地方，Token 用量就少了 3 倍：改动前：10.4M tokens、10 个错误、$9.21。改动后：3.7M tokens、0 个错误、$2.81。”修复方法是使用“Insforge Skills + CLI 作为后端上下文工程层”——这意味着，开箱即用的代理配置可能在无谓烧钱。

### 多代理信心漂移

[@om_patel5](https://x.com/om_patel5) [警告](https://x.com/om_patel5/status/2051499323012108543)（5 次点赞、2 次收藏、395 次浏览）指出，在多代理配置中，“两个 AI 模型可能会让彼此显得更有把握、共同产生幻觉，同时悄悄偏离你真正提出的要求”。这种失效模式很隐蔽：每个代理都在验证另一个代理的输出，形成一个看似正确、实则已经偏离原始意图的闭环。

### 技能信任模型“靠感觉”

[@yzg75001](https://x.com/yzg75001) 在回复 @omarsar0 时承认：“我一直在生产环境中运行代理技能，而现在的信任模型基本上就是靠感觉——签名技能 = 可信，这太离谱了。供应链攻击这个向量是真实存在的。”从“上架 marketplace”到“经验证可安全执行”之间的鸿沟，依然没有被填平。

### 演示品与生产级代理

[@databricks](https://x.com/databricks) [发起了](https://x.com/databricks/status/2051683930223325228)（53 次点赞、18 次收藏、2717 次浏览）直言不讳地评价：“大多数‘agentic AI’仍然只是演示品。明显的例外是数据工作和编程。”[@LandonExplr](https://x.com/LandonExplr) 回复道：“Agentic AI 只有在输出可验证的地方才有效。数据流水线符合这一点。其他所有自称 ‘agentic’ 的东西，仍然都只是演示品。”

## 3. 人们希望出现什么

### 代理间通信管道

[@SaidAitmbarek](https://x.com/SaidAitmbarek) [描述了](https://x.com/SaidAitmbarek/status/2051565623369433256)（12 次点赞、1 次收藏、206 次浏览）介绍了自己在 ChatGPT 和 Codex 之间来回复制内容的工作流，并希望有这样一种东西：“一个无头桥接器（pipe），能在代理之间流式传输数据（ad-hoc）。就像 OAuth，但面向代理，而且带持久化流。”当前的缺口是：不同供应商的两个代理之间，还没有一种标准方式可以实时来回传递上下文。

### 技能验证基础设施

[@omarsar0](https://x.com/omarsar0) [呼吁](https://x.com/omarsar0/status/2051772437520622035)（21 次点赞、34 次收藏）提出了“SKILL.md”——一种类似软件供应链证明的代理技能验证标准。[@yzg75001](https://x.com/yzg75001) 转发并补充道：“在有人发布一个对生产环境有写权限的恶意技能之前，我们需要类似 sigstore 的代理技能方案。”

### 超越 1200 万 Token 的上下文扩展性证明

[@willdepue](https://x.com/willdepue) [质疑了](https://x.com/willdepue/status/2051757962595635323)（59 次点赞、8 次收藏）直接向 SubQ 发问：“如果它真的是次二次复杂度，是什么阻止你们演示 1 亿、10 亿，甚至 100 亿规模的上下文？”人们需要的是可验证的演示，来证明长上下文方案真的能扩展，而不只是抛出缺乏复杂度分析的大数字。

### 原生代理的权限与身份层

[@Arkive_live](https://x.com/Arkive_live) [认为](https://x.com/Arkive_live/status/2051617906283192428)（12 次点赞）在 Meta 泄露事件后表示：“企业从第一天起就需要带有内置权限边界和可审计性的智能层。”Meta 事件证明，把治理事后补到现有代理部署上是行不通的。

| DeepSeek TUI | 终端编程代理 | 新兴 | 1M 上下文、子代理、键盘驱动、git 管理 | 生态支持不如 Claude/Codex |
| Flue | 代理 harness | 正面 | 一键部署到 Render；将 .ts 文件放入 agents/ 即可 | 仅支持 TypeScript；处于早期阶段 |

最显著的变化是：工具层面的讨论已经从“哪个模型最好”转向“哪个编排层能在尽量延长自主运行时间的同时，把 Token 开销压到最低”。Insforge 的 3 倍 Token 降幅，以及 /goal 的多日执行能力，代表了新的性能前沿。

## 7. 机会在哪里

**[+++] 代理技能验证与供应链安全。** @omarsar0 提出的“SKILL.md”框架、@yzg75001 承认生产环境中的信任“靠感觉”，以及 OpenClaw marketplace 中 13,700+ 技能，共同指向一个明确空白：代理技能领域还没有 sigstore 的等价方案。随着技能 marketplace 扩张，谁能做出可验证的技能证明体系，谁就有机会掌握信任层。

**[+++] 消除 Token 浪费的上下文工程。** @akshay_pachaar 通过 Insforge Skills 演示了 3 倍 Token 降幅（10.4M 降至 3.7M），且错误数为 0。SubQ 则宣称支持 1200 万 Token 的工作上下文。共同模式是：位于用户与模型之间、通过组织信息来减少冗余推理的上下文工程层，正在成为增长最快的价值捕获点。

**[++] 具备漂移检测能力的多代理编排。** Scion 已提供容器隔离。@om_patel5 指出信心漂移问题。@artemg314 的 AutoSwarm 则把多代理流水线从 30% 提升到 90%。从“代理并行运行”到“代理保持一致地运行”之间的缺口，带来了内置分歧检测的协同工具机会。

**[++] 原生代理的视频与语音生产。** HyperFrames + Hermes、HeyGen + Superhuman Go、xAI Custom Voices，以及 Deepgram + Together 都在同一天发布。这个汇聚信号表明，多模态代理输出（而不只是文本）正在成为标配，机会存在于质量控制、品牌一致性和自动化编辑。

**[+] 单人团队基础设施。** Coinbase 围绕“one-person teams”的重组，以及 @code_rams 的“3-agent solo founder stack”，都指向一种基础设施需求：让单个操作者能管理覆盖研究、内容和运营的代理舰队。能让这一模式可靠运转的工具（监控、交接、质量闸门）需求正在增长。

**[+] 去中心化代理工作 marketplace。** AgenC、ShelleyBay、GenLayer 和 Handshake trading skills 都代表了独立构建链上代理任务 marketplace 的尝试。这一模式已被多个团队验证；最终谁胜出，将取决于执行能力和信任基础设施。

## 8. 要点

1. **/goal 命令让“执行计划”的质量成为新的瓶颈。** AlexFinn 那条得分 2577、收藏 424 次的帖子证明，社区已经认识到，多日代理运行是可行的，但完全依赖结构化规划文档——最值钱的技能因此从“写好代码”转向“为代理写好计划”。（[来源](https://x.com/AlexFinn/status/2051525926874501291)）

2. **上下文工程今天就能带来可量化的 3 倍成本下降。** @akshay_pachaar 展示的前后对比（10.4M tokens/$9.21 对 3.7M tokens/$2.81），且错误数归零，证明上下文工程层不是理论概念——对任何大规模运行代理的人来说，它都能立刻带来可量化节省。（[来源](https://x.com/akshay_pachaar/status/2051589749689962949)）

3. **技能生态的发展已经超过其信任基础设施。** OpenClaw 拥有 13,700+ 技能，HyperFrames 已为 Hermes 发布，而实践者也承认信任“靠感觉”，这说明代理技能层的分发扩张速度已经快于验证能力。@omarsar0 的供应链安全框架，是在首个重大技能型攻击发生前发出的预警。（[来源](https://x.com/omarsar0/status/2051772437520622035)）

4. **多代理编排已经从概念走向容器化产品。** Scion 为每个代理提供容器隔离，@daytradingzoo 的前后端拆分，以及 @om_patel5 的“4 人团队”（2 个人类 + 2 个 Claude）都表明，多代理如今已是实用工作流，而不再只是研究好奇心——但漂移检测仍未解决。（[来源](https://x.com/geminicli/status/2051725136974246266)）

5. **Coinbase 裁员 14%，表明“AI 原生组织结构”已经成为上市公司的运营命题。** 单人团队、扁平化层级和代理舰队不再只是博客文章里的概念——它们已经在一家市值 600 亿美元以上的公司里左右裁员决策。这将加速企业对代理管理与治理工具的需求。（[来源](https://x.com/rohanpaul_ai/status/2051750752742502812)）

6. **代理视频技术栈在一天之内到位。** HyperFrames、HeyGen + Superhuman、xAI Custom Voices，以及 Together 上的 Deepgram STT 都在 5 月 5 日发布。代理不再只是文本输入/文本输出——多模态输出正成为默认能力，也在把原本彼此分离的工具类别压缩为单技能安装。 （[来源](https://x.com/AndyMarlowg/status/2051764817153962477)）
