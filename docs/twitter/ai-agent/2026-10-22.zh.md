# Twitter AI 智能体 - 2026-10-22

## 1. 大家在讨论什么

### 1.1 Agent Skills 开始接受中立治理 🡕

Anthropic 宣布将 Agent Skills 捐赠给 Agentic AI Foundation。[@ClaudeDevs](https://x.com/ClaudeDevs) [据报道](https://x.com/ClaudeDevs/status/2113328526413996100)（1,228 个赞、72 条回复、57,510 次浏览、219 次收藏）称，自 2025 年 12 月以来，已有 70 多个智能体平台集成了这一标准。后续帖子将版本化发布、正式提案流程和安全指南列为委员会的首要任务。

### 1.2 编码智能体评测检验后续改动是否会破坏已有成果 🡕

SlopCodeBench 通过一系列不断变化的需求，以及针对早期功能的回归测试来评估智能体。[@NotRyanB](https://x.com/NotRyanB) [据报道](https://x.com/NotRyanB/status/2113357440959791299)（25 个赞、8 条回复、1,607 次浏览）显示，在所审阅的图表中，严格得分最高值为 16.33%，而仅考察核心功能时的成功率为 69.39%；不过，作者提醒，运行样本较少，且测试框架未经定制，因此不足以据此对模型进行权威排名。

![SlopCodeBench 图表：严格全套测试成功率与仅核心测试成功率对比](https://pbs.twimg.com/media/HVQhEXKXoAAfEmj.jpg)

### 1.3 有报道称，智能体已用于生产环境的贷款业务流程 🡒

一项贷款机构案例研究介绍了两名工程师如何在现有生产平台上构建 ACH、承保和银团管理系统。[@mardehaym](https://x.com/mardehaym) [据报道](https://x.com/mardehaym/status/2113235089513423216)（49 个赞、35 条回复、11,176 次浏览、28 次收藏）介绍了各阶段周期时间的缩短，以及先写规格再实施、测试优先开发、自动化检查和合并前人工审核等做法。这是供应商提供的案例研究，并非独立的生产力基准测试。

![贷款机构系统示意图，展示业务核心、共享数据和集成关系](https://pbs.twimg.com/media/HVO4HOPX0AEnPDM.jpg)

## 2. 大家感到不满的地方

### 回归问题与运行所需背景信息缺失

在所审阅的这次测试中，SlopCodeBench 的严格得分远低于仅考察核心功能时的得分，说明后续改动可能通过新功能检查，却破坏已有行为。贷款机构案例指出，缺少架构背景、易于查找的构建和测试命令、一致的模块模式以及可复用流程，都是实际存在的问题；案例作者在交付改动前补充了背景文件和自动化验证。



---



## 3. 大家希望出现什么

### 配备正式变更和安全流程的可移植技能

Agent Skills 的公告介绍了一种旨在供各方共享的标准；后续治理公告则将版本化发布、提案流程和安全指南列为优先事项。[@ClaudeDevs](https://x.com/ClaudeDevs) [概述了](https://x.com/ClaudeDevs/status/2113328529911730587)（142 个赞、5 条回复、12,033 次浏览、41 次收藏）介绍了这项工作。**机会：直接且正在形成**；该帖提出了具体的治理需求，但尚未说明最终会采取哪些管控措施。

### 面向需求演进的基准测试

SlopCodeBench 被用来检验代码库发生变化时，智能体能否保留早期需求。作者 [解释了](https://x.com/NotRyanB/status/2113357440959791299)（25 个赞、8 条回复、1,607 次浏览）介绍了该基准测试中一系列不断变化的规格和回归测试，同时提醒，运行样本较少，限制了基于结果进行排名的可靠性。
