# Twitter 智能体 - 2026-11-04

## 1. 大家在讨论什么

### 1.1 智能体运行框架逐渐成为明确的工程工作流（🡕）

相关帖子不再局限于提示词串联，而是开始聚焦明确的运行环境、集成、运维、记忆机制和专业智能体协作。相关证据包括一套研讨会课程、从业者的批评，以及一个团队分享的修复漏洞工作流。

[@GrahamHelton3](https://x.com/GrahamHelton3) [发布了](https://x.com/GrahamHelton3/status/2118030259329949803)（19 个赞、3 次转发、2 条回复、1,499 次浏览、2 次收藏）介绍了一套面向漏洞研究的智能体运行框架工程入门研讨会材料。一条回复将其中的经验归纳为本地验证环境、外部集成、运维接口和记忆机制；链接的 [工作坊代码库](https://github.com/GrahamHelton3/harness-engineering-workshop) 收录了书籍的源文件。这些材料是一套课程，并非经过测量的安全成效。

[@zachlloydtweets](https://x.com/zachlloydtweets) [认为](https://x.com/zachlloydtweets/status/2117944698647494678)（258 个赞、28 次转发、70 条回复、35,906 次浏览、154 次收藏）认为，指望提示词链取代运行框架的团队终将后悔。这条引发广泛讨论的帖子将两者的差距归结为工作流设计问题，但没有提供基准测试，也没有指定某种架构。

[@patrickjcampbell](https://x.com/patrickjcampbell) [报道](https://x.com/patrickjcampbell/status/2117928338422786536)（122 个赞、9 次转发、16 条回复、7,868 次浏览、37 次收藏）称，一套 XLA 运行框架与智能体蜂群配置已经发现并修复了数百个漏洞。作者表示，由一个主智能体负责去重，专业智能体则调查各项报告；但帖子没有给出样本总量，也没有经过独立验证。

**与前一天相比：** 11 月 3 日的讨论已经涉及运行框架评估、技能和安全控制。今天的例子新增了实用研讨会课程和另一套由团队分享的工作流，同时也出现了旨在管理或改进智能体运行过程的产品。

### 1.2 智能体能力目录开始具备产品和开发者计划入口（🡕）

可复用能力的分发正成为一种产品形态；另有一项新计划，旨在从智能体反复出现的失败中学习。

[@NousResearch](https://x.com/NousResearch) [推出](https://x.com/NousResearch/status/2118006378690754694)（651 个赞、55 次转发、70 条回复、60,050 次浏览、529 次收藏）介绍了 Hermes Marketplace，用于提供插件、连接器和技能。[在线目录](https://hermes-agent.nousresearch.com/marketplace/) 将发现和安装功能具体呈现出来；这则公告并不能证明扩展的质量或采用情况。

[@NousResearch](https://x.com/NousResearch) [宣布](https://x.com/NousResearch/status/2117988208528449824)（307 个赞、32 次转发、42 条回复、33,768 次浏览、151 次收藏）宣布举办 11 月 4 日至 11 日的 Hermes Agent 黑客松，六名获胜者将分享 10,000 美元奖金；评审标准包括实用性、可靠性、打磨程度和创造力。这只是主办方公布的计划，不能证明项目已经完成。

[@oumi_ai](https://x.com/oumi_ai) [推出](https://x.com/oumi_ai/status/2117992968347181298)（35 个赞、5 次转发、3 条回复、3,254 次浏览、7 次收藏）介绍了 FAiE：一个处于私人预览阶段的系统，它利用现有运行框架中反复出现的失败模式来创建评测、训练数据和微调模型。其 [产品页面](https://faie.oumi.ai/) 描述了构建与评估的循环；所引用的材料没有提供独立的质量评估结果来佐证其训练相关说法。

## 2. 大家遇到的困扰

### 等待审批可能让长时间运行的工作陷入停滞

**严重程度：中；普遍程度：低置信度。** 一位开发者表示，Claude Code 的一项任务曾等待审批两小时（[帖子](https://x.com/0xMfox/status/2117975491963945269)，14 个赞、2 次转发、4 条回复、1,490 次浏览、5 次收藏）。侧边栏会显示等待状态，但帖子没有提到自动升级处理或可恢复的审批流程。对于异步运行的工作流，值得考虑构建相关能力；不过，单凭这一个人的经历，无法证明市场上普遍存在此类需求。

### 提示词链被认为不足以替代运维设计

**严重程度：低；普遍程度： 未经量化。** [@zachlloydtweets](https://x.com/zachlloydtweets) [警告](https://x.com/zachlloydtweets/status/2117944698647494678)（258 个赞、28 次转发、70 条回复、35,906 次浏览、154 次收藏）这条讨论指出，团队可能会后悔把提示词链当作智能体运行框架。它反映了从业者的担忧，但没有提供具体的失败案例或采用数据。这种批评说明，工作流设计值得关注，但并未证明这是一个已量化的痛点。

## 3. 人们希望出现什么

没有发现普遍而明确的需求清单。最明确的实际需求是从一则任务受阻的报告中推断出来的；其他证据反映的是产品供给，而非用户需求。

### 保留任务状态的审批交接

Pixel Agents 的创作者称，审批等待了两小时（[帖子](https://x.com/0xMfox/status/2117975491963945269)，14 个赞、2 次转发、4 条回复、1,490 次浏览、5 次收藏）。清晰可见的任务状态、异步审批和可靠的恢复节点或许能解决这一案例中的问题，但没有受访者明确提出某项具体功能。**需求类型：** 实用。**机会：** 直接，但依据仅限一个具体工作流案例。

### 能明确体现可靠性的能力目录

Hermes Marketplace 提供了一个查找插件、连接器和技能的平台；其黑客松也将可靠性列为评审标准之一（[市场公告](https://x.com/NousResearch/status/2118006378690754694)，651 个赞、55 次转发、70 条回复、60,050 次浏览、529 次收藏；[黑客马拉松公告](https://x.com/NousResearch/status/2117988208528449824)，307 个赞、32 次转发、42 条回复、33,768 次浏览、151 次收藏）。这些帖子没有显示用户要求安全性或质量评级，因此，提供经过验证的兼容性信息和可追溯来源的目录只是推断，并非用户明确表达的需求。**需求类型：** 实用，但未经验证。**机会：根据现有证据，属于** 愿景型。

## 6. 新动态与亮点

### 智能体故障成为改进模型的输入

FAiE 的封闭预览版介绍了一套基于现有运行框架的故障处理流程：提取反复出现的故障模式，生成评估和训练数据，再在保留运行框架的同时微调模型。[@oumi_ai](https://x.com/oumi_ai) [宣布](https://x.com/oumi_ai/status/2117992968347181298)（35 个赞、5 次转发、3 条回复、3,254 次浏览、7 次收藏）介绍了该产品，[页面](https://faie.oumi.ai/) 则描述了这套工作流。公告没有提供独立结果来证明这一训练闭环能提高任务成功率。

## 7. 机会所在

**[+++］ 可靠的智能体运行** - 工作坊课程涵盖验证、集成、运维和记忆；XLA 示例增加了主代理去重；Pixel Agents 则提供等待人工审批的机制。这些内容共同表明，我们需要可观测、可恢复且结果可供审查的工作流（［工作坊](https://github.com/GrahamHelton3/harness-engineering-workshop)；[XLA 帖子](https://x.com/patrickjcampbell/status/2117928338422786536)，122 次点赞、9 次转发、16 条回复、7,868 次浏览、37 次收藏；[Pixel Agents 帖子](https://x.com/0xMfox/status/2117975491963945269)，14 次点赞、2 次转发、4 条回复、1,490 次浏览、5 次收藏）。这些证据来自课程资料以及个人和团队的报告，并非市场规模估算。

**[++］ 可信的扩展发现** - Hermes Marketplace 已上线，其黑客马拉松明确将可靠性与实用性、精致度和创意一并纳入评分（［上线](https://x.com/NousResearch/status/2118006378690754694)，651 次点赞、55 次转发、70 条回复、60,050 次浏览、529 次收藏；[黑客马拉松](https://x.com/NousResearch/status/2117988208528449824)，307 次点赞、32 次转发、42 条回复、33,768 次浏览、151 次收藏）。兼容性、来源信息和质量信号或许能帮助用户挑选扩展，但这两则公告都未能证明市场对验证层的需求。

**[+ 将失败转化为评估的流程** - FAiE 提议将反复出现的运行失败转化为评估和训练数据（［公告](https://x.com/oumi_ai/status/2117992968347181298)，35 次点赞、5 次转发、3 条回复、3,254 次浏览、7 次收藏）。这是一个新兴的产品方向；预览版尚未提供经独立验证的改进结果。

## 8. 要点

1. **智能体工程正被视为工作流设计，而非提示词编排。** 一场研讨会列出了验证、集成、运维和记忆；XLA 案例则展示了由主代理负责去重、专业代理负责调查的工作流（[工作坊](https://github.com/GrahamHelton3/harness-engineering-workshop)；[@patrickjcampbell](https://x.com/patrickjcampbell) [报道](https://x.com/patrickjcampbell/status/2117928338422786536)，122 次点赞、9 次转发、16 条回复、7,868 次浏览、37 次收藏）。
2. **可复用的智能体能力如今有了在线目录和开发者计划。** Hermes Marketplace 上线公告的互动量很高，配套黑客松也将可靠性列为评审标准之一（[市场](https://x.com/NousResearch/status/2118006378690754694)，651 次点赞、55 次转发、70 条回复、60,050 次浏览、529 次收藏；[黑客马拉松](https://x.com/NousResearch/status/2117988208528449824)，307 次点赞、32 次转发、42 条回复、33,768 次浏览、151 次收藏）。
3. **执行流程中仍能看到人工把关。** 一位创作者称，审批等待了两小时；FAiE 则提出将失败案例用于评估和训练。这两者都是早期信号，并非经过独立测量的结果（[Pixel Agents](https://x.com/0xMfox/status/2117975491963945269)，14 次点赞、2 次转发、4 条回复、1,490 次浏览、5 次收藏；[FAiE](https://x.com/oumi_ai/status/2117992968347181298)，35 次点赞、5 次转发、3 条回复、3,254 次浏览、7 次收藏）。
